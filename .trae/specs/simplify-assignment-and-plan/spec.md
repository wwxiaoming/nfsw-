# 简化分配速查 + 优化执行规划 Spec

## Why
当前 sub-agent 速查表与执行规划文档存在过度约束：
1. 速查表里塞了字符下限/字符限定、必含 4 项、推荐元素池等"输出约束"内容，违背了"速查"定位（应是纯分配指引，不约束 AI 发挥）。
2. 规划文档里既保留旧的"权重 9-10 分"硬指标，又出现 sub-agent 数量限制，且与速查表重复，且每本小说没有"灵活模板"输出指引。
3. 旧版 `旧但详细documents/v2-阶段4.1-4.3-...` 与新版的 `v2-阶段4.1-4.3-...` 内容冲突，用户要求用新版覆盖旧版。

## What Changes
- **删除**：`sub-agent分配速查表.md` 中的 §3 字符预算、§4 最少必含项、§5 字符下限相关列、表格中的"字符下限"列、表格中的"5必含版本"列
- **覆盖**：`旧但详细documents/v2-阶段4.1-4.3-逐本通读+笔记实时写入_2026-06-20.md` → 被新版 `v2-阶段4.1-4.3-...` 覆盖后整目录删除（或仅保留空目录或整个旧但详细documents 目录）
- **重写**：`v2-阶段4.1-4.3-...` 的核心：
  - 删掉"权重 9-10 分"硬指标（字符下限整段删除）
  - 删掉"6 批次 36 个 sub-agent + 6 个合并 = 42 个"等 sub-agent 数量规定（具体数量由速查表决定，规划只描述方法论）
  - **新增"每本小说输出指引（灵活模板）"**：列出可选元素池（作品定位/关键章节/核心套路/关键场景/角色弧光/世界观设定/写作技法/v2 SKILL 升级建议/可复用元素/戏剧冲突结构/情绪曲线/对白风格/跨作品对比），但**不强制数量、不锁死顺序**——让 AI 按作品实际自由发挥
  - 删掉"5 必含"硬性下限
  - 删掉表格中"权重"列、"字符下限"列
- **保留**：3 步走流程、6 份笔记文件路径、写入策略（串行/并行待用户选）、分段读取提示、实测边界、文档关系等基础设施

## Impact
- Affected specs: `expand_xiaoyingxiong_skill_v2` 阶段 4.1-4.3
- Affected code: 3 个 markdown 文件
  - `documents/sub-agent分配速查表.md`（瘦身）
  - `documents/v2-阶段4.1-4.3-逐本通读+笔记实时写入_2026-06-20.md`（重构）
  - `documents/旧但详细documents/`（删除或清空）

## 待用户决定（执行模式）
由用户在两个方案中选一个，写入 spec 的"执行模式"小节：
- **方案 1**：同一批次并行输出多份深度阅读草稿（每个 sub-agent 写到独立草稿 .md），主代理再串行合并草稿到正式笔记
- **方案 2**：不同批次并行，同一批次串行（sub-agent 直接写正式笔记 4.X/5.X 段，串行避免冲突）

## 硬约束（保留）
1. 单 sub-agent 总大小 ≤ 500KB（实测硬上限，单章节不拆）
2. 6 份笔记文件路径不变
3. 段落编号 4.X / 5.X 唯一

## 软约束（删除/改为灵活）
- ~~字符下限 ≥ 15,000（高分）~~ → **删除**，AI 按内容自由发挥
- ~~必含 4 项 + 推荐元素池（强制最少 4 项）~~ → **改为"灵活模板"**，列可选元素让 AI 自由组合
- ~~5 必含版本（完整/略简/紧凑/4 必含）~~ → **删除**
- ~~权重 9-10 分 / 7-8 分 / 5-6 分 / 1-4 分~~ → **删除**
- ~~sub-agent 数量 36/42/77~~ → **删除**，具体由速查表决定

## "每本小说输出指引"灵活模板（新增）
规划文档新增一节"每本小说输出指引（灵活模板）"，列元素池但不锁死：

**可选元素池**（13 项，AI 按作品实际自由选用 3-10 个，顺序自由）：
- 作品定位 / 关键章节 / 核心套路 / 关键场景 / 角色弧光
- 世界观设定 / 写作技法 / v2 SKILL 升级建议
- 可复用元素 / 戏剧冲突结构 / 情绪曲线
- 对白风格 / 跨作品对比

**指引原则**（不锁死）：
- AI 根据小说实际内容自由决定详略
- 鼓励写得越详细越好，但**无硬性下限**
- 高质量套路/章节/场景摘录优先
- 给出**至少 1 条可操作**的 v2 SKILL 升级建议（如有）
