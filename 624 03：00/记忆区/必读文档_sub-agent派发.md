## §3 3 大雷点（**写进子代理，写时严格避免，v3 严格版**）

> **v3 更新（2026-06-22）**：sub-agent 雷点判定**只用本表 3 条**——禁止自创 R1/R2/R3 之外的任何雷点标签、子标签、二级识别、边缘分桶、擦边球、边界命中、轻度命中等。

| 编号 | 雷点 | 处理 | 子代理判定的合法措辞 |
|---:|---|---|---|
| **R1** | 雷女性角色（受害者） | 默认 male 化（亲情线除外） | "**命中**" / "**不命中**" |
| **R2** | 雷 R18G（极端血腥/阉割/内脏） | 轻-中度暴力，无内脏描写（阉割→肿胀） | "**命中**" / "**不命中**" |
| **R3** | 雷父子乱伦（所有形式） | 严禁出现 | "**命中**" / "**不命中**" |

**禁止措辞清单**（出现即整段重写）：
- ❌ "R1=性瘾/榨精/控制"
- ❌ "R2=调教/驯服/羞辱/擦边"
- ❌ "R3=强制/违愿/洗脑"
- ❌ "R3-b 非血亲权力差" / "R2 二级识别" / "R3 边缘命中" / "R-B 父子同侍一主"
- ❌ "轻度命中" / "严重擦边但不入黑名单" / "边缘铺垫" / "R3 边缘父子同侍一主"
- ❌ 任何 R1/R2/R3 + 字母后缀的命名（如 R3-a / R3-b / R2-c / R-A）

**v2 SKILL 升级建议段（§X.9）的特殊规则**：
- ✅ 允许提**子型 / 子模板**（如 T1-c 金丝笼收编型、S-边界场景、M-萌点模板）—— **属于 SKILL 扩展建议，不是雷点**
- ✅ 必须明确标注"v2 SKILL 升级建议（不是雷点）"
- ❌ 子型建议**不能**用 R3-b / R2-二级 这种容易混淆雷点标签的格式

## §4 v9 弹窗协议

> **每个关键步骤完成后，主代理必须用 AskUserQuestion 弹窗让用户决定下一步。不跳过、不擅自连跑。**

### sub-agent 派发时弹窗触发
- batch 启动前（弹窗让用户确认本批次）
- batch 中每 1-2 部作品（弹窗让用户确认进度）
- batch 完成（弹窗让用户审阅）

### sub-agent 自己的弹窗
- 遇雷点触发时 → 弹窗询问处理方式
- 遇 R18 元素歧义时 → 弹窗询问按哪部处理
- 遇命中度问题 → 弹窗询问
