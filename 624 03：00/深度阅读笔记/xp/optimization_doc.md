## 三、雷点处理规则

### 3.1 未命中 = 不写（核心原则）

如果一部作品**没有命中任何雷点**，则**整个雷点部分留空**，不写任何内容。

**绝对禁止**（以下所有模式必须删除）：
```
- **女性** — 无 ✓
- **血腥** — 无
- **NTR** — 无 → 雷点规避
- **女性角色**：无 → 雷点完全规避
- **血缘父子直接** — 无
- ❌ **无血亲父子乱伦中心**。
- **女性角色**：无（除...）→ 雷点基本规避
- **血腥**：无（调教无出血）→ 雷点规避
- **女性角色**：无 → 雷点完全规避
- **血腥**：含"精液出血"但属虚构 → 雷点轻度命中
- **三观偏移**：含"父子乱伦" → 雷点命中 -1~3 分
```

**正确做法**：
- 如果没有雷点，直接跳过雷点小节
- 或只写 `**雷点**：` 后面留空
- 或写 `#### 雷点命中` 后直接空行

### 3.2 只保留实际命中（当前3种雷点清单）

仅当作品**确实命中**某雷点时，才写入该雷点描述。

**当前3种雷点清单**：

| 序号 | 雷点类型 | 严重度 | 处理规则 |
|:---:|----------|--------|----------|
| 1 | **女性角色（受害者）** | 高 | 生成时将"受害者"全部默认 male 化；女性角色可保留为"调教师"或"旁观者" |
| 2 | **R18G（去势、刀割、断肢）** | 高 | 生成时改为"羞辱到极致但不见血"（如锁链、羞辱工具等） |
| 3 | **父子乱伦（所有）** | 高 | 严禁出现；包括血亲、非血亲、记忆覆盖型、养父子、师徒父子等所有形式 |


**已删除的雷点（不列入标注，发现即删）**：
- 成年-未成年+师生（用户指定删除）
- 正太/儿童色情（用户指定删除）
- 校园轮奸（用户指定删除）
- 亲兄弟暧昧（用户指定删除）
- 儿童正太（<14 岁）+ SM/强暴/暴力（用户指定删除）
- 儿童正太（<14 岁）+ 暴力管教（用户指定删除）
- 三观偏移（不在清单中）
- NTR（不在清单中）
- 跨性别/性别认同（不在清单中）
- 恋尸癖（不在清单中）

### 3.3 删除"雷点边界处理"相关内容

以下内容已随雷点删除而失效，必须一并删除：
- `雷点边界处理`、`结构借鉴`、`年龄改写 18-25`
- `雷点边界：替换为"能量灌注"`
- `雷点边界处理: 结构借鉴 + 年龄改写 18-25`
- `雷点 -1/-2/-3 显式标注`
- `剔除未成年人受害 + 改写 18-25 岁`

### 3.4 雷点格式统一

命中雷点的标准格式：
```
⚠️ **雷点名称**：具体描述——**处理规则**。
```

或简写：
```
⚠️ **雷点名称**：具体描述。
```

**禁止**使用：
- `❌ **无XX**` 格式
- `无 →` 格式
- `无（...）` 格式
- `✓` 标记
- `轻度命中`、`严重命中` 等主观评级（保留客观描述即可）
- `降 X 分`、`-1/-2/-3` 等评分标记

### 3.5 父子乱伦特别规则

根据雷点清单，**父子乱伦（所有）= 雷点**，包括：
- 血亲父子乱伦
- 非血亲父子乱伦
- 记忆覆盖型父子乱伦
- 养父子乱伦
- 师徒父子乱伦

**任何形式的父子乱伦都视为雷点，必须标注。**

**注意**：如果作品包含"父子乱伦"，只写 `⚠️ **父子乱伦**：具体描述。`，不写"雷点 -1/-2/-3"等评分。
