# 小英雄学院（独立条目）

> 来源：06 圣灵战队 + 01 战队特摄 + 02 勇者奇幻 + 09 体制化榨精
> 定位：跨子类核心联动世界观
> 生成时间：2026-06-21

---

## 为什么是小英雄学院？

| 维度 | 说明 |
|------|------|
| **跨子类联动** | 01 战队特摄（紧身衣+战队结构）+ 02 勇者奇幻（冒险+升级）+ 09 体制化榨精（群像+考核）+ 06 圣灵战队（5人编制+学院体制） |
| **天然 XP 训练场** | 学院体制 = 有教官、有考核、有升级、有同学竞争、有败北-被俘-榨精循环 |
| **受众匹配** | 正太/少年主角 + BL 队友 + 战败羞辱 = 命中所有核心 XP |
| **扩展性强** | 可添加班级/年级/导师制/实战考核/同学竞争/竹马羁绊等无限扩展 |

## 核心设定

### 1. 学院体制

| 元素 | 说明 | 来源 |
|------|------|------|
| 班级/年级 | 按战力分班，低年级是高年级的"猎物" | 09 奴隶调教中心 |
| 导师制 | 每名学生配一名导师/教官，负责"特训" | 01 超星战队日常 |
| 考核排名 | 实战考核排名决定资源分配和"惩罚" | 09 奴隶节/期末考核 |
| 同学竞争 | 竹马/队友从小一起，觉醒后互调 | 01 超星战队日常（竹马/队友互调） |

### 2. 紧身衣战衣变身体系

| 元素 | 说明 | 来源 |

| 阶段 | 说明 | 来源 |
|------|------|------|
| 败北 | 实战中被击败，暴露弱点 | 01 高弹#8、天装#1 |

| 榨精 | 强制射精、当众羞辱、精能抽取 | 01/02/04/05 全子类 |
| 回收 | 治疗后回归，战力提升 | 01 战队常规 |

## v2 SKILL 建议：新增"小英雄学院"子模块

### 模块结构

```
小英雄学院/
├── 学院体制（班级/年级/导师制）
├── 紧身衣战衣变身体系
├── 实战考核（败北-被俘-榨精循环）
├── 同学竞争/竹马羁绊
└── 榨精魔物/榨精生物实战
```

### 核心公式

1. **考核失败公式**：实战考核失败 → 被俘 → 强制榨精 → 精能抽取 → 治疗后回归
2. **竹马互调公式**：竹马从小一起 → 觉醒后互撸+互调+口交 → 竞争+嫉妒+保护
3. **魔物实战公式**：学院用榨精魔物作为考核怪物 → 学生被魔物捕获榨精 → 败北-被俘-榨精循环
