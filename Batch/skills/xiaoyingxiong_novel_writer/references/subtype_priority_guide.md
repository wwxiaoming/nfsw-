# 子类型优先级建议指南（Subtype Priority Guide）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"新作品 / 续写时子类型优先级排序"的建议指南。

---

## 一、子类型优先级 4 原则

### 原则 1：主类型必选（战队 01）
- **规则**：所有"小英雄"题材作品必选子类型 01（战队/英雄）
- **原因**：11 部主线语料 + 8 部战队特摄 = 100% 都有战队元素
- **应用**：01 子类型优先级 = 100%

### 原则 2：副类型推荐 2-3 个
- **规则**：04 调教 + 08 触手 + 06 主仆 是 3 大副类型
- **原因**：实战显示 8/8 战队特摄都有 04 + 08
- **应用**：04 + 08 子类型优先级 = 95%；06 主仆 = 50%

### 原则 3：特色辅类型 1-2 个
- **规则**：根据作品特色选 1-2 个（02 喜剧 / 03 反派 / 05 兄弟 / 09 足控）
- **原因**：平均 5-6 个子类型 / 部，辅类型占 1-2 个
- **应用**：
  - 想做喜剧情色 → 02 喜剧（4.3 超级战士 9.5 分）
  - 想做反派恶堕 → 03 反派（4.1 高弹 10 分）
  - 想做兄弟同堕落 → 05 兄弟（4.1 高弹 / 5.1 龙骧 / 5.3 超星 / 5.4 超能 kk）
  - 想做足控 → 09 足控（5.1 龙骧 / 5.3 超星 / 5.4 超能 kk）

### 原则 4：同人 / 二创是跨作品衍生
- **规则**：07 同人 可叠加任何子类型，作为"角色熟悉度"加分
- **应用**：07 同人优先级 = 50%（半数作品同人化）

## 四、新作品子类型选择 SOP

### Step 1：选主类型（必选）
- 01 战队（100%）

### Step 2：选 2-3 个核心副类型（≥ 60%）
- 04 调教 + 08 触手 + 06 主仆（3 选 2-3）

### Step 3：选 1-2 个特色辅类型
- 02 喜剧 / 03 反派 / 05 兄弟 / 09 足控（4 选 1-2）

### Step 4：选 0-1 个同人/二创
- 07 同人（可选）

### Step 5：查冲突
- 03 + 06 冲突（仅 4.4 裆能战记特例）
- 09 + 04 罕见但可融合

### Step 6：输出
- 平均 5-6 个子类型（3-8 范围）
- 填入 `body_data_card.subtypes`
