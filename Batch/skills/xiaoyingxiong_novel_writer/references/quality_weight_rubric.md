# 质量打分标尺（Quality Weight Rubric）

> 本文档基于 8 部"战队特摄"子批次的 100% 实读 + 11 部主线语料提炼。提供"作品 → 质量分（0-10）"的打分标尺。每部作品的分数由 4 个维度决定：套路密度、角色深度、XP 命中、结构创新。

---

## 一、4 维度打分

### 维度 1：套路密度（最高 3 分）
- **3 分**：10+ 套路 / 部，跨子类型融合 ≥ 5 个
- **2 分**：6-9 套路 / 部，跨子类型融合 3-4 个
- **1 分**：3-5 套路 / 部，跨子类型融合 1-2 个
- **0 分**：< 3 套路 / 部

### 维度 2：角色深度（最高 3 分）
- **3 分**：5+ 角色弧光 + 反派也有心理深度
- **2 分**：3-4 角色弧光
- **1 分**：1-2 角色弧光
- **0 分**：无角色弧光

### 维度 3：XP 命中（最高 2 分）
- **2 分**：TOP 10 XP 元素命中 ≥ 6 个 + 加分项 ≥ 2 个
- **1 分**：TOP 10 XP 命中 3-5 个
- **0 分**：< 3 个

### 维度 4：结构创新（最高 2 分）
- **2 分**：突破性结构（如 jumpuri 投票 / 父子性记忆 / 三代精液闭环）
- **1 分**：常规结构 + 1-2 个创新
- **0 分**：完全套用模板

## 三、3 档分级标准

### 9-10 分（高权重 / 必读）
- 套路密度 3 + 角色深度 3 + XP 命中 2 + 结构创新 1.5-2
- **代表**：4.1 高弹紧身衣战士白曜、4.4 裆能战记系列、4.3 超级战士、5.1 龙骧、5.4 超能 kk
- **建议**：作为主模板库，跨作品复用

### 7-8 分（中权重 / 选读）
- 套路密度 2 + 角色深度 2 + XP 命中 1.5-2 + 结构创新 0.5-1
- **代表**：4.2 超级战队收集计划、5.2 天装战队护星红、5.3 超星战队日常
- **建议**：作为子类型补充，特定场景使用

### 5-6 分（低权重 / 参考）
- 套路密度 1 + 角色深度 1 + XP 命中 0.5-1
- **建议**：仅作为某 1-2 个套路 / 场景 / XP 的参考

## 四、加分项 / 减分项

### 加分项（每项 +0.5）
- 反派第一人称驱动
- 反派也有心理深度（不是纯工具人）
- 反派叛变 / 加入主角方
- 双英雄对称 + 同堕落
- 跨子类型融合 ≥ 6 个
- 突破性结构（jumpuri 投票 / 父子性记忆 / 三代精液闭环）
- 番外 + 元叙事插页

### 减分项（每项 -0.5）
- 反派完全工具人
- 主角被动无反抗
- 套路同质化（无新意）
- 章节超长但密度低
- 文字质量差（错别字 / 病句 / 翻译腔）

---

## 五、应用步骤

1. **按 4 维度打分**（套路密度 / 角色深度 / XP 命中 / 结构创新）
2. **加 / 减分项**（每项 ±0.5）
3. **查 3 档分级**（9-10 / 7-8 / 5-6）
4. **写入 `body_data_card.quality_score` 字段**
