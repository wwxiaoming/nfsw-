# 节奏模板库（Rhythm Templates）

> 本文档提供"小英雄"题材的节奏模板：章节长度区间、场景切换频率、高潮位置、情绪曲线、收束方式。AI 写文时按本文档规划整体结构。

---

## A. 章节长度区间

### A1. 按题材规模分类

| 题材规模 | 章节数 | 单章字数 | 总字数 | 示例 |
|---|---|---|---|---|
| 短篇 | 1-3 章 | 3,000-8,000 字 | 5,000-25,000 字 | 双子特工（11,807 字）|
| 中篇 | 5-15 章 | 5,000-15,000 字 | 50,000-200,000 字 | 双子特工 2（25,727 字）|
| 长篇 | 20-50 章 | 8,000-20,000 字 | 200,000-1,000,000 字 | 进化之路 / 龙骧战队 |
| 超长篇 | 50+ 章 | 5,000-15,000 字 | 1,000,000+ 字 | 超人暂存（37 chat）|

### A2. 按子类型分类

| 子类型 | 推荐章节数 | 推荐单章字数 | 节奏特点 |
|---|---|---|---|
| 战队 / 群像 | 20-50 章 | 8,000-15,000 字 | 慢热 + 多线推进 |
| 单反派长程 | 10-25 章 | 8,000-20,000 字 | 中速 + 阶段递进 |
| 短篇精湛 | 5-15 章 | 5,000-10,000 字 | 紧凑 + 高密度 |
| 卧底 / 假戏真做 | 8-15 章 | 5,000-15,000 字 | 节奏感强 + 反转密集 |
| 反派洗白 | 10-20 章 | 8,000-15,000 字 | 慢热 + 情感推进 |
| 反英雄 / 严肃 | 10-30 章 | 8,000-20,000 字 | 慢热 + 深度刻画 |

### A3. 章节内部分段

**标准结构**（1 章节 = 3-5 段）：

```
【段 1】开篇
├─ 长度：800-2,000 字
├─ 内容：场景引入 + 角色展示 + 事件开端
├─ 节奏：缓 → 急
└─ 关键：建立本章"情绪基调"

【段 2】发展
├─ 长度：1,500-3,000 字
├─ 内容：情节推进 + 第一次冲突
├─ 节奏：急
└─ 关键：第一次"小高潮"

【段 3】转折
├─ 长度：2,000-4,000 字
├─ 内容：核心事件 + 心理变化
├─ 节奏：急 → 极急
└─ 关键：本章"主高潮"

【段 4】延续
├─ 长度：1,500-3,000 字
├─ 内容：高潮后余韵 + 关系变化
├─ 节奏：极急 → 缓
└─ 关键：角色"心理转折"

【段 5】收束
├─ 长度：500-1,500 字
├─ 内容：本章总结 + 下一章铺垫
├─ 节奏：缓
└─ 关键："句号 + 省略号"
```

## B. 场景切换频率

### B1. 单章场景数

| 题材 | 推荐场景数 | 节奏特点 |
|---|---|---|
| 短篇 1-3 章 | 1 章 = 1-2 场景 | 紧凑 + 单一空间 |
| 中篇 5-15 章 | 1 章 = 1-3 场景 | 中等密度 + 多空间切换 |
| 长篇 20-50 章 | 1 章 = 2-4 场景 | 高密度 + 群像空间切换 |
| 超长篇 50+ | 1 章 = 2-5 场景 | 极高密度 + 多视角 |

### B2. 场景切换的"三坐标法"

> **时间 × 地点 × 角色** 三坐标切换

**示例**（长篇群像 第 3 章）：

```
段 1（场景 1）
├─ 时间：白天 / 训练场
├─ 地点：战队训练馆
├─ 角色：千洛 / 玄麟
└─ 内容：训练 → 千洛第一次觉醒

段 2（场景 2）
├─ 时间：夜晚 / 密室
├─ 地点：反派实验室
├─ 角色：玄麟 / 反派
└─ 内容：玄麟被反派捕获

段 3（场景 3）
├─ 时间：第二天 / 战场
├─ 地点：城市废墟
├─ 角色：天岚 / 反派
└─ 内容：天岚救援失败，被反派的触手怪人擒获
```

### B3. 场景切换的"心理坐标法"

> **从主角的视角切换**

**示例**（单反派长程 第 5 章）：

```
场景 1（密室 / 反派视角）
├─ 反派的"调教师身份"展示
├─ 反派的"过去 / 童年"暗示
└─ 主角的"被展示"状态

场景 2（密室 / 主角视角）
├─ 主角的"心理防线"被突破
├─ 主角的"身体反应"开始
└─ 主角的"自我说服"开始

场景 3（密室 / 队友视角）
├─ 队友赶到，但已经太迟
├─ 队友的"震惊"与"无力"
└─ 主角被反派"展示"给队友
```

## C. 高潮位置

### C1. 整体高潮位置

| 题材规模 | 主高潮位置 | 副高潮位置 | 反高潮位置 |
|---|---|---|---|
| 短篇 1-3 章 | 60-80% | 30-40% | 0-20% |
| 中篇 5-15 章 | 60-80% | 30-40% + 90% | 0-20% |
| 长篇 20-50 章 | 70-85% | 30% + 50% + 90% | 0-20% |
| 超长篇 50+ | 75-90% | 每 10-15 章一个副高潮 | 0-20% |

### C2. 章节内高潮位置

| 章节类型 | 主高潮位置 | 次高潮位置 | 低谷位置 |
|---|---|---|---|
| 标准章节 | 50-70% | 20-30% | 0-10% + 80-100% |
| 反转章节 | 70-90% | 20-30% | 0-20% |
| 番外章节 | 30-50% | 60-80% | 0-10% + 90-100% |
| 情感章节 | 60-80% | 20-30% + 90% | 0-10% |

### C3. 高潮的"递进式"设计

**5 章递进示例（中篇）**：

```
第 1 章：小高潮
├─ 内容：第一次被俘 + 第一次胁迫
├─ 情绪强度：3/10
└─ 作用：建立"调教"基调

第 2 章：副高潮 1
├─ 内容：第一次身体觉醒 + 第一次"自我说服"
├─ 情绪强度：5/10
└─ 作用：心理转折

第 3 章：副高潮 2
├─ 内容：第一次公开凌辱 / 第一次被展示
├─ 情绪强度：6/10
└─ 作用：社会性崩塌

第 4 章：主高潮
├─ 内容：彻底沦陷 + 第一次主动配合
├─ 情绪强度：9/10
└─ 作用：核心情绪爆发

第 5 章：收束 / 番外
├─ 内容：沦陷后日常 + 新平衡
├─ 情绪强度：4/10
└─ 作用：情绪"着陆"
```

### C4. 多主角高潮的"时间错开"

> 长篇群像中，每名队员的高潮时间应错开

**示例（10 队员 × 50 章）**：

```
队员 A（应龙）：高潮在 5 / 15 / 35 / 50 章
队员 B（玄麟）：高潮在 8 / 20 / 38 / 50 章
队员 C（天岚）：高潮在 12 / 25 / 40 / 50 章
队员 D（世风）：高潮在 16 / 30 / 42 / 50 章
队员 E（尘渊）：高潮在 20 / 35 / 45 / 50 章
```

**关键**：
- 避免同时高潮（"群高潮"会让读者疲劳）
- 错开 3-5 章为佳
- 主高潮应集中在 60-80% 处
- 收束阶段（80-100%）应是"多线收束 + 番外"

## E. 收束方式

### E1. 章节内收束

| 收束类型 | 使用场景 | 模板 |
|---|---|---|
| 反差收束 | 主高潮后 | 主角"动作 + 心理"反差 |
| 留白收束 | 转折后 | 主角"未说出口的话" |
| 旁白收束 | 番外 | "……故事还在继续" |
| 队友收束 | 队伍线 | 队友的"反应"作章节尾 |
| 反派收束 | 反派线 | 反派的"评价 / 计划"作章节尾 |
| 觉醒收束 | 心理转折 | 主角"刚刚意识到……"作章节尾 |
| 主动收束 | 半沦陷 | 主角"主动靠近"作章节尾 |
| 崩塌收束 | 彻底沦陷 | 主角"用尽力气……"作章节尾 |

**模板示例**：

反差收束：
```
……他以为自己会哭，但眼泪已经被挤干。
……他的手不自主地握紧了被角。
……——这是他的第一次。
```

留白收束：
```
"……我……"
……话没说完，他已经吻上了反派。
```

队友收束：
```
千洛睁眼，看到玄麟站在门口。
……他不知道该怎么解释。
```

反派收束：
```
"……L-09-17……"反派在笔记本上记录："今日完成第一阶段调教。"
……故事还没结束。
```

### E2. 整体作品收束

| 收束类型 | 适用题材 | 模板 |
|---|---|---|
| 新平衡收束 | 单反派长程 | 主角在"沦陷"中建立新身份 |
| 群像共沦陷 | 群像 | 全部队员"接受"新身份 |
| 反派洗白 | 敌人变情人 | 反派放弃"调教师"身份 |
| 番外 / 续作 | 长篇 | 留多个"未完待续" |
| 反转 | 反英雄 | 主角复仇 / 反杀 |
| 救赎 | 反英雄 / 创伤 | 主角"接受爱" |
| 轮回 | if 线 | "如果当初……" |

**新平衡收束示例**：
```
……故事没有结束。
……千洛已经成为反派的"专属藏品"。
……但他开始接受。
……因为反派的怀抱……是温暖的。
……他有了新的身份。
……他有了新的家。
```

**群像共沦陷示例**：
```
……龙骧战队已经不存在。
……五龙全部成为"收藏家"的所属物。
……但他们仍然在一起。
……这也许是……另一种形式的"战队"。
```

**反派洗白示例**：
```
……敏寒之的"调教师"身份结束了。
……他开始用另一种方式照顾兄弟俩。
……他说："让我……当一天哥哥。"
……第二天，他真的只是哥哥。
……但他留下了白袜和内裤作为"礼物"。
……——这是一个没有结局的故事。
```

**反英雄 / 复仇收束示例**：
```
……乐澄没有去拯救世界。
……他选择了复仇。
……他的复仇对象，是整个"小英雄"系统。
……他成功了。
……但他失去了所有人。
……包括他曾经的队友。
……这是他的选择。
```

**救赎收束示例**：
```
……雷霄没有杀黎明。
……他选择了另一种方式。
……他报了警。
……黎明被抓。
……雷霄开始接受治疗。
……他开始接受"被爱"的可能性。
……这是他的救赎。
```

### E3. 番外 / 后日谈结构

**番外章节模板**（单章 5,000-10,000 字）：

```
【番外 1：沦陷后的一天】
├─ 时间：沦陷后 N 天
├─ 地点：反派的家 / 主控室
├─ 角色：主角 + 反派
├─ 内容：日常 + 暧昧
├─ 情绪：甜蜜 + 羞耻
└─ 收束：温馨

【番外 2：队友的视角】
├─ 时间：沦陷后 N 天
├─ 地点：战队基地
├─ 角色：队友
├─ 内容：队友的"知情 / 不知情"反应
├─ 情绪：复杂 + 反思
└─ 收束：沉默 / 接受

【番外 3：反派的童年】
├─ 时间：N 年前
├─ 地点：反派童年
├─ 角色：童年反派
├─ 内容：反派的创伤 / 起源
├─ 情绪：沉痛
└─ 收束：与主时间线呼应

【番外 4：if 线】
├─ 时间：某个选择点
├─ 地点：分支空间
├─ 角色：主角（另一个选择）
├─ 内容：if 线的不同结局
├─ 情绪：戏剧性
└─ 收束：与主时间线对比

【番外 5：跨角色故事】
├─ 时间：沦陷后 N 天
├─ 地点：混合空间
├─ 角色：多角色
├─ 内容：角色间的羁绊
├─ 情绪：群像
└─ 收束：温馨 / 暗示
```

## F. 整体规划清单

写作前，按本清单规划整体结构：

### F1. 题材规模

- [ ] 决定题材规模（短 / 中 / 长 / 超长）
- [ ] 决定总章节数与单章字数
- [ ] 决定主角数（1 / 4-5 / 7+）

### F2. 节奏规划

- [ ] 标注主高潮位置（60-80% 处）
- [ ] 标注副高潮位置（每 5-10 章）
- [ ] 标注反高潮 / 低谷位置（开篇 + 主高潮后）
- [ ] 设计多线高潮的"时间错开"（如有多主角）

### F3. 场景规划

- [ ] 每章规划 2-4 个场景
- [ ] 用"时间 × 地点 × 角色"三坐标切换
- [ ] 避免连续 3 章同一空间

### F4. 收束规划

- [ ] 每章设计收束方式（反差 / 留白 / 旁白 / 队友）
- [ ] 整体作品设计收束方式（新平衡 / 群像 / 反派洗白 / 反转 / 救赎）
- [ ] 规划番外章节（5-10 个）

### F5. 情绪曲线

- [ ] 绘制整体情绪曲线
- [ ] 绘制单章情绪曲线
- [ ] 绘制多角色情绪曲线（如有）

### F6. 自检

- [ ] 是否有"开篇钩子"（前 3 段必须抓住读者）
- [ ] 是否有"中段转折"（中段必须有"心理转折"）
- [ ] 是否有"主高潮"（60-80% 处必须爆发）
- [ ] 是否有"收束缓冲"（80-100% 必须有"着陆"段）
- [ ] 是否有"番外"（至少 3-5 个番外章节）
