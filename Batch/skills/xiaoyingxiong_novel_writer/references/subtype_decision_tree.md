# 子类型决策表（Subtype Decision Tree）

> 本文档基于 11 部"小英雄"题材语料 + 8 部"战队特摄"子批次（高弹紧身衣/超级战队收集/超级战士/裆能战记/龙骧/天装/超星/超能 kk）的 100% 实读提炼。提供"输入世界书 → 输出 9 大子类型多选结果"的决策流程。

---

## 一、9 大子类型枚举

| 编号 | 子类型 | 关键词 | 典型应用 |
|---|---|---|---|
| 01 | 战队 / 英雄型 | 战队、5 人组、队长、副队、王牌、战衣、变身、圣兽 | 几乎所有小英雄题材（10/11） |
| 02 | 喜剧情色型 | 喜剧、反讽、吐槽、恶搞、蠢萌 | 超级战士、裆能战记（2/8） |
| 03 | 反派 / 恶堕型 | 反派、堕落、恶堕、恶人改造 | 高弹、裆能、天装（3/8） |
| 04 | 调教 / 催眠型 | 调教、催眠、精神控制、贞操锁 | 几乎所有（8/8 全员） |
| 05 | 兄弟 / 双主角型 | 兄弟、双子、竹马、搭档 | 战队 + 兄弟组合（4/8） |
| 06 | 主仆 / 反派主导型 | 主仆、反派主导、主奴、臣服 | 超级战队收集、龙骧、天装、超能 kk（4/8） |
| 07 | 同人 / 二创型 | 同人、二创、官方衍生 | 超级战队收集、龙骧、超星、超能 kk（4/8） |
| 08 | 触手 / 操控 / 异种型 | 触手、操控、触手椅、植入、芯片 | 几乎所有（8/8 全员） |
| 09 | 足控 / 榨精型 | 足控、裸足、鞋袜、雄臭、榨精 | 战队特摄子类（4/8） |

## 二、子类型决策树（输入 → 输出）

### Step 1：识别主语（被调教方）
- **少年英雄 / 战队成员** → 子类型 01 必选
- **反派 / 反派转化者** → 子类型 03 可能
- **兄弟 / 双主角** → 子类型 05 可能

### Step 2：识别反派 / 调教师
- **触手怪人 / 兽人 / 非人反派** → 子类型 08
- **催眠博士 / 淫纹师 / 收藏家** → 子类型 04 + 06
- **师兄 / 学长 / 教官** → 子类型 06 主仆
- **跨作品二创角色** → 子类型 07

### Step 3：识别色情场所
- **训练室 / 巡逻 / 任务地点** → 战队特摄标配
- **公开场合（公园/公交/教室）** → 子类型 01 公共空间变种
- **直播 / 触手椅** → 子类型 04 + 08

### Step 4：识别 XP 焦点
- **紧身战衣激凸 / 龟头/乳头/屁股缝** → 子类型 01 + 04
- **足部 / 雄臭 / 战靴** → 子类型 09
- **触手 / 植入 / 控制芯片** → 子类型 08
- **反讽 / 喜感反应** → 子类型 02

### Step 5：输出多选结果
**战队特摄 8 部实读结果**（8 部子批次全部 100% 读）：
- 4.1 高弹紧身衣战士白曜：01 + 03 + 05 + 07 + 08（5 个子类型）
- 4.2 超级战队收集计划：01 + 04 + 05 + 06 + 07 + 08（6 个）
- 4.3 超级战士：01 + 02 + 04 + 06 + 08（5 个）
- 4.4 裆能战记系列：01 + 02 + 03 + 04 + 05 + 06 + 07 + 08（8 个，最多）
- 5.1 龙骧战队二创：01 + 04 + 05 + 06 + 08 + 09（6 个）
- 5.2 天装战队护星红：01 + 03 + 04 + 06 + 08（5 个）
- 5.3 超星战队日常：01 + 04 + 05 + 08 + 09（5 个）
- 5.4 超能战队 kk版：01 + 04 + 05 + 06 + 09（5 个）

## 三、子类型组合规则

### 可共存
- **01 战队 + 04 调教**：标配
- **01 战队 + 08 触手**：标配
- **04 调教 + 06 主仆**：标配
- **05 兄弟 + 09 足控**：标配
- **07 同人 + 任何**：可叠加
- **02 喜剧 + 任何**：可叠加

### 冲突 / 罕见
- **03 反派 + 06 主仆**：反派同时为主仆，矛盾（仅 4.4 裆能战记有"反派作为工具人"特例）
- **09 足控 + 04 调教**：非标配但可融合（4.1 高弹 凌夜用脚 + 04 调教）

### 多选上限
- 实战显示最多 8 个子类型（4.4 裆能战记）
- 平均 5-6 个子类型 / 部
- 建议新作品控制在 3-6 个子类型（避免主题发散）

---

## 四、应用步骤

1. **读世界书**：识别角色 / 反派 / 场所 / XP 焦点
2. **走决策树**：按 Step 1-4 判定候选子类型
3. **查冲突表**：剔除冲突子类型
4. **查上限**：控制在 3-6 个
5. **输出子类型多选结果**：写入 `body_data_card.subtypes` 字段
