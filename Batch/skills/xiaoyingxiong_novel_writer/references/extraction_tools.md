## 一、功能类别

| # | 功能类别 | 作用 | 出现的子类型 |
|---|:---|---|---|
| 1 | **刺激类** | 物理刺激敏感点 | 战队 / 调教 |

## 二、具体道具

### 1. 飞机杯
- **代表**：5.1 龙骧战队（#4 怪人破解 + 飞机杯二人组互相交配）、5.4 超能战队 kk（飞机杯化）
- **描述模板**：「[飞机杯]套在[主角]的[阴茎]上，[自动/遥控]进行[抽插/挤压/震动]，反派通过[摄像头/直播]监控[主角]的反应」
- **所属功能类别**：刺激类
- **XP 命中**：道具化 + 被物化 + 互相交配镜像
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #257 飞机杯二人组、#277 飞机杯互相交配、#282 001 号贱狗

### 2. 电鞭
- **代表**：4.4 裱能战记（电激魔人的电鞭茧房）
- **描述模板**：「[电鞭]从[反派]手中甩出，[鞭打/电击][主角]的[身体/足底/裆部/乳头]，[麻痹/刺激/痛苦]与[快感]同时产生」
- **所属功能类别**：刺激类
- **XP 命中**：电击 + 茧房拘束 + 痛苦与快感
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #308 博士的回忆（电击）

### 3. 恶念增幅器
- **代表**：4.4 裱能战记（李虎吃下"恶念增幅器"被改造为螳螂怪人）
- **描述模板**：「[恶念增幅器]被[主角/反派]服下后，[性癖/攻击欲/屈服度]被[放大/扭曲/改造]，身体开始[异化/增生/肉棒化]」
- **所属功能类别**：刺激类
- **XP 命中**：药物改造 + 肉棒化 + 怪人化
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #308 李虎吃下恶念增幅器被改造为螳螂怪人

### 4. 反精神耳机
- **代表**：5.1 龙骧战队（#1 手机拍照 + 反精神耳机 + 赋予物品能力三件套）
- **描述模板**：「[反精神耳机]戴在[主角]头上，[阻断/篡改/改写][主角]的[思维/记忆/常识]，让[主角]主动接受[调教/堕落/屈服]」
- **所属功能类别**：刺激类（精神刺激）
- **XP 命中**：精神控制 + 常识改写 + 主动堕落
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #254 手机拍照+反精神耳机+赋予物品能力三件套

### 5. 痒纹
- **代表**：5.1 龙骧战队（#1 射精篮球赛：累加道具）
- **描述模板**：「[痒纹]刻在[主角]的[皮肤/足底/腋下/裆部]，[持续/定时]产生[痒感/刺痛/快感]，让[主角]在[公共/战斗]中[失态/射精]」
- **所属功能类别**：刺激类
- **XP 命中**：痒感 + 公共暴露 + 累加道具
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #274 射精篮球赛（痒纹）

### 6. 控制芯片
- **代表**：4.1 高弹紧身衣（控制芯片）、4.2 超级战队收集（控制芯片）、5.1 龙骧战队（控制芯片 + VR 头盔）
- **描述模板**：「[控制芯片]植入[主角]的[后颈/心脏/裆部]，反派可远程[电击/束缚/控制]。芯片带有[人格编号/触发词/远程改写]功能」
- **所属功能类别**：植入类
- **XP 命中**：植入 + 远程控制 + 反派控制 + 触发词控制
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #256 控制芯片、#266 控制芯片→远程改写行为/思维

### 7. 淫纹印记
- **代表**：4.2 超级战队收集（5 阶段堕落循环第 4 阶段紧身衣仪式化）、5.1 龙骧战队（#4 控制淫纹 / 物理铭刻）
- **描述模板**：「[淫纹/印记]刻在[主角]的[后颈/手背/裆部/大腿内侧]，代表[反派所属/控制权/被触发时的快感]。纹路[发光/发热/蠕动]时自动触发[快感/服从/改造]」
- **所属功能类别**：植入类
- **XP 命中**：所属化 + 长期性癖 + 物理铭刻 + 无法破解
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #266 控制淫纹（物理铭刻，附加【真实】无法破解）

### 8. VR/AR 头盔
- **代表**：5.1 龙骧战队（#6 VR 黑客入侵式调教）、5.4 超能战队 kk（VR 黑客）
- **描述模板**：「[VR/AR 头盔]戴上后[主角]进入[虚拟世界/游戏副本/梦境]，现实中身体被[反派/榨精魔物]接管，[6h/12h/24h]不间断执行[产精任务/战斗任务/调教任务]」
- **所属功能类别**：科技类
- **XP 命中**：VR 入侵 + 意识接管 + 身体被剥夺
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #259 VR 黑客入侵式调教、#279 边玩游戏边擦桌子

### 9. 半成品游戏头盔
- **代表**：5.1 龙骧战队（#6 半成品游戏头盔 + 蜃煌赋予【超现实修改】+【完全掌控】特性）
- **描述模板**：「[半成品游戏头盔]被[反派/蜃煌]赋予[超现实修改/完全掌控]特性后，[主角]在[游戏世界]中[战斗/产精]，现实中[身体/意识]被[彻底接管/改造]」
- **所属功能类别**：科技类
- **XP 命中**：半成品 + 超现实修改 + 完全掌控 + 产精任务
- **来源**：`pixiv_深度阅读笔记_01_战队特摄.md` #259 半成品游戏头盔+【超现实修改】+【完全掌控】
