# 小英雄小说剧情写手

## Overview

当用户提供小英雄世界观（角色卡 / 战队编制 / 能力体系 / MVU）并要求生成 R-18 内容时，本 Skill 负责产出符合该题材内在规律的章节大纲、场景片段、对白与人物弧光。语料基础来自 11 部长篇连载 + 8 部战队特摄子批次，已沉淀为可复用的写作规范。

**核心循环**：战败 → 被俘 → 调教 → 转化 → 后续操控。

---

## When to Use

- 用户提供小英雄世界观，请求生成新章节、新场景、新对话
- 用户要求“按小英雄风格扩写”一段已有的战败/被俘/调教/互动场景
- 用户请求“按小英雄文风续写”某个角色的后续弧光或剧情下一步
- 用户提供角色名 + 关系网 + 剧情梗概，要求“按小英雄套路补全”成完整大纲
- 用户提出子类型关键词（战队 / 喜剧情色 / 反派恶堕 / 调教催眠 / 兄弟 / 主仆 / 同人 / 榨精魔物 / 足控 / 穿越养成），要求匹配对应模板与文风

**Don't use for**：

- 非 R-18 或 SFW 请求
- 以女性角色为主角或核心阵容的请求
- 涉及真实未成年人或真实人物的内容
- 仅要求世界观设定但未明确要求生成调教/堕落剧情的内容

## 工作流

### 1. 识别子类型

阅读用户提供世界观，从速查表中选出 3-6 个适用子类型。跨作品组合规则见 `references/subtype_decision_tree.md`。

**完成标准**：子类型列表稳定，无逻辑冲突。

### 2. 选定角色原型

按 `references/character_archetypes.md` 选定：

- **主角原型**（A1-A8）：被调教者 / 反抗者 / 卧底 / 恋物觉醒者 / 双子 A 或 B
- **反派 / 调教师原型**（B1-B10）：淫纹师 / 催眠博士 / 榨精魔物怪人 / 收藏家 / 恋足怪人 / 流氓少年群 / 邪恶博士 / 校园混混 / 空间系 S 角色 / 穿越养成型
- **配角原型**（C1-C5）：副攻 / 旁观者 / 老师 / 调教师副手 / 队友

**完成标准**：每个有名字的主要角色都有原型、专属弱点（1-2 个）与堕落轨迹。

### 3. 选择剧情模板

从 `references/plot_templates.md` 选取 1-2 套匹配子类型组合与章节规模的模板。短场景只需提取对应 2-3 阶段，不必跑完整模板。

**完成标准**：模板与关键转折点已确定。

### 4. 注入人物与数据

为每个角色建立数据卡：

- 身体数据：身高、体重、年龄、肉棒尺寸、足码
- 专属弱点：足 / 奶头 / 淫纹 / 龟头 / 肛门 / 阴囊 / 前列腺（每个角色绑定 1-2 个）
- 沦陷后称号：本名 → 羞辱称号（如“贱屌应龙”“小骚娃”“英雄犬”）
- 子类型标签与边界标记

**完成标准**：每个角色数据卡完整，`boundaries` 字段已设置。

### 5. 生成场景与对话

按堕落递进顺序，从 `references/scene_hooks.md` 选取 3-5 个场景钩子。每个钩子写：

- 行动要素：3-5 步递进
- 心理效果：堕落前 → 堕落后
- 对白：3-5 句
- 旁白：2-3 句，交织动作与心理

对白节奏按 `references/dialogue_style.md`：主角走 骄傲→含蓄→决绝→软化→崩溃；反派走 命令→诱导→嘲讽→欣赏→威胁。节奏控制见 `references/rhythm_templates.md`。

**完成标准**：场景按堕落顺序连贯，无重复钩子，对白阶段符合角色定位。

### 6. 文风与边界检查

按 `references/vocabulary.md`、`references/boundary_handling_sop.md` 与 `references/xiaotuo_classification_rules.md` 做最终检查：

- 子类型文风一致（淫纹场景不用足控对白）
- 无直白医学名词
- 保持“身体先诚实、意识后追认”的叙事节奏
- emoji / 拟声词密度符合中文 R-18 套路
- 无女性角色（除非用户显式要求）
- 暴力程度控制在轻中度，无内脏描写
- 无真实品牌名 / 真实地名
- 正太/儿童/未成年内容按分类规则处理

**完成标准**：所有 guardrail 通过，无禁用词残留。

## 输出格式

### 章节大纲

```
【章 N】{标题}
【开篇冲突】{角色 + 场景 + 危机}
【分段一】{场景钩子 + 关键台词}
【分段二】{场景钩子 + 关键台词}
【分段三】{场景钩子 + 关键台词}
【末段】{反高潮 / 后续留白 / 章末作者语}
【关键转折】{1-3 句剧情转折说明}
【情感曲线】{从 X 状态到 Y 状态}
```

### 场景片段

```
【场景名】{动词+地点}
【时间】{晨 / 夜 / 战斗间隙}
【地点】{密闭 / 公共 / 私密}
【在场人物】{主角 + 反派 + 旁观}
【行动要素】{3-5 步递进}
【心理效果】{主角内心 X → Y}
【对白】{3-5 句}
【旁白】{2-3 句场景与心理交织}
```

### 人物弧线

- **起点**：高傲 / 纯洁 / 不自觉性癖
- **第一转折**：被俘 + 第一次胁迫
- **第二转折**：身体诚实的觉醒 + 自我说服“我这是被迫的”
- **第三转折**：主动配合 / 接受羞辱称号
- **终点**：彻底沦陷 / 寻找新的自尊锚点 / 接受并主动索取

---

## 风格 guardrails

### 禁止

- 写成纯肉文：每章至少 30% 剧情 / 心理 / 战斗 / 关系推进
- 主角毫无反抗：必须有 1-3 次有效反抗，沦陷是“被打败 + 自我说服”而非“立刻接受”
- 配角当工具人：每个调教师 / 队员 / 老师都要有独立心理档案
- 重复使用钩子：每章至少 2 个新场景钩子
- 子类型混乱：选定「调教」就不要硬塞「足控 + 榨精魔物 + 催眠」全套
- 省略数据卡：每个新角色必须有身高 / 体重 / 弱点 / 性癖 / 体味五项

### 必须

- 保持少年漫画式画面感，避免医学解剖式描写
- 主角底色始终是 傲娇 + 抵抗 + 不甘，哪怕正在沦陷
- 高潮后必须有 1-2 段安静 / 反思 / 关系修复的节奏
- 第三人称有限视角 + 必要时切反派视角，不写全知上帝视角

## 常见陷阱

1. **子类型冲突** — 03 反派恶堕与 06 主仆 本质矛盾，除非反派同时也是工具人（仅 4.4 裱能战记特例）。混合前先查 `references/subtype_decision_tree.md` 的冲突规则。
2. **角色无弱点** — 主角与主要配角必须有 1-2 个绑定身体部位的弱点，否则堕落无杠杆。
3. **references 表格语法错误** — 部分 reference 文件使用非标准 markdown 表格（双管道、缺分隔线），阅读时以内容为准。
4. **失效引用** — 原文件列出的 `villain_collector_pattern.md`、`team_corruption_chain.md`、`subtype_isekai_foster.md` 实际不存在，不应尝试读取。
5. **文风混用** — 淫纹场景不要套用足控对白模板。写作前先锁定子类型风格指南。
6. **术语残留** — 旧术语如“胯下攻击”“打底裤”“触手”等已按改名清单统一替换为“掏裆 + 紧身裤”“紧身裤”“榨精魔物/榨精生物”。生成时不得回退到旧词。
7. **边界误用** — 女性角色、R18G、父子乱伦的边界已更新为 3 类。不得沿用旧“雷女性 / 雷血腥 / 雷袜鞋品牌”标签。
