# 人物原型库（Character Archetypes）

> 本文档提炼自 11 部"小英雄"题材 R-18 长篇连载的跨作品共性模式。每个原型包含：身份、性格特征、典型台词（3 句）、心理弧线、在剧情中的功能。文末附"如何选择原型"的决策树。

---

## A. 主角原型（被调教方 / 视角人物）

### A1. 傲娇英雄型（"应龙"系）

- **身份**：战队队长 / 副队 / 王牌；战斗力强；常为火系 / 雷系 / 时空系等"耀眼"系能力
- **性格特征**：表面高傲、自尊心极强、嘴硬；对队友保护欲强；战斗时冷静，私下却可能有不自觉的性癖
- **典型台词**：
  1. "才、才没有……你、你看错了！"
  2. "就算你……我也不会……唔……！"
  3. "哥哥……你在哪……❤️"
- **心理弧线**：「高傲 → 反抗 → 被俘 → 身体觉醒 → 自我说服 → 主动配合 → 沦陷后寻找新的自尊锚点（如保护队友）」
- **剧情功能**：作为队内的"最强 = 最惨"反讽载体；沦陷过程承载"最强也救不了自己"的核心戏剧张力

### A2. 软萌辅助型（"蓝莲"系）

- **身份**：副队 / 辅助型 / 治愈系 / 法系；常为蓝 / 银 / 白发；技能以支援 / 治愈 / 感知为主
- **性格特征**：温柔体贴、善解人意、常为队内"心理支柱"；被俘时倾向于"自保性服从"
- **典型台词**：
  1. "你……你不会真的……？"
  2. "好、好吧……你轻一点……"
  3. "……只要你不伤害他们……我什么都可以……"
- **心理弧线**：「温顺 → 警觉 → 自我牺牲式妥协 → 彻底沦陷 → 自愿留下保护他人」
- **剧情功能**：作为队内"心理减压阀"；沦陷过程承担"为他人牺牲"的核心情感冲突

### A3. 卧底型 / 假戏真做型（"凯风"系）

- **身份**：潜入敌营 / 反派内部成员 / 双重间谍；常为银发琥珀眼 / 狼耳 / 凤眼等"非主流"美学形象
- **性格特征**：表面驯服、内心算计；擅长演戏；自我定位"我不会被影响"；常因自负而陷落
- **典型台词**：
  1. "这不过是伪装……我才不会……"
  2. "等、等等……这跟说好的不一样……！"
  3. "……我好像……回不去了……"
- **心理弧线**：「伪装 → 自我怀疑 → 身体先沦陷 → 心理崩溃 → 接受并寻找新定位」
- **剧情功能**：作为"反派也有脆弱一面"的对照；提供"以为自己是猎人实际是猎物"的核心反转

### A4. 双子 / 兄弟 A（"则星"系）

- **身份**：双胞胎中的哥哥；剑 / 刀 / 物理近战；保护者角色
- **性格特征**：勇敢坚韧、外冷内热、把"保护弟弟"当作生命意义；自身有软嫩等"反差"特征
- **典型台词**：
  1. "弟弟别怕……哥哥在。"
  2. "唔……你、你想对弟弟做什么！"
  3. "我、我会保护你……就算……唔……"
- **心理弧线**：「保护者 → 被剥夺保护能力 → 目睹弟弟受辱 → 自责式自我牺牲 → 兄弟共沦陷」
- **剧情功能**：作为"英雄 + 普通人"双视角的载体；提供兄弟羁绊 + 兄弟共沦陷的核心情感线

### A5. 双子 / 兄弟 B（"则空"系）

- **身份**：双胞胎中的弟弟；法杖 / 治愈 / 幻术；常为辅助 / 后排
- **性格特征**：聪慧机敏、外柔内刚；表面顺从实则掌控信息差；可能有"被保护者"+"暗中观察者"双重身份
- **典型台词**：
  1. "哥哥……我没事的……真的……"
  2. "你、你别碰我哥哥……！"
  3. "……我全都听到了……"
- **心理弧线**：「被保护者 → 信息掌握者 → 反向保护哥哥 → 兄弟共沦陷时维持最后尊严」
- **剧情功能**：作为"看似弱实则强"的角色镜像；提供"信息差 + 反转"的核心叙事钩子

### A6. 直男变弯型（"启润"系）

- **身份**：校园英雄 / 校队 / 普通少年；常为跆拳道 / 篮球 / 足球等体育系
- **性格特征**：自认直男、有女朋友、咸鱼；内心深处有"被同性吸引"的萌芽而不自知
- **典型台词**：
  1. "我、我不是同性恋……！"
  2. "这、这不算……我、我只是……唔……"
  3. "对不起……我是直男……但、但是……"
- **心理弧线**：「直男自觉 → 否认 → 接受同性亲密 → 接受同性吸引 → 接受自己是 bi / 弯」
- **剧情功能**：作为"自我认知崩塌"的核心载体；提供"先女装 / 再少年感"的心理滑坡节奏

### A7. 恋物觉醒型（"小英雄零决"系）

- **身份**：小学生英雄 / 年龄最小；常为白袜 / 校服 / 童真形象
- **性格特征**：自尊心强、战斗状态冷峻、日常生活中有"不自觉性癖"（白袜 / 足）
- **典型台词**：
  1. "你零爷爷还能留你小命……！"
  2. "这、这是战斗损伤……不是、不是那样……"
  3. "我、我没有……才没有喜欢……呜……"
- **心理弧线**：「战斗天才 → 受伤后性癖暴露 → 自我说服"这是战斗副作用" → 接受性癖"
- **剧情功能**：作为"战斗 + 日常反差"的核心载体；提供"小大人 + 真小孩"的双面性

### A8. 反英雄型（"乐澄"系）

- **身份**：穿书者 / 复仇者 / 失去光环的昔日英雄；常为孤僻、阴郁、自毁倾向
- **性格特征**：表面冷漠、内心创伤深；把"拯救世界"视为赎罪或自我毁灭的手段
- **典型台词**：
  1. "反正我死了也没人在乎……"
  2. "你、你要做什么……不、不要……"
  3. "……好温暖……原来……"
- **心理弧线**：「自毁倾向 → 被俘后被强制给予温暖 → 心理防线崩塌 → 接受"被爱"的可能性」
- **剧情功能**：作为"严肃题材"的核心载体；提供"创伤 + 治愈"的双层情感结构

## B. 反派 / 调教师原型

### B1. 温柔大哥哥型（"健身房教练"系）

- **身份**：成年男性 / 专业身份（教练 / 老师 / 医生 / 按摩师）
- **性格特征**：表面温和、专业、有耐心；用身体知识 / 心理洞察缓慢打开少年心防
- **典型台词**：
  1. "别紧张……我是专业的。"
  2. "你这样紧绷会受伤的……放松……"
  3. "你看……这不就是身体想要的吗？"
- **调教模式**：「专业知识 → 身体接触 → 心理松动 → 自我说服 → 主动配合」
- **剧情功能**：作为"非暴力型"调教师；提供"温柔陷阱"的核心叙事钩

### B2. 淫纹师 / 印记师（"龙骧"系）

- **身份**：神秘纹术师 / 古代传承者 / 拥有"淫纹"植入能力
- **性格特征**：冷静、学者气质、把"调教"视为"研究"；对不同少年的反应做笔记
- **典型台词**：
  1. "你的淫纹位置……应该在这里。"
  2. "让我记录一下你的反应……"
  3. "这枚纹是给你哥哥的礼物……"
- **调教模式**：「植入纹 → 观察反应 → 调整位置 → 强化触发条件 → 让被植入者主动展示」
- **剧情功能**：作为"非物理改造"调教师；提供"符号化所属"的核心叙事

### B3. 催眠博士 / 洗脑师（"进化之路"系）

- **身份**：邪恶博士 / 心理学家 / 神经科学家；常配白大褂 + 实验室
- **性格特征**：理性、实验化、把被调教者当"研究对象"；用 HIP-HOP 节奏感强的"催眠式改写"话术
- **典型台词**：
  1. "现在，请把'屌大精浓的骚货'这个词念十遍。"
  2. "你的常识正在被改写……接受它。"
  3. "实验数据很完美……可以进入下一阶段了。"
- **调教模式**：「意识层植入 → 反复念诵 → 自我说服 → 常识改写 → 主动执行」
- **剧情功能**：作为"意识改造"调教师；提供"催眠话术"的核心对话模板

### B4. 榨精魔物怪人 / 非人反派（"光莲红莲"系）

- **身份**：榨精魔物怪人 / 异世界生物 / 改造怪人；常为非人物种
- **性格特征**：机械化重复动作、会说人话但语气非人；把少年当成"实验材料"
- **典型台词**：
  1. "……你将成为我们的……容器。"
  2. "……这才是英雄该有的样子。"
  3. "……你的精源很纯净……可以多产一些。"
- **调教模式**：「捕获 → 催眠气息 → 榨精魔物缠绕 → 物理改造 → 反复榨取」
- **剧情功能**：作为"非人反派"调教师；提供"机械 + 榨精魔物"的核心视觉锤

### B5. 收藏家 / 主人型（"帝王天火"系）

- **身份**：成年 / 收藏家 / 主人；拥有"藏品"陈列室
- **性格特征**：审美化、艺术化、把少年英雄视为"收藏品"；用编号 / 称号标注藏品
- **典型台词**：
  1. "你是第 17 号藏品……编号 L-09-17。"
  2. "乖……让主人好好看看你。"
  3. "今天要展览……你要乖乖跟着。"
- **调教模式**：「捕获 → 编号 → 调教 → 展示 → 收藏」
- **剧情功能**：作为"美学化"调教师；提供"收藏家"的核心叙事母题

### B6. 恋足怪人 / 足控反派（"黓月 / 黯月"系）

- **身份**：恋足癖反派 / 足控施虐者 / 收藏鞋袜
- **性格特征**：对少年的脚 / 袜 / 鞋有病态执着；用足部作为主要施虐 / 恋物焦点
- **典型台词**：
  1. "……这双袜子……我要收藏。"
  2. "踩在我脸上……这样才乖。"
  3. "你的脚心好软……让我再舔一次。"
- **调教模式**：「脱鞋袜 → 脚底接触 → 强迫自慰 / 舔脚 → 恋物成瘾」
- **剧情功能**：作为"恋物型"调教师；提供"足 / 袜 / 鞋"的核心感官钩

### B7. 流氓少年群 / 不良少年（"阿雷四人组"系）

- **身份**：街头少年 / 校园混混 / 失学青少年；4-5 人组
- **性格特征**：粗野、嘲弄、群体行动；用"小骚娃""奶臭小鬼"等称号羞辱
- **典型台词**：
  1. "哟，奶臭小鬼，醒啦？"
  2. "英雄就这点能耐？"
  3. "乖，给爷舔干净。"
- **调教模式**：「群体围观 → 言语羞辱 → 强迫全裸 → 轮番玩弄 → 公开凌辱」
- **剧情功能**：作为"群体暴力"调教师；提供"社会底层"视角

### B8. 空间系 / 时间系 S 角色（"敏寒之"系）

- **身份**：拥有空间 / 时间 / 法则能力的成年强者；常为西装皮鞋 / 家族长子
- **性格特征**：冷漠、克制、童年创伤导致性癖扭曲；用"绝对力量"压制
- **典型台词**：
  1. "……别动。你动不了。"
  2. "这是你的专属宠物……肉便器标本。"
  3. "……给我当一天哥哥……就一天……"
- **调教模式**：「空间凝固 → 强制侵犯 → 心灵击溃 → 请求羁绊 → 反派洗白」
- **剧情功能**：作为"强大但脆弱"调教师；提供"反派洗白"的核心叙事钩

### B9. 穿越养成型反派 / 普通人戏耍超英（"苏贺"系）

- **身份**：穿越者 / 普通人 / 无超能力但掌握"前世记忆"+生物科技公司+春药库+贞操锁生产链
- **性格特征**：冷静算计、长期布局、把"养成英雄性癖"当作终极目标；表面温和实际是终极施虐者
- **典型台词**：
  1. "听说你们超级战士的能量都集中在这儿……"
  2. "那是不是可以认为这两颗能源核心就是你们的弱点……"
  3. "……等将来他真正觉醒，成为那只威风凛凛的白虎战士时，也会忍不住想起今晚……"
- **调教模式**：「穿越者视角 → 提前布局 → 春药/资金/情报碾压 → 隐性性癖种下 → 养成收尾」
- **剧情功能**：作为"反差权威"调教师；提供"普通人戏耍超英"的核心叙事母题；长期潜意识烙印

### B10. 喜剧情色型反派 / 被逗乐后主动加入（"光莲博士"系）

- **身份**：邪恶博士 / 怪人 / 本应是严肃反派；因战士们的"喜感反应"而破功
- **性格特征**：本应冷酷理性，却被英雄们的笨拙/怕痒反应逗笑；最终主动加入调教行列
- **典型台词**：
  1. "哈哈哈哈……你们……你们真是太有趣了……"
  2. "我本来是来抓你们的……但你们……"
  3. "好吧……让我加入你们……这太有意思了……"
- **调教模式**：「初次交锋 → 被喜感反应逗乐 → 理性崩溃 → 主动加入 → 喜剧情色高潮」
- **剧情功能**：作为"非典型反派"；提供"喜剧情色"的核心叙事转折

## C. 配角原型（副攻 / 旁观 / 老师 / 知情者）

### C1. 副攻型（"镇国队长云轩"系）

- **身份**：队长 / 总攻 / 主人公的"对应面"；常为黑发红瞳 / 腹黑
- **性格特征**：表面稳重、内心计算；对队员有占有欲但表达克制
- **典型台词**：
  1. "……别急，你是我的。"
  2. "嗯……乖……再叫一声。"
  3. "今天……就到这里。"
- **剧情功能**：作为"调教师 vs 情人"双重身份；提供"队员的暗恋对象"+"真正的救赎者"

### C2. 旁观者 / 知情者（"邓毅"系）

- **身份**：队友 / 朋友 / 旁观全程但不参与的清醒者
- **性格特征**：直男 / 清醒 / 旁观 / 知道但不能说
- **典型台词**：
  1. "你、你怎么变成这样了……"
  2. "我不能说……因为……"
  3. "我……我应该救你吗……"
- **剧情功能**：作为"读者代入视角"；提供"悲剧性清醒者"的核心叙事张力

### C3. 老师 / 教练 / 长辈（"志铭博士"系）

- **身份**：导师 / 训练师 / 心理辅导师；常为白大褂 / 年轻 + 闷骚
- **性格特征**：关怀型但有自己的秘密；与主角有"半师半友"关系
- **典型台词**：
  1. "……你的训练……还没完成。"
  2. "你、你怎么变成这样了……"
  3. "我可以……帮你……但你得听我的。"
- **剧情功能**：作为"关怀型引诱者"；提供"信任崩塌"的核心情感线

### C4. 调教师副手 / 旁观反派（"威尔玛少校"系）

- **身份**：主调教师的副手 / 负责物理调教 / 配合科学调教
- **性格特征**：执行命令、不带感情；用"编号"称呼被调教者
- **典型台词**：
  1. "这是今天的实验对象 L-09-17。"
  2. "张嘴。"
  3. "……今天的任务是 10 次。"
- **剧情功能**：作为"主调教师的物理执行者"；提供"双反派权力分配"的核心叙事结构

### C5. 队友 / 副线主角（"陆凌光"系）

- **身份**：副线主角 / 暗恋对象 / 与主角有情感羁绊
- **性格特征**：独立成章、有自己的弱点、与主角的沦陷形成对照
- **典型台词**：
  1. "你……你怎么会……"
  2. "我、我不会让你一个人……"
  3. "……请让我……一起……"
- **剧情功能**：作为"主角沦陷后的情感锚点"；提供"双主角共沦陷"的核心叙事线

## D. 决策树：如何选择原型

```
问题 1：用户的世界书主角数量是？
├─ 1 个 → 进入问题 2
└─ 多个（3-7）→ 直接选 A1 傲娇英雄型（队长）+ A2 软萌辅助型（副队）+ A3 卧底型（特殊位）

问题 2：主角年龄是？
├─ 小学（10-12 岁）→ 选 A7 恋物觉醒型 或 A8 反英雄型
├─ 初中（13-15 岁）→ 选 A1 / A2 / A6 直男变弯型
└─ 高中及以上（16+）→ 选 A3 / A4-A5 双子型

问题 3：主角的核心动机是？
├─ 保护他人（队友 / 弟弟）→ 选 A1 / A4
├─ 复仇 / 赎罪 → 选 A8
├─ 探索自身性癖 → 选 A7
├─ 隐瞒卧底身份 → 选 A3
└─ 维持"直男"自我认知 → 选 A6

问题 4：反派 / 调教师数量是？
├─ 1 个 → 进入问题 5
└─ 多个 → 选 B7 流氓少年群 + B1 温柔大哥哥（双反派）

问题 5：调教师的能力是？
├─ 榨精魔物 / 非人 → 选 B4
├─ 淫纹 / 标记 → 选 B2
```
