## 三、XP 模式详细描述（TOP 10 精选）

### 1. 紧身战衣激凸
- **触发场景**：战衣穿脱 / 战斗 / 训练 / 公开场合
- **描述模板**：「战衣完美贴合[乳头/龟头/屁股缝/大腿内侧]，战斗时[激凸/湿润/勃起]」
- **命中概率**：100%（战队特摄标配）
- **加分项**：战衣破裂（物理破坏）/ 战衣光点消散（能量耗尽）双解除模式

### 2. 反派恶堕 / 控制芯片
- **触发场景**：反派登场 / 主角被俘 / 章节高潮
- **描述模板**：「反派将[控制芯片/贞操锁]植入[主角]的[后颈/裆部/心脏]」
- **命中概率**：63%（5/8 作品）
- **加分项**：芯片 + 直播控制（反派实时调控）

### 3. 调教 / 催眠系统化
- **触发场景**：5 阶段堕落循环 / 24h 监控
- **描述模板**：「反派通过[欲珠植入/学长渗透/伦理绑架/紧身衣仪式化/锁精三件套]五阶段[主角]」
- **命中概率**：63%
- **加分项**：5 战士堕落互相攻击（滚雪球式）

### 4. 足控 + 四件套
- **触发场景**：足部特写 / 白袜脱下
- **描述模板**：「[主角]的[足底/脚趾]在反派面前[暴露/被舔/被踩]」
- **命中概率**：50%
- **加分项**：四件套（足底 + 脚趾 + 踩踏）

### 5. 榨精魔物椅 / 榨精生物地毯
- **触发场景**：反派科技 / 痒感调教 / 束缚工具
- **描述模板**：「[榨精魔物]将[主角]束缚在[椅子/地毯]上，从[脚底/腋下/腹股沟]释放痒感」
- **命中概率**：50%
- **加分项**：榨精魔物 = 多功能工具（束缚 + 痒感 + 注入 + 直播）

### 6. 直播经济 / 投币
- **触发场景**：反派经济来源 / 公共空间变种
- **描述模板**：「反派将[主角]的[调教/性化]场景[直播]，观众通过[投币/打赏]影响剧情」
- **命中概率**：38%
- **加分项**：直播 + 榨精魔物椅 + 投币控制（3 重叠加）

### 7. 战衣破裂 vs 光点消散
- **触发场景**：战衣解除 / 战斗结束 / 章节高潮
- **描述模板**：「战衣从[乳头/裆部]开始[破裂/光点消散]，露出[激凸/湿润/勃起]的身体」
- **命中概率**：38%
- **加分项**：双解除模式（物理破坏 vs 能量消散 = 2 种性感来源）

### 8. 兄弟 / 竹马同堕落
- **触发场景**：双主角登场 / 公开场合 / 互相攻击
- **描述模板**：「[兄弟A]和[兄弟B]被反派同时[调教/控制]，最终[同堕落/互相攻击]」
- **命中概率**：50%
- **加分项**：双英雄对称 + 同堕落 = "兄弟情深 + 反差情色"

### 9. 穿越者养成型反派
- **触发场景**：穿越者登场 / 提前布局 / 养成开始
- **描述模板**：「穿越者[反派]提前[布局/养成][主角]，从[儿童期/少年期]开始[控制/性化]」
- **命中概率**：25%
- **加分项**：养成系 + 长期性癖 + 反差权威

### 10. 精液能量守恒
- **触发场景**：榨精 / 战士能量 / 反派获得战衣
- **描述模板**：「反派通过榨取[主角]的[精液/乳汁]，获得[圣兽能量/战衣加持]」
- **命中概率**：25%
- **加分项**：精液 = 战士能量 = 反派战衣的设定统一
