## 二、6 大实战融合模式

### 模式 1：战队 + 调教 + 触手（标配 3 件套）
- **代表作品**：4.1 高弹紧身衣、4.2 超级战队收集、4.3 超级战士、4.4 裆能战记、5.1 龙骧、5.2 天装、5.3 超星、5.4 超能 kk（**8/8 全员**）
- **融合结构**：战队主角 → 触手怪人 / 反派 → 调教工具（触手椅 / 触手地毯 / 触手剃须刀）
- **XP 命中**：紧身衣 + 触手 + 反派 + 调教
- **典型场景**：训练室 / 巡逻 / 任务地点 + 触手反派 + 系统化调教

### 模式 2：战队 + 兄弟 + 同堕落（双英雄对称）
- **代表作品**：4.1 高弹（白曜 + 顾烨皓）、4.2 超级战队收集（5 战士同堕落）、5.1 龙骧（蜃煌 + 哥哥）、5.3 超星（竹马）、5.4 超能 kk（5 战士）
- **融合结构**：双主角 / 多主角 + 同反派 + 同时被俘 + 互相攻击
- **XP 命中**：兄弟 + 双英雄对称 + 同堕落
- **典型场景**：公开场合 / 直播 / 任务地点 + 兄弟同被俘

### 模式 3：战队 + 反派 + 主仆（反派主导型）
- **代表作品**：4.2 超级战队收集（反派幻梦第一人称）、4.4 裆能战记（高司令作为工具人）、5.1 龙骧（反派兄控型）、5.2 天装（养蛊型反派）、5.4 超能 kk（穿越者养成）
- **融合结构**：反派第一人称驱动 + 主仆关系 + 系统化控制
- **XP 命中**：反派恶堕 + 控制芯片 + 贞操锁 + 主仆
- **典型场景**：反派主场（怪人基地 / 直播室 / 调教室）+ 主仆仪式

### 模式 4：战队 + 喜剧 + 喜剧情色（反差情色）
- **代表作品**：4.3 超级战士（怕痒调教）、4.4 裆能战记（jumpuri 投票）
- **融合结构**：喜剧情色 + 反讽套话 + 反派叛变
- **XP 命中**：喜感反应 + 反派被逗乐 + 反派加入
- **典型场景**：怕痒调教 / 等价交换 / 喜剧情色反转

### 模式 5：战队 + 足控（足部特化）
- **代表作品**：5.1 龙骧（蜃煌的脚）、5.3 超星（催情菌魔 + 身体反应反差）、5.4 超能 kk（穿越者足控）
- **融合结构**：足部特化 + 白袜 + 踩踏
- **XP 命中**：足控 + 白袜
- **典型场景**：足部特写 / 白袜脱下

### 模式 6：战队 + 同人 + 二创（跨作品衍生）
- **代表作品**：4.2 超级战队收集（同人化）、5.1 龙骧（二创）、5.3 超星（同人）、5.4 超能 kk（同人）
- **融合结构**：原作角色 + 二创情节 + 同人设定
- **XP 命中**：跨作品关系 + 角色熟悉度
- **典型场景**：原作情节扩展 + 同人化解读

## 三、4.4 裆能战记（极限 8 子类型融合）
- **子类型组合**：01 战队 + 02 喜剧 + 03 反派 + 04 调教 + 05 兄弟 + 06 主仆 + 07 同人 + 08 触手
- **融合结构**：核心世界观 + 多角色 + 多反派 + 跨子段弧光 + 投票分支 + 父子性记忆 + 三代精液闭环
- **XP 命中**：裆能系统 + 精液现形 + jumpuri 投票 + 父子性记忆 + 三代精液闭环 + 烈日变身 + 5 人物线集中引爆
- **核心套路**：12 淫魔谱系 / 4 子段叙事 / 2 种结局（结局 1 + 结局 2）
- **融合特点**：所有子类型都达到"深度融合"而非"浅层叠加"

## 四、子类型冲突 / 协同规则

### 高协同（推荐）
- 01 + 04 + 08：标配三件套
- 04 + 06：调教 + 主仆天然协同
- 05 + 09：兄弟 + 足控天然协同
- 02 + 任何：喜剧可叠加

### 低协同 / 冲突
- 03 + 06：反派 + 主仆矛盾（仅 4.4 裆能战记"反派作为工具人"特例）
- 09 + 04：足控 + 调教非标配但可融合

### 多选上限
- 实战显示最多 8 个子类型（4.4 裆能战记）
- 平均 5-6 个子类型 / 部
- 建议新作品控制在 3-6 个子类型（避免主题发散）

---

## 五、融合应用步骤

1. **识别主类型**（必选 01 战队）
2. **识别 2-3 个核心副类型**（04 调教 + 08 触手 + 06 主仆）
3. **识别 1-2 个特色辅类型**（02 喜剧 / 03 反派 / 05 兄弟 / 09 足控）
4. **查冲突表**（剔除冲突组合）
5. **应用融合模式**（从 6 大模式选 1 个作主线）
6. **填入 `body_data_card.subtypes`**
