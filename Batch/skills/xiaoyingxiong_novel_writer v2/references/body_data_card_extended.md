# 数据卡 8-10 项扩展规范（Body Data Card Extended）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"小英雄"角色数据卡的 8-10 项扩展字段标准（原基础 4 项 + 扩展 6 项）。

---

## 一、数据卡总览

### 基础 4 项（v1 已有）
1. **name**：角色名
2. **subtype**：子类型
3. **role**：主角 / 反派 / 配角
4. **xp_focus**：XP 焦点

### 扩展 6 项（v3 新增）
5. **age**：年龄（精确到岁）
6. **height**：身高（cm）
7. **build**：体型（纤细 / 标准 / 健壮 / 肌肉）
8. **outfit**：战衣 / 制服（颜色 + 样式 + 关键特征）
9. **personality**：性格特征（3-5 个关键词）
10. **arc**：角色弧光（高傲→反抗→被俘→身体觉醒→自我说服→主动配合→沦陷后寻找新自尊锚点）

---

## 二、扩展 6 项详细规范

### 5. age（年龄）
- **类型**：数字（岁）
- **必填**：是
- **取值范围**：14-25（"小英雄"题材典型范围）
- **示例**：
  - 白曜：15 岁
  - 顾烨皓：16 岁
  - 凌夜：18 岁
  - 蜃煌：16 岁
  - 幻梦（反派）：25 岁
  - 苏贺（穿越者）：18 岁外表，30+ 灵魂

### 6. height（身高）
- **类型**：数字（cm）
- **必填**：是
- **取值范围**：160-190
- **示例**：
  - 白曜：180cm（纤细）
  - 蜃煌：175cm（标准）
  - 雷神：185cm（健壮）
  - 银河领主：178cm（标准）

### 7. build（体型）
- **类型**：枚举
- **必填**：是
- **取值**：纤细 / 标准 / 健壮 / 肌肉
- **示例**：
  - 白曜：纤细（180cm + 纤细 = "高瘦纤细"型）
  - 顾烨皓：标准
  - 雷神：肌肉
  - 幻梦：标准（反派）

### 8. outfit（战衣 / 制服）
- **类型**：字符串
- **必填**：是
- **格式**：「颜色 + 样式 + 关键特征」
- **示例**：
  - 白曜：「红色高弹战衣 + 完美贴合乳头/龟头/屁股缝 + 战衣破裂 = 激凸」
  - 银河领主：「蓝银战衣 + 银光闪烁 + 战衣光点消散」
  - 雷神：「黄色战衣 + 雷电纹路 + 触手怕痒地毯」
  - 蜃煌：「绿色战衣 + 兽耳装饰 + 触手束缚」

### 9. personality（性格特征）
- **类型**：关键词数组（3-5 个）
- **必填**：是
- **取值示例**：
  - 白曜：[勇敢, 热血, 略显天真, 保护队友, 反杀时冷酷]
  - 凌夜：[反派, 自负, 心理脆弱, 自我牺牲, 知识型反派]
  - 顾烨皓：[宿敌, 隐忍, 复仇心, 反派化, 工具人]
  - 蜃煌：[反派兄控, 半兽人化, 触手化, 直播, 怕痒]
  - 幻梦：[反派第一人称, 系统化, 收集者, 滚雪球堕落链]

### 10. arc（角色弧光）
- **类型**：字符串
- **必填**：是
- **格式**：「状态1 → 状态2 → ... → 最终状态」
- **典型结构**（7 阶段）：
  1. 高傲（入队 / 登场）
  2. 反抗（遇到反派 / 任务失败）
  3. 被俘（被反派击败 / 落入陷阱）
  4. 身体觉醒（第一次被性化 / 第一次勃起）
  5. 自我说服（"只是任务" / "只是身体"）
  6. 主动配合（开始享受 / 主动堕落）
  7. 沦陷后寻找新自尊锚点（保护队友 / 反杀反派 / 兄弟同堕落）
- **示例**：
  - 白曜：「热血新人 → 反抗凌夜 → 被囚禁 → 身体觉醒 → 自我说服 → 反杀凌夜 → 番外反讽」
  - 凌夜：「无敌反派 → 心理脆弱 → 自我牺牲 → 翻车被反控 → 番外亲口讲解」
  - 蜃煌：「反派登场 → 触手化 → 直播 → 怕痒 → 主动加入」
