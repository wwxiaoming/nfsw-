# 榨精道具库（Extraction Tools）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"榨精 / 调教 / 束缚道具"分类 + 描述模板 + 实战案例。

---

## 一、道具 12 大分类

### 1. 环（贞操锁环 / 阴茎环 / 乳环 / 贞操带）
- **代表**：超能战队 kk（贞操锁 = 能源核心）、超级战队收集（5 战士贞操锁）
- **描述模板**：「[贞操锁环]锁住[主角]的[阴茎/乳头/睾丸]，只有反派可解锁」
- **XP 命中**：贞操锁 + 能源核心 + 长期性癖
- **特殊形态**：贞操锁 = 能源核心（5.4 超能 kk，贞操锁本身提供战衣能量）

### 2. 夹（夹子 / 乳头夹 / 阴蒂夹）
- **代表**：超级战队收集（5 阶段堕落循环第 4 阶段）
- **描述模板**：「[夹子]夹住[主角]的[乳头/阴蒂]，通过[绳子/锁链]与反派控制台连接」
- **XP 命中**：调教 + 控制 + 痛感

### 3. 针（注射器 / 针头 / 催情针）
- **代表**：超级战队收集（欲珠植入）、高弹紧身衣（控制芯片）
- **描述模板**：「[针头]将[欲珠/控制芯片/催情剂]注入[主角]的[后颈/裆部/心脏]」
- **XP 命中**：植入 + 控制芯片 + 反派控制

### 4. 管（玻璃管 / 软管 / 中空管）
- **代表**：超级战队收集（血乳交融中空玻璃管）
- **描述模板**：「[中空玻璃管]连接[主角]的[乳头/阴茎/后庭]，允许[精液/乳汁/血液]流通」
- **XP 命中**：血液交换 + 乳汁交换 + 反派获得圣兽基因

### 5. 杯（精杯 / 集精杯 / 储精杯）
- **代表**：超级战队收集（5 阶段堕落循环第 5 阶段锁精三件套）
- **描述模板**：「[精杯]放在[主角]的[裆部]，反派定时取精用于[战衣进化/反派能量]」
- **XP 命中**：定时榨精 + 精液能量守恒

### 6. 笼（贞操笼 / 阴茎笼 / 拘束笼）
- **代表**：高弹紧身衣（凌夜的暗面体）、超级战队收集
- **描述模板**：「[贞操笼]锁住[主角]的[阴茎]，只有反派解锁」
- **XP 命中**：长期贞操 + 反派控制 + 24h 监控

### 7. 椅（触手椅 / 电椅 / 反派控制椅）
- **代表**：超级战队收集（电椅 + 兄弟精液）、龙骧战队（触手椅 + 直播）
- **描述模板**：「[触手椅/电椅]将[主角]束缚，提供[痒感/电击/控制]」
- **XP 命中**：触手 + 直播 + 多战士同囚

### 8. 床（榨精床 / 调教床 / 实验室床）
- **代表**：超级战队收集（24h 反弹药水健身器材）、高弹紧身衣（#22 懒人沙发）
- **描述模板**：「[榨精床/调教床]上设有[束缚带/榨精器/直播摄像头]」
- **XP 命中**：24h 调教 + 直播 + 反派系统化

### 9. 椅（反派控制椅 / 指挥官椅 / 直播椅）
- **代表**：龙骧战队（直播控制椅）
- **描述模板**：「反派坐在[控制椅]上，通过[触手/锁链/直播]控制[主角]」
- **XP 命中**：反派主场 + 触手控制 + 直播

### 10. 仪（贞操仪 / 控精仪 / 调教仪）
- **代表**：超级战队收集（5 阶段堕落循环第 3 阶段伦理绑架）
- **描述模板**：「[贞操仪]监测[主角]的[勃起/射精/心率]，自动触发[电击/束缚/调教]」
- **XP 命中**：自动控制 + 反派远程操控 + 24h 监控

### 11. 绳（束缚绳 / 龟甲缚 / 悬挂绳）
- **代表**：超级战队收集（5 阶段堕落循环第 2 阶段）
- **描述模板**：「[束缚绳]将[主角]绑成[龟甲缚/后手缚/悬挂]姿势」
- **XP 命中**：束缚 + 调教 + 公开场合

### 12. 链（锁链 / 牵引链 / 控制链）
- **代表**：高弹紧身衣（凌夜与白曜的锁链）、超级战队收集
- **描述模板**：「[锁链]连接[主角]与[反派/控制器]，限制[主角]的行动范围」
- **XP 命中**：牵引 + 调教 + 公开场合

### 13. 胶囊（控制胶囊 / 定时胶囊 / 毒药胶囊）
- **代表**：超级战队收集（5 阶段堕落循环第 1 阶段欲珠植入）
- **描述模板**：「[胶囊]在[主角]的[口腔/后庭/阴茎]内溶解，释放[欲珠/毒药/控制剂]」
- **XP 命中**：植入 + 控制 + 长期性化

### 14. 印记（淫纹 / 烙印 / 控制印记）
- **代表**：超级战队收集（5 阶段堕落循环第 4 阶段紧身衣仪式化）
- **描述模板**：「[淫纹/烙印]刻在[主角]的[后颈/手背/裆部]，代表[反派所属/控制权]」
- **XP 命中**：所属化 + 长期性癖 + 反派控制

### 15. 控制器（控制芯片 / 植入物 / 反派遥控器）
- **代表**：高弹紧身衣（控制芯片）、超级战队收集（贞操锁 + 控制芯片）
- **描述模板**：「[控制芯片]植入[主角]的[后颈/心脏/裆部]，反派可远程[电击/束缚/控制]」
- **XP 命中**：植入 + 远程控制 + 反派控制

## 二、道具交叉组合

### 椅 + 链 + 锁
- **代表**：龙骧战队（触手椅 + 锁链 + 贞操锁）
- **应用**：多武器组合 + 直播控制

### 床 + 杯 + 仪
- **代表**：超级战队收集（24h 调教床 + 精杯 + 贞操仪）
- **应用**：24h 系统化调教

### 环 + 笼 + 芯片
- **代表**：超能战队 kk（贞操锁环 + 贞操笼 + 控制芯片 = 能源核心）
- **应用**：贞操锁 = 能源核心

### 印记 + 胶囊 + 注射
- **代表**：超级战队收集（淫纹印记 + 欲珠胶囊 + 注射）
- **应用**：5 阶段堕落循环

### 触手椅 + 直播椅 + 触手控制
- **代表**：龙骧战队
- **应用**：触手 + 直播 + 反派主场

## 三、道具描述模板（按功能）

| 功能 | 道具 | 描述模板 |
|---|---|---|
| 束缚 | 椅 / 床 / 绳 / 链 | 「[主角]被束缚在[椅/床]上，通过[绳/链]与[反派]连接」 |
| 榨精 | 杯 / 环 / 笼 / 仪 | 「[精杯/贞操环]收集[主角]的[精液]，反派定时取精」 |
| 植入 | 针 / 胶囊 / 印记 / 芯片 | 「[针头/胶囊/印记/芯片]植入[主角]的[部位]，反派可远程控制」 |
| 监控 | 仪 / 摄像头 / 直播椅 | 「[贞操仪/摄像头]监测[主角]的[勃起/射精/心率]，自动触发[电击/束缚]」 |
| 调教 | 触手椅 / 触手地毯 / 反派控制椅 | 「[触手/反派]通过[椅/地毯]对[主角]进行[痒感/电击/调教]」 |
| 控制 | 芯片 / 锁链 / 反派控制 | 「[控制芯片/锁链]限制[主角]的[行动/思想/性化]」 |
