### 作品定位

**同人 / 战队 / R-18G / 反英雄重生 / 父子宿敌 / 精神与身体双重崩坏**

极重度黑暗向超级战队（Super Sentai Style）同人。作者 **Shen an**，以"护星天使"为宇宙公理（光之力 → 5 人天装战队），构建了一个**对"英雄"概念最彻底的解构与复仇**——把"父子两代如何被同一群敌人从精神到肉体彻底打碎、改造、再驯化"这条主线，撕给读者看。

Pixiv 8 章 199.9KB，2025-08~09 连续更新，喜欢数从 170（第 1 章峰值）一路下滑到 26（终章）。这条喜欢曲线本身就是一个**信号**——读者黏性靠的不是情节推进，而是"看父/子被摧毁的刺激"逐章递减；终章"新征程"作者把视角切到伊甸星，实际上是一次 IP 转移/重启。

**目标读者**：
- 战队控 + 紧身衣爱好者
- 重度 R-18G（性暴力 / 阉割 / 兽化 / 调教）爱好者
- 反派视角爱好者（"如果英雄被养成了敌人的狗"）

**XP 命中清单**（按强度）：
- **第一优先**：紧身衣战队（红色/红白战衣 → 几乎每个章节都把战衣"贴出性器轮廓"当视觉锚点）、英雄败北、被俘调教
- **第二优先**：父子同款宿命（父被割 JJ → 子被性侵十年）、复仇者变施暴者（赤救父、却为"变强"投奔杀父仇人）
- **第三优先**：榨精（巨量射精打湿战衣被公开展示）、战衣合身描边（胯下"羞耻"挺立）、反派主导（"爸爸"是强奸犯）

### 关键章节（按叙事功能选 6 个）

- **#1 天装战队的末日（24.5KB）**：开篇双重毁灭——天装 5 人被公开处刑（电击+当众榨精+被阉），地球被"天罚"主炮气化。然后揭示：总统在凌小宇面前强迫他改口叫"爸爸"、并第一次性侵 8 岁幼童。**这是整部作品的"道德锚"——比这更过分的章节都是它的逻辑延伸**。
- **#2 新的生活（13.6KB）**：10 年时间跳跃。18 岁的赤（凌小宇）被养在残虐军团里，每天被"爸爸"总统性侵。紧身训练服 + 性刺激 + 身体已经形成肌肉记忆（被抚摸就会自动硬）——**"调教成功"的身体被作为战力配件的隐喻**。
- **#3 工具英雄（19.5KB）**：博士登场 → 用"贴生物传感器"性骚扰赤 → 塞进菊花作指检 → 给予"天装核心"作为交换。赤的第一次变身：红白相间战衣 + 嘲讽式天使翅膀头盔。变身后第一次敢对博士说"滚开"。
- **#4 博士的回忆（45.4KB）**：**全作最长的回溯章节**。10 年前博士抓凌云 7 天 7 夜的"实验"全过程（电击、探针、强制高潮至失禁、在人前露出）。同时给出凌云的变身起源（小巷被打时收到变身器）以及李虎吃下"恶念增幅器"被改造为怪人的战斗。最终战星给凌云灌药→被踩碎胯下→被吓出屎→被塞粪入口→**靠队友光之力灌注才反杀**。博士有数据备份（"备用义体"），确保了系列的可续写性。
- **#5 嫉妒的决斗（26.7KB）**：赤以新形态 vs 战星。战斗里被精准踹裆、被打到解除头盔、战星在台上玩弄他肿胀的下体、逼出"我父亲是总统"的认主宣言。是赤"对父亲身份认知被反派公开羞辱"的高光场景。
- **#6 战星回忆"上"+ #7 战星回忆"下"（共 45.8KB）**：战星的过去与伊甸星五位护星天使登场。凌云受四战友光之力灌注后第一次在完全平等条件下与战星对战。**4 人变身的"战星回忆上"和 5 人的"新征程"前奏在 #6 末/#7 末**。
- **#8 新的征程（26.5KB）**：视角切到伊甸星。赤单枪匹马被派去执行"杀 5 位护星天使+征服星球"任务。**通过小男孩阿奇（5-6 岁）的眼睛，写"杀父仇人的接班人学会伪装"**——阿奇天真地摸赤的裆说"鸡巴好大"，赤淡定地变形出一套西装。这是**R-18G 同人里罕见的、把"正太纯真"和"成年战犯冷漠"并置**的写法。

### 核心套路（按出现频率）

1. **紧身衣 = 性器官外骨骼**（贯穿 8 章）：每次出场都明写"战衣将 JJ 轮廓/勃起/肿胀/射精痕迹勾勒得一清二楚"。这是**该作者的母题**，没有一次战斗/性侵/处刑场景不强调战衣的"羞耻描边"功能。
2. **5 人战队的"彩虹冲击波" + 单一被俘 → 救援的反转结构**：父辈和子辈的"5 人战队"采用同款叙事节拍——主角败→被凌辱→被战衣"标记"（精液/血/粪）→被战友注入光之力反杀。
3. **敌人 = 父亲 = 强奸犯 = 拯救者**的复合身份：总统是赤的"养育者/性侵者/给予力量者/需要被取悦的爸爸"。博士是"实验者/性骚扰者/给予天装核心的造物主"。这两个反派在赤的心理建设上**完全替代了凌云的"父亲"位置**。
4. **博士的"备用义体"**：博士每次被物理消灭（#1 凌云反杀、#3 暗示）都有数据备份复活。这是个**模块化反派机制**——读者不需要担心"反派死了怎么续"，作者能无限次地写"凌云/赤被博士重新抓回实验室"。
5. **正太 → 成人 → 战士 → 性奴的成长路径**（赤）：8 岁被性侵 → 18 岁身体形成"被虐→兴奋"的反射 → 变身后拥有力量但仍被迫承认总统是父亲 → 被派去伊甸星杀自己的"同族"。**这其实就是"养蛊"模板**。
6. **"光之力" + 紧身衣 + 5 人制 + 战败露出"的超级战队同人手淫解构**：把"战队是荣耀"的所有元素都翻译成"性虐/兽化/阉割/失禁"的物料库。
7. **博士的"以科研名义合法猥亵"话术**（#3 + #4）：用"同步率测试""肌肉数据采集""神经电位测量"作为剥衣服 + 抚弄乳头 + 手指插入的借口。**这是 R-18G 圈经典的"伪科学 + 性侵"组合**——比直接脱裤子更有"制度化"的恐怖感。

### 写作技法

1. **POV 切换**：父辈视角（#1-#2, #4-#7）→ 子辈视角（#3, #5, #8）→ 博士回溯（#4 大量）→ 反派回溯（#6 战星视角）。**这种在 R-18G 同人里罕见的多 POV 切换**让该作在"主题黑暗"之外还有"叙事技巧"上的优势。
2. **回溯式叙事**：#4 博士回忆 10 年前抓凌云，#6 战星回忆 10 年前打地球。**两段回忆都聚焦在"当年被打到失禁"的同一类细节**，作者用复沓的方式强化"战队 = 败北 + 失禁"的母题。
3. **变身的"宗教化"描写**：每次变身都用"光之粒子→战衣覆盖→头盔闭合"的三段式，带有明显的**圣战/十字架受难**的宗教意象。战衣越神圣（红色 + 金色 V 形 + 天使翅膀），被摧毁时越亵渎。
4. **"博士/总统 实验室 = 刑房"的物理化**：实验室里拘束器、电极、机械臂、注射器都是具体的"刑具集合体"，**比抽象的"调教"更有实感**。
5. **父子宿命的"镜像台词"**：赤在 #5 喊"我不认识凌云，我父亲只有总统"，而凌云在 #1 高台被问"英雄"时回以"我们……宣布……"（没说完）。**两组台词在"父 = 谁的父"这个核心问题上互文**。
