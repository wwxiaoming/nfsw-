## 二、核心人物档案（基于 #1「人设档案」+ 作品信息）

### 2.1 顾烨皓 / 高弹紧身衣战士「白曜」

- **阵营**: 帝王战队 621 队员，代号"白曜"
- **能力**: 体内蕴含近乎无限的能量核心，可自由调用以战斗与自愈
- **变身机制**: 右腕银色变身手镯 + 纯白高弹战衣
- **战衣特征**: 紧身设计勾勒肌肉轮廓；高领遮住脖颈；象征"纯洁/正义"
- **性格素描**: 冷峻、原则性极强、高傲、责任感重；体能/能量属性极强，但
  心理防线一旦被渗透会出现剧烈反差
- **弱点（被凌夜/敌方识破）**:
  1. 能量被外部装置（黑色项圈 + 暗蓝宝石）压制时，能量"输出需求"会
     转为"内敛"，向生殖系统汇聚，敏感度呈几何级数暴增
  2. 越抗拒刺激 → 身心对抗消耗越大 → 释放时越激烈/越屈辱
  3. 若主动"接受"快感，则身心消耗会下降，敏感点会被"重塑"

### 2.2 凌夜 / 凌夜

- **明面身份**: 帝王战队 621 队员之一（"手无缚鸡之力"少年）
- **实际身份**: 研究者/暗处主人——以"无害同伴"伪装渗透进顾烨皓
- **外形特征**: 比顾烨皓矮近一个头；银灰色湿发；琥珀色清澈眼眸；
  苍白皮肤，可见淡青血管
- **特殊气味**: 消毒水 + 糖果的混合味（标志性识别符）
- **能力素描**:
  - 极强的情绪伪装能力（怯懦少年 ↔ 冰冷研究者无缝切换）
  - 触觉"研究者"——通过触碰采集数据
  - 极强的语言引导与"建议重构"能力——把屈辱包装为"为你好"
- **声线与话术特征**:
  - 清越 / 软糯 / 气音
  - 善用"奖励""训练""缓解""科学"等中性词
  - 关键咒语: "顾哥好乖""真乖""训教得不错""白曜大人"

### 2.3 其他要素

- **敌方**: 构装体（机械兽/锁链怪物） + 神秘科研型反派
- **项圈**: 黑色皮革 + 暗蓝色宝石，压制能量核心，外人/凌夜所上
- **手镯**: 银色（顾烨皓自有），用于变身
- **银链情趣道具**: 乳头夹 + 根部银环 + 银链联动（#20 章登场）

## 三、剧情流线（第 1-21 章完整脉络）

### 阶段 A：开局与初陷（第 1-4 章）——"同伴"建立

- **#1 人设档案**: 顾烨皓白曜的设定/能力/性格集中展示，为后续"弱点
  分析"做铺垫
- **#2 初次交锋，结果被敌人攻击胯下**: 顾烨皓在战斗中下体受创，
  开始意识到这是"系统性针对"
- **#3 清洁室的被迫调教与浴室的自渎**: 被俘后的第一轮屈辱性
  "疏导"，身体在羞耻中完成首次被迫释放
- **#4 白曜的弱点分析计划**: 敌方开始将"胯下弱点"升级为系统性
  "实验"——为后续项圈/能量压制研究做铺垫

### 阶段 B：捕获与"同伴"伪装登场（第 5-10 章）——凌夜入场

- **#5 苦战！白曜的危机**: 顾烨皓被构装体围攻，陷入绝境
- **#6 战神的帅气反击，却落入新的陷阱**: 顾烨皓短暂爆发后反被
  新型陷阱控制
- **#7 白曜的沉沦**: 顾烨皓第一次"全面失守"——身体/能量/意志
  三重被压制
- **#8 彻底缴械！白曜的首次败北**: 在敌人面前完成"完全释放"，
  尊严与能量同时被剥夺
- **#9 被圈养的战神与暗处的主人**: "圈养"设定显形——顾烨皓
  沦为"被观察的样本"
- **#10 新的"伙伴"**: 凌夜以"被俘的伙伴"身份登场，开始与
  顾烨皓同处一室

### 阶段 C：伪装信任与逐步渗透（第 11-15 章）——攻心计

- **#11 被哄骗的顾烨皓**: 凌夜通过"安慰/自责/依赖"完成第一轮
  心理渗透
- **#12 困于掌中的"巨龙"**: 凌夜巧妙暗示顾烨皓的"敏感核心"
  就在能量与性器的耦合处
- **#13 为战神戴上项圈**: 凌夜亲手为顾烨皓戴上能量压制项圈——
  心理上"我为你缓解"的伪装与物理禁锢同步发生
- **#14 排雷章（短）**: 作者主动标注全文雷点，提示读者风险
  （此章极短，仅 730B，是元叙事插页）
- **#15 又一次的亵玩**: 项圈压制状态下，顾烨皓再次被迫"被观察
  + 被释放"，凌夜开始介入"测试"过程

### 阶段 D：研究者面目的初现（第 16-19 章）——"训教"启动

- **#16 无限能量的"弊端"**: 凌夜首次以"研究者"视角完整
  解释：能量压制 → 内敛 → 快感混淆 → 能量与性系统共振
  → 释放时精华纯度/强度暴增
- **#17 凌夜的训狗计划**: 凌夜正式"训教"——把"接受快感"包装
  为"减少消耗"的科学建议，顾烨皓开始动摇
- **#18 凌夜继续训狗中**: 在沙发上"训练性自慰"——从"被动
  抗拒"转向"半推半就接受"；凌夜引入"亲亲"作为奖励与
  控制工具
- **#19 温柔的欲网**: 浴室场景——温水/泡沫/抚摸/亲吻；
  顾烨皓的"同伴界限"被彻底模糊，开始主动搂抱/抚摸凌夜

### 阶段 E：道具化与"白曜"身份亵渎（第 20-21 章）——绝对掌控

- **#20 自己戴上情趣道具的战神**: 凌夜用"脱敏训练"的话术，
  引导顾烨皓**主动**为自己戴上乳头夹 + 根部银环 + 银链
  联动套装；银链通过物理连接放大敏感点联动；
  **战斗场景出现**——道具在战衣下对战斗节奏产生实际干扰
- **#21 变身成白曜后在战衣里缴械**: 凌夜以"白曜大人"的称呼
  强化身份亵渎；隔着白色战衣抚慰顾烨皓；
  顾烨皓在战衣内被迫/半主动释放；战衣"玷污"；
  顾烨皓第一次对凌夜产生"是不是喜欢我"的认知动摇
  ——子段 1/2 在此章结束，留下"凌夜决定速战速决"的悬念

## 四、核心主题与叙事母题

1. **能量-性-心理的三重耦合**: 作者将"超级战士的无限能量"
   概念化地与"性系统"绑定，形成独特的"能量宣泄"机制——
   这在特摄/超英同人里是少见的设定耦合
2. **伪装信任的攻心计**: 凌夜是"温柔版反派"——不靠暴力，靠
   伪装 + 引导 + 模糊命名（训练/缓解/奖励）来完成支配
3. **"抗拒 vs 接受"的悖论**: 凌夜用"接受会更舒服/省力"的逻辑
   把"屈从"重塑为"理性选择"——这是全文的认知操纵核心
4. **表里反差的亵渎感**:
   - 白色纯洁战衣 vs 裆部被自己液体浸透
   - "白曜大人"的神圣称呼 vs 战衣内的失控释放
   - 校园男神外形的衬衫 vs 银链情趣道具的"表里不一"
5. **认知迟滞**: 顾烨皓始终"差一点"发现凌夜的真实身份——
   浴室疑问、项圈疑问、视角切换疑问都在他心里一闪而过，
   随即被"舒适"覆盖
6. **研究者与样本的关系**: 凌夜对顾烨皓的"兴趣"是混合了
   掌控欲、破坏欲、探究欲、以及"扭曲的欣赏"的复合体
