### 作品定位（本子段）

本子段（#15–#23）是《裆能战记5：分裂》的**承上启下**——SA-01-A（#1–#14）已完成"序 + 队伍分裂"前史，本子段把全部矛盾压缩为三条**主线 × 多支线**，并给出"结局 1"和"结局 2"的明确分叉点（#21 末尾的 jumpuri 投票）。

- **核心卖点**：在"裆能战队"产品线上，本子段是**全系列核心中段**——裆能侠的中年身体衰退（#15）、与蓝剑侠的父子仇杀（#16–#20）、J 的同谋/情人双重身份（#21）、G 城火车站决战的两个结局（#22 结局1、#23 结局2入口）。
- **XP 命中**：紧身衣战士 + 龟责/榨精 + 正太（蓝剑侠）+ 中年人（裆能侠 38 岁前后）+ 师徒/父子反目 + 复仇 + 当众羞辱 + 触手 + 菌菇道具（黑汁鬼伞 / 鬼伞素）+ 梦中自慰 + 老年人精（高司令首次登场）——几乎覆盖了战队子类型下所有可命名的硬核标签。
- **目标读者**：能接受"叙事非线性 + 支线分歧 + 心理描写主导 + 父子间性回忆的穿插"的硬核读者；偏好"师徒反目 + 父子情仇 + 中年英雄身体衰退"这条高情感浓度线。
- **叙事定位**：作者ダイノマン在本子段使用大量**非线性时间**（#15 体检是分裂体战后，#16 倒回两周前，#18 是蓝剑侠幻境，#22 是火车站决战），且在 #21 末用 `[[jumpuri:10]]` / `[[jumpuri:12]]` 给出"读者投票"机制——**这是同人小说里少见的、把读者选择权塞进文本的实验**。

### 关键章节

- **#15（3）— 裆能侠的医学体检 + 高司令登场**：
  - 战后回基地，裆能侠给 J 做人工呼吸（掀面罩）+ 接受李医生详细体检。
  - **关键医学细节**：年近四十的裆能侠阴茎"随年龄略变长 / 缓慢变成粗壮肉屌"；过去被淫魔打断过几次阴茎，影响勃起硬度和持久度；隐性伤口加剧龟头敏感度；**"裆能战士生殖器官比普通人更活跃"**——作者用医学报告的笔法，把"超能力勃起"内化为生理学。
  - **体检高潮段**：李医生用棉棒插入后穴取前列腺液 → 裆能侠在医护人员面前**颜面无存地失控爆射** → 精液喷在检查床淡蓝色垫子上；李医生"自主取精环节可以掠过了"。
  - **新角色高司令登场**：本名高崇鹰，前裆能战士出身，刚调任 G 城，**只比裆能侠大几岁**；戴宽大方框眼镜；推眼镜是标志性动作；**有和吸精魔王交手的经验**——这让"前辈"和"现任上司"双重身份压到裆能侠头上。
  - 关键台词："有些事想的太天真可不行……那小子虽然也帮了你几次，但是万一哪天他又投靠了魔王，联合起来对付你，该怎么办？"——**首次把 J 标定为"不可信任的同谋"**。
  - 收尾：裆能侠解除隔离，去看 J 撞见蓝剑侠。**蓝剑侠首次露出对裆能侠的敌意**："消灭吸精魔王，这个借口真不错！就像害死我父亲时候一样。"
  - 裆能侠"如果再有一次机会，我希望替队长去死"——**作者把"父子/师徒关系裂痕"正面化**。
  - 章末意象：电梯里三面镜子，裆能侠看着镜子里的自己——"变身之后的样子和两周前没什么不同。可在别人眼中，他的形象已经完全改变了。"——**本章最关键的双关收束**。

- **#16（4）— 两周前，建筑工地夜战三分裂体**：
  - 倒回两周前。夏夜工地，工人光膀子住工棚，分裂体被工棚里的"雄性气味"吸引——作者用一段**环境描写**把"工地性压抑"作为分裂体的诱因。
  - **裆能侠 + 蓝剑侠的战术配合**：裆能侠用护目镜能量模式侦察；护目镜目标能量水平显示 940μ——"是个不好对付的家伙"。
  - **最大分裂体**：两米多长，灰绿色疙瘩，狗头 + 鬣狗爪 / 食草蹄 / 巨屌，**护甲在腹部**（作者用"和自然界的动物相反"做了明确设定）。
  - **裆能侠战败 → 被按住 → 当众手淫 → 巨屌打脸**：
    - 巨兽一蹄踩住双臂 + 脚踝 → 狗头舔胸 + 爪子按裆能腰带 + 另一只爪子隔紧身衣握鸡巴手淫。
    - 分裂体"知道该用什么方式，在最短时间内榨出英雄的裆能"——**用地球生物界罕见的方式（鬣狗攻击生殖器）合理化魔王的战术**。
    - 巨屌横抽裆能侠面罩；裆能侠意识模糊——"快要被……打射了……"
  - 蓝剑侠独自对付另外两只：一只是带刺沙蓬形态，被"裆能冰雷斩"冻成冰球；另一只是肉球形态，能吸收攻击能量变成蓝色炸弹。
  - 蓝剑侠"裆能冰雷斩"独杀沙蓬；裆能侠被打到快射时，**蓝剑侠在耳机里听见裆能侠呻吟** → 紧急前来救援。
  - **结尾翻转**：裆能侠救蓝剑侠 → 两人撞塌围墙 → 三分裂体地下重新聚合 → **第四只分裂体从地底把蓝剑侠拖入地下**——**整个 SA-01-A 段的核心悬念"蓝剑侠失踪"在此章正式埋下**。

- **#17（5）— 裆能侠反杀三分裂体 + 蓝剑侠被第四分裂体掳走**：
  - 裆能侠集中精神 → 找准怪兽背部气孔弱点 → 蓝剑侠背后插剑 → 裆能侠右手射"红色裆能光镖" → 刺入气孔 → **引爆**。
  - 蓝剑侠得意："下次这种大家伙，可以直接让我来对付。"——**这是蓝剑侠最后一句"少年英雄"的台词**。
  - 肉球分裂体吸收蓝剑侠的能量 → 蓝色炸弹 → 裆能侠紧急护盾救蓝剑侠 → 两人撞塌围墙。
  - 两人同时陷入苦战：**裆能侠被蘑菇头形分裂体顶裆 → 被触手捆成粽子**；**蓝剑侠被另一分裂体含住阳物口交**——两人腰带一红一白交替闪。
  - 裆能侠的护目镜警报"裆能紧身衣严重受损！防御力不足。剩余20%……18%……15%……"
  - **反杀奇招**：裆能侠握拳 → 打自己裆下 → "裆能激动拳——" → 钟型蘑菇头被击爆；脑浆里有"从他身上吸走的小股裆能"——**作者用"归还自己的精"作为击杀反派的关键招式**。
  - 章末：**蓝剑侠被地下黑色粘液拖入地下** → 裆能侠一拳砸在战车车顶 → "可恶！！"——**SA-01-A 段最戏剧化的一幕**。

- **#18（6）— 蓝剑侠幻境，代入父亲视角**：
  - 裆能侠驱车找 J 询问蓝剑侠下落；J 一脸无辜 → 裆能侠追问 → J 暗示"那东西对待他，可不会像我对你一样温柔"——**首次把"裆能侠曾让 J 吸精"明示出来**。

  - **J 镜前 play**：J 从背后咬裆能侠乳头 + 另一只手加速手淫 → 裆能侠被操射在镜子上。
  - 蓝剑侠被分裂体抓到地下沼泽 → 看见一棵树上挂着裆能侠（裆能侠管他叫"队长"）——**蓝剑侠在沼泽里看见"裆能侠的视角下的自己父亲"**。
  - **手套变金黄 + 裆能战衣变深蓝** → 蓝剑侠变成"父亲的形象" → 裆能侠（被挂着的）射了他一脸。
  - **第一次性记忆代入**：蓝剑侠闻到裆能侠能量精液的味道 → 自己硬了 → 替裆能侠把尿 → 套弄阴茎 → 用嘴含乳头 → **两人在泥沼里交合**。
  - 章末蓝剑侠意识渐失："他们一直射到虚脱，才一同倒下"——**父子/师徒/情人三线合一的幻境**。

- **#19（7）— 蓝剑侠延续幻境，看父亲为裆能侠口交 + 母亲之死**：
  - 蓝剑侠在黑暗中"看到了父亲的记忆"；意识到"听说是另一回事，亲眼所见是另一回事，而代入父亲的角色亲身经历，又是另一回事"。
  - **母亲之死的细节揭露**：蓝剑侠小时候母亲听信电激魔人 → 把裆能队长和裆能侠困在提取元精的机器上 → 她被绑架作为吸精魔王控制父亲的筹码 → 死了。
  - **裆能队长死因的真正顺序**：

    - 裆能侠贪生怕死 → 父亲帮他吸出黑精 → 父亲中毒身亡。
  - **父亲替裆能侠口交**（延续 #18 的内容）：父亲扒光裆能侠所剩无几的紧身战衣 → 反手摩挲裆能侠乳头 + 双唇含住裆能侠阴茎 + 插入 G 点 + 按住会阴 + 深喉吸吮 → **裆能侠在队长口里射出黑精** → 父亲倒下去。
  - 蓝剑侠跪地哽咽："许少阳叔叔，敬爱的兄长，顽强的英雄，亲密的战友……无耻的骗子，淫荡的失败者，害死父母的帮凶……"
  - **章末反讽**：蓝剑侠昏沉 → 身体"被裆能侠的黑精灌满" → 心里满是对裆能侠的鄙夷和怨恨——**作者用"精液污染"作为仇恨的物理化**。

  - **裆能侠发动"烈日变身"分解鬼伞素**（用高温）——本章的高潮招。
  - 裆能侠主动伸双手入分裂体 → 黑色菌伞缠住他的双臂 → **吸精魔王在幻觉里现身**。
