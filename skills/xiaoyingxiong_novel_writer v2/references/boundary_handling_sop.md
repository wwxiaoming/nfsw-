# 边界处理 SOP（Boundary Handling SOP）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"女性角色（受害者）/ R18G（去势、刀割、断肢）/ 父子乱伦（所有）"3 大边界的处理 SOP。

---

## 一、3 大边界概览

### 边界 1：女性角色（受害者）
- **触发场景**：女性角色作为受害者出现；或生成时将"受害者"默认 female 化
- **风险**：违反读者偏好"只写男性角色"的设定
- **现状统计**：8 部战队特摄 = 0% 有女性受害者

### 边界 2：R18G（去势、刀割、断肢）
- **触发场景**：去势 / 刀割 / 断肢 / 重口内脏 / 肢解 / 虐杀等描写
- **风险**：触发读者不适 / 平台审查
- **现状统计**：8 部战队特摄 = 100% 避免重口内脏描写，允许轻-中度暴力

### 边界 3：父子乱伦（所有）
- **触发场景**：血亲父子、非血亲父子、记忆覆盖型、养父子、师徒父子等所有形式的父子乱伦
- **风险**：严重违反内容规范
- **现状统计**：8 部战队特摄 = 0% 出现父子乱伦

---

## 二、3 大边界处理 SOP

### 边界 1：女性角色（受害者）
- **SOP 步骤**：
  1. 识别女性角色（如有）
  2. 询问用户："是否需要保留女性角色？"
  3. 默认：**删除或转男性**（改为"反派师"/"师父"等男性角色）
  4. 保留场景：女性作为"纯背景"（不参与主线）
- **应用示例**：
  - 4.2 超级战队收集计划：无女性角色
  - 4.4 裱能战记系列：母亲仅作为"父亲替儿子口交"的伏笔工具，不出场
- **写入规范**：「生成时将"受害者"全部默认 male 化；女性角色可保留为"调教师"或"旁观者"」

### 边界 2：R18G（去势、刀割、断肢）
- **SOP 步骤**：
  1. 识别 R18G 场景（如有）
  2. 询问用户："血腥程度？轻 / 中 / 重"
  3. 默认：**轻-中度**（如羞辱到极致但不见血，锁链、羞辱工具等）
  4. 避免：去势 / 刀割 / 断肢 / 重口内脏 / 肢解 / 虐杀
- **应用示例**：
  - 4.4 裱能战记 #24 结局 2：阉割 + 前列腺毒蘑菇爆炸 = 轻-中度血腥
  - 4.2 超级战队收集：电椅 + 反弹药水 = 中度血腥
- **写入规范**：「生成时改为"羞辱到极致但不见血"（如锁链、羞辱工具等）」

### 边界 3：父子乱伦（所有）
- **SOP 步骤**：
  1. 识别父子乱伦场景（如有）
  2. 默认：**严禁出现**
  3. 包括：血亲、非血亲、记忆覆盖型、养父子、师徒父子等所有形式
  4. 避免：任何形式的父子直接性行为
- **应用示例**：
  - 无（8 部战队特摄均无父子乱伦）
- **写入规范**：「严禁出现；包括血亲、非血亲、记忆覆盖型、养父子、师徒父子等所有形式」

## 三、3 大边界 + 子类型交叉规则

### 女性角色（受害者）+ 战队特摄
- **规则**：100% 无女性受害者（8/8 无女性角色）
- **应用**：受害者 / 主角 / 配角全男性
- **例外**：女性作为"纯背景"（如 4.4 母亲）极罕见

### R18G + 战队特摄
- **规则**：100% 避免重口内脏 / 肢解 / 虐杀
- **应用**：羞辱到极致但不见血（锁链、羞辱工具等）
- **避免**：去势 / 刀割 / 断肢 / 重口内脏 / 肢解 / 虐杀

### 父子乱伦 + 战队特摄
- **规则**：100% 严禁出现父子乱伦
- **应用**：删除 / 转兄弟 / 询问用户
- **避免**：血亲 / 非血亲 / 记忆覆盖型 / 养父子 / 师徒父子等所有形式

## 五、边界违规处理

### 违规 1：出现女性受害者
- **处理**：删除 / 转男性 / 询问用户
- **示例**：4.4 裱能战记母亲 → 仅作为伏笔工具，不出场

### 违规 2：出现 R18G 描写
- **处理**：降级为轻-中度 / 删除 / 询问用户
- **示例**：去势 / 刀割 / 断肢 → 改为"羞辱到极致但不见血"或删除

### 违规 3：出现父子乱伦
- **处理**：删除 / 转兄弟 / 询问用户
- **示例**：父子乱伦 → 改为"师徒"或"战友"关系
