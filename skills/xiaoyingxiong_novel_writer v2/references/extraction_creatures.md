# 榨精生物图鉴（Extraction Creatures）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"榨精生物 / 角色"分类 + 描述模板 + 实战案例。

---

## 一、榨精生物 7 大分类

### 1. 榨精魔物兽（榨精魔物怪人 / 异种生物）
- **代表**：超级战队收集（榨精魔物怪人）、龙骧战队（蜃煌手下榨精魔物兽）、天装战队（养蛊型榨精魔物怪）
- **描述模板**：「[榨精魔物]从[反派身体的某部位]伸出，[缠绕/注入/束缚][主角]的[足底/腋下/裆部]」
- **XP 命中**：榨精魔物束缚 + 注入 + 多功能（束缚+痒感+直播）
- **特殊形态**：榨精魔物椅 / 榨精生物地毯 / 榨精魔物剃须刀 / 榨精魔物播音器

### 2. 魅魔（精液吸收型）
- **代表**：超级战队收集（幻梦本人）、天装战队护星红（反派兄控型）
- **描述模板**：「[反派]张开[嘴/性器官]吸收[主角]的[精液/乳汁/眼泪]，从普通反派变成[战衣加持/圣兽能量]形态」
- **XP 命中**：精液能量守恒 + 榨精 + 反派进化
- **特殊形态**：精液现形（魔王从精液里凝聚，4.4 裆能战记 #28）

### 3. 黏液生物（史莱姆 / 胶质怪）
- **代表**：超级战队收集（史莱姆分身）、龙骧战队（榨精魔物兽变体）
- **描述模板**：「[史莱姆/胶质怪]将[主角]包裹在[身体内部]，提供[痒感/束缚/性化]」
- **XP 命中**：史莱姆分身揭示 + 榨精魔物椅变体
- **特殊形态**：史莱姆分身（反派真正身份）

### 4. 肉壁空间生物（体内空间型）
- **代表**：超级战队收集（血乳交融中空玻璃管）、高弹紧身衣（凌夜的暗面体）
- **描述模板**：「[主角]被吸入[反派/异空间]的[体内/器官]，从[内部/表面]进行[性化/调教]」
- **XP 命中**：体内空间 + 反派作为容器
- **特殊形态**：暗面体（凌夜 4.1，体内空间型反派）

### 5. 兽人（人形反派 / 兽化）
- **代表**：天装战队护星红（养蛊型反派选拔）、龙骧战队（蜃煌手下兽人）
- **描述模板**：「[反派]保留[人类/兽人]外形，但具有[兽耳/兽尾/兽人化]特征」
- **XP 命中**：反派半兽人化 + 榨精魔物化
- **特殊形态**：养蛊型反派（天装 5.2，反派之间互相斗争）

### 6. 植物生命（菌魔 / 妖精 / 孢子）
- **代表**：超星战队日常（催情菌魔）、天装战队（菌丝榨精魔物怪）
- **描述模板**：「[菌魔/妖精]释放[催情孢子/菌丝榨精魔物]，从[皮肤/呼吸]侵入[主角]身体」
- **XP 命中**：催情菌魔 + 能量转换 = 身体反应反差
- **特殊形态**：催情菌魔（5.3 超星，菌丝榨精魔物 + 身体反应反差）

### 7. 元素生命（能量体 / 战衣形态）
- **代表**：高弹紧身衣（白曜战衣）、超级战士（5 战士战衣）、超能战队 kk（贞操锁 = 能源核心）
- **描述模板**：「[战衣]从[主角]的[身体]上[破裂/光点消散]，露出[激凸/湿润/勃起]的身体」
- **XP 命中**：紧身战衣激凸 + 双解除模式（物理破坏 vs 能量消散）
- **特殊形态**：贞操锁 = 能源核心（5.4 超能 kk，贞操锁是能源）

## 二、榨精生物交叉组合

### 触手兽 + 魅魔
- **代表**：超级战队收集（幻梦既是榨精魔物怪人也是精液吸收型）
- **应用**：反派从榨精魔物束缚升级到榨精

### 魅魔 + 元素生命
- **代表**：4.4 裆能战记（精液现形 = 魔王从精液里凝聚 + 烈日形态变身）
- **应用**：反派榨精后变身

### 兽人 + 榨精魔物兽
- **代表**：天装战队护星红（养蛊型反派 = 兽人 + 榨精魔物怪）
- **应用**：反派半兽人化 + 榨精魔物化

### 菌魔 + 榨精魔物兽
- **代表**：超星战队日常（催情菌魔 + 榨精魔物椅变体）
- **应用**：菌丝榨精魔物 + 身体反应反差

### 元素生命 + 榨精魔物兽
- **代表**：高弹紧身衣（白曜战衣 + 凌夜榨精魔物束缚）
- **应用**：战衣激凸 + 榨精魔物束缚
