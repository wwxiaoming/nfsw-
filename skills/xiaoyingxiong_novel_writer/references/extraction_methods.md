# 榨精方式指南（Extraction Methods）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"榨精手法 / 龟责技巧 / 边缘控制技巧"3 大榨精方式的实战指南。

---

## 一、榨精方式 3 大分类

### 1. 榨精手法（直接获取精液）
- **定义**：通过物理 / 道具手段直接榨取主角的精液
- **应用场景**：反派通过榨精获得圣兽能量 / 战衣加持 / 系统化控制
- **频率**：100%（8/8 战队特摄都有榨精手法）

### 2. 龟责技巧（龟头刺激 / 局部精化）
- **定义**：通过龟头 / 阴部 / 乳头的局部刺激，反复让主角达到边缘
- **应用场景**：调教师 / 反派 / 触手怪人
- **频率**：75%（6/8 战队特摄有龟责技巧）

### 3. 边缘控制技巧（反复阻止射精 / 延长快感）
- **定义**：让主角多次达到射精边缘但不允许射精，延长快感
- **应用场景**：贞操锁 / 控制芯片 / 反派系统化
- **频率**：63%（5/8 战队特摄有边缘控制）

## 二、榨精手法 6 大类

### 1. 物理榨精（手 / 嘴 / 触手）
- **代表**：4.1 高弹紧身衣（凌夜用手/触手榨精白曜）、4.2 超级战队收集（5 阶段第 4 阶段）
- **描述模板**：「[反派/触手]用[手/嘴/触手]对[主角]的[阴茎/乳头/后庭]进行[直接刺激/系统化榨精]」
- **XP 命中**：物理 + 直接 + 系统化
- **应用场景**：训练室 / 任务地点 / 反派主场

### 2. 道具榨精（贞操锁 / 精杯 / 触手椅）
- **代表**：4.2 超级战队收集（5 阶段第 5 阶段锁精三件套）、5.4 超能 kk（贞操锁 = 能源核心）
- **描述模板**：「[贞操锁/精杯/触手椅]对[主角]的[阴茎]进行[定时榨精/24h 监控/能源核心榨精]」
- **XP 命中**：贞操锁 + 定时 + 24h
- **应用场景**：反派控制室 / 直播室 / 24h 监控

### 3. 触手榨精（触手怪人 / 触手科技）
- **代表**：4.2 超级战队收集（触手怪人榨精）、5.1 龙骧（触手椅 + 直播榨精）
- **描述模板**：「[触手]从[反派身体的某部位]伸出，对[主角]的[阴茎/乳头/足底]进行[榨精/束缚/痒感]」
- **XP 命中**：触手 + 多功能 + 直播
- **应用场景**：怪人基地 / 直播室

### 4. 战衣榨精（紧身战衣激凸 + 勃起 = 榨精前提）
- **代表**：4.1 高弹（红色高弹战衣完美贴合）、4.3 超级战士（5 战士战衣激凸）
- **描述模板**：「[战衣]对[主角]的[乳头/龟头]产生[激凸/湿润/勃起]，导致[持续榨精/反复勃起]」
- **XP 命中**：紧身战衣 + 激凸 + 持续
- **应用场景**：训练室 / 巡逻 / 任务地点

### 5. 反派榨精（反派第一人称 / 反派系统化）
- **代表**：4.2 超级战队收集（幻梦第一人称榨精）、4.4 裆能战记（高司令榨精）
- **描述模板**：「[反派]通过[控制芯片/贞操锁/淫纹]对[主角]进行[定时/24h/系统化]榨精」
- **XP 命中**：反派系统化 + 24h + 精液能量守恒
- **应用场景**：反派控制室 / 24h 监控

### 6. 精液现形（魔王从精液里凝聚 = 色情魔幻化）
- **代表**：4.4 裆能战记 #28 大结局（精液现形 + 烈日变身）
- **描述模板**：「[主角]射精后，[魔王/反派]从[精液]里[凝聚/进化/变身]」
- **XP 命中**：色情魔幻化 + 榨精后变身
- **应用场景**：高潮 / 章节结尾

## 三、龟责技巧 5 大类

### 1. 龟头刺激（直接刺激龟头）
- **代表**：4.1 高弹（凌夜用触手刺激白曜龟头）、4.2 超级战队收集（5 阶段第 4 阶段）
- **描述模板**：「[反派/触手/道具]对[主角]的[龟头/冠状沟/系带]进行[直接刺激/反复抚摸/旋转]」
- **XP 命中**：直接 + 局部 + 高潮前
- **应用场景**：训练室 / 调教室

### 2. 乳头刺激（乳头 = 第二龟头）
- **代表**：4.1 高弹（红色高弹战衣乳头激凸）、4.4 裆能战记（裆能系统涉及乳头）
- **描述模板**：「[反派/触手/道具]对[主角]的[乳头]进行[夹/捏/吸/舔/刺激]」
- **XP 命中**：乳头 + 夹子 + 吸吮
- **应用场景**：调教室 / 反派主场

### 3. 阴部刺激（睾丸 / 会阴 / 后庭）
- **代表**：4.2 超级战队收集（5 阶段第 4 阶段锁精三件套）
- **描述模板**：「[反派/道具]对[主角]的[睾丸/会阴/后庭]进行[按摩/插入/刺激]」
- **XP 命中**：阴部 + 插入 + 高潮前
- **应用场景**：调教室 / 触手椅

### 4. 足部龟责（足底 = 敏感区）
- **代表**：4.3 超级战士（脚底怕痒）、5.1 龙骧（蜃煌足部）、5.4 超能 kk
- **描述模板**：「[反派/触手]对[主角]的[足底/脚趾]进行[踩踏/舔/闻/按摩]」
- **XP 命中**：足控 + 雄臭 + 战靴
- **应用场景**：训练室 / 任务地点

### 5. 腋下龟责（腋下 = 隐藏敏感区）
- **代表**：4.3 超级战士（腋下怕痒）
- **描述模板**：「[触手/剃须刀]对[主角]的[腋下]进行[剃腋毛/挠痒/刺激]」
- **XP 命中**：腋下 + 剃腋毛 + 怕痒
- **应用场景**：触手剃须 / 喜剧情色

## 四、边缘控制技巧 4 大类

### 1. 贞操锁边缘控制（贞操锁 = 阻止射精）
- **代表**：4.2 超级战队收集（5 阶段第 5 阶段锁精三件套）、5.4 超能 kk（贞操锁 = 能源核心）
- **描述模板**：「[贞操锁]锁住[主角]的[阴茎]，让[主角]达到[边缘]但[不允许射精]，[反复/24h]」
- **XP 命中**：贞操锁 + 边缘 + 反复
- **应用场景**：24h 监控 / 贞操锁控制

### 2. 控制芯片边缘控制（芯片 = 远程控制）
- **代表**：4.1 高弹（控制芯片）、4.2 超级战队收集
- **描述模板**：「[控制芯片]植入[主角]的[后颈/裆部/心脏]，[反派]通过[远程控制]让[主角]达到[边缘]但[停止]」
- **XP 命中**：植入 + 远程 + 边缘
- **应用场景**：24h 监控 / 反派远程

### 3. 触手边缘控制（触手 = 多功能边缘）
- **代表**：4.2 超级战队收集（触手怪人）、5.1 龙骧（触手椅）
- **描述模板**：「[触手]对[主角]的[阴茎/乳头/足底]进行[反复刺激/边缘停止/痒感控制]」
- **XP 命中**：触手 + 多功能 + 边缘
- **应用场景**：触手椅 / 触手地毯

### 4. 反派系统化边缘（5 阶段循环 = 边缘控制）
- **代表**：4.2 超级战队收集（5 阶段堕落循环）
- **描述模板**：「[反派]通过[5 阶段]对[主角]进行[植入→渗透→仪式化→锁精→滚雪球]，[每阶段边缘控制]」
- **XP 命中**：系统化 + 5 阶段 + 边缘
- **应用场景**：5 阶段循环 / 滚雪球

## 五、榨精方式交叉组合

### 物理 + 触手 + 战衣
- **代表**：4.1 高弹（触手 + 战衣激凸 = 物理榨精 + 触手榨精 + 战衣榨精）
- **应用**：3 重叠加榨精

### 道具 + 反派 + 系统化
- **代表**：4.2 超级战队收集（贞操锁 + 反派系统化 + 5 阶段）
- **应用**：系统化榨精

### 触手 + 直播 + 边缘
- **代表**：5.1 龙骧（触手椅 + 直播 + 边缘控制）
- **应用**：触手 + 直播 + 边缘控制

### 精液现形 + 战衣榨精 + 龟责
- **代表**：4.4 裆能战记（精液现形 + 战衣 + 龟责）
- **应用**：色情魔幻化 + 战衣 + 龟责

### 足部 + 腋下 + 喜剧情色
- **代表**：4.3 超级战士（足部龟责 + 腋下龟责 + 喜剧情色）
- **应用**：怕痒 + 剃腋毛 + 反派叛变
