# 词汇子类型特化（Vocabulary Subtype Specifics）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"子类型 → 词汇库"的特化规则。

---

## 一、9 大子类型词汇库

### 01 战队（标配）
- **角色称谓**：队长 / 副队 / 王牌 / 队员 / 战衣 / 圣兽 / 战队
- **场所**：训练室 / 巡逻 / 任务地点 / 宿舍 / 浴室 / 医务室 / 怪人基地
- **战斗**：变身 / 攻击 / 防御 / 必杀技 / 合体技 / 终极武器
- **状态**：激凸 / 湿润 / 勃起 / 失禁 / 疲惫 / 觉醒
- **示例**：「白曜在训练室穿上红色高弹战衣，乳头和龟头被完美贴合」

### 02 喜剧（喜剧情色）
- **反讽套话**：上校 / 少将 / 准将 / 中校 / 大校 / 军衔
- **喜感反应**：笑到流泪 / 精疲力竭 / 主动求反派收编 / 反派被逗乐
- **吐槽**：蠢萌 / 反讽 / 恶搞 / 自嘲
- **示例**：「雷神上校被触手地毯搞得精疲力竭，主动向反派请求收编」

### 03 反派（反派恶堕 / 心理深度）
- **反派称谓**：暗面体 / 触手怪人 / 淫纹师 / 催眠博士 / 收藏家 / 养蛊型 / 穿越者
- **心理展开**：自毁 / 自我牺牲 / 翻车 / 反派说教 / 知识型反派
- **反派哲学**：力量 / 控制 / 所属化 / 系统化
- **示例**：「凌夜作为暗面体，在番外亲自讲解'神明战体的交配模式'」

### 04 调教（系统化精神控制）
- **调教工具**：欲珠 / 淫纹 / 控制芯片 / 贞操锁 / 触手椅 / 触手地毯
- **调教阶段**：植入 → 渗透 → 仪式化 → 锁精三件套 → 滚雪球
- **调教师**：淫纹师 / 催眠博士 / 反派学长 / 教官 / 触手怪
- **状态**：被控 / 沦陷 / 主动配合 / 自我说服
- **示例**：「主角被植入欲珠，进入 5 阶段堕落循环，最终主动配合反派」

### 05 兄弟（双主角同堕落）
- **兄弟称谓**：哥哥 / 弟弟 / 双子 / 竹马 / 搭档 / 队友
- **兄弟互动**：保护 / 互攻 / 同堕落 / 兄弟情深反差
- **反派利用**：让兄弟互相攻击 / 公开场合同时被调教
- **示例**：「蜃煌和哥哥被反派同时调教，蜃煌主动堕落，哥哥试图保护却失败」

### 06 主仆（反派主导 / 反派第一人称）
- **主仆仪式**：紧身衣仪式化 / 贞操锁 / 控制芯片 / 淫纹
- **主仆状态**：臣服 / 服从 / 主动 / 长期 / 24h 监控
- **反派第一人称**：我 / 我的 / 反派视角
- **示例**：「幻梦作为反派第一人称，将 5 战士系统化收编为主仆」

### 07 同人（二创 / 跨作品衍生）
- **原作角色**：白曜 / 顾烨皓 / 凌夜 / 蜃煌 / 银河领主 / 雷神 / 钢铁之子 / 时空之眼 / 苏贺
- **二创设定**：原作 + 衍生情节 + 同人化解读
- **示例**：「龙骧战队二创加入触手机械 + VR 入侵分支」

### 08 触手（触手怪人 / 异种生物）
- **触手形态**：触手椅 / 触手地毯 / 触手剃须刀 / 触手播音器 / 触手束缚
- **触手功能**：束缚 / 痒感 / 注入 / 直播 / 多功能
- **触手种类**：黏液生物 / 兽化触手 / 菌丝触手 / 元素触手
- **示例**：「触手从反派身体的某部位伸出，缠绕主角的足底/腋下/裆部」

### 09 足控（足部特化）
- **足部称谓**：足底 / 脚趾 / 脚背 / 脚踝 / 雄臭 / 战靴
- **足部动作**：踩踏 / 舔足 / 闻臭 / 足部按摩 / 足部高潮
- **足部服饰**：红色过膝袜 / 黑色短袜 / 白色足袋 / 军靴 / 运动鞋
- **示例**：「主角的足底在反派面前暴露，被舔/被踩/被闻」

## 二、跨子类型高频词汇

### 紧身战衣
- 描述词：完美贴合 / 激凸 / 湿润 / 勃起 / 破裂 / 光点消散 / 战衣激凸
- 部位：乳头 / 龟头 / 屁股缝 / 大腿内侧 / 腋下
- 示例：「战衣完美贴合乳头/龟头/屁股缝/大腿内侧」

### 战衣解除（双解除模式）
- 模式 1（物理破坏）：战衣破裂 / 战衣撕裂 / 战衣撕开
- 模式 2（能量消散）：战衣光点消散 / 战衣溶解 / 战衣变成光
- 示例：「战衣从乳头/裆部开始破裂/光点消散，露出激凸/湿润/勃起」

### 反派系统化
- 阶段词：植入 / 渗透 / 仪式化 / 锁精三件套 / 滚雪球
- 工具词：欲珠 / 淫纹 / 芯片 / 贞操锁 / 触手椅
- 示例：「5 阶段堕落循环 + 锁精三件套 + 滚雪球」

### 精液能量
- 描述词：精液 / 乳汁 / 眼泪 / 血液 / 圣兽能量
- 功能词：榨精 / 精液能量守恒 / 精液现形 / 三代精液闭环
- 示例：「反派通过榨取主角的精液/乳汁，获得圣兽能量/战衣加持」

### 触手多功能
- 描述词：触手 / 触手椅 / 触手地毯 / 触手剃须刀 / 触手播音器
- 功能词：束缚 / 痒感 / 注入 / 直播 / 多功能
- 示例：「触手 = 痒感工具 + 高科技 + 低俗反差」

### 兄弟同堕落
- 描述词：兄弟 / 双子 / 竹马 / 搭档 / 队友
- 动作词：同被俘 / 互相攻击 / 兄弟情深反差 / 同沦陷
- 示例：「双主角同时被俘，互相攻击，兄弟情深反差」

## 四、词汇违规处理

### 违规 1：使用真实品牌名
- **处理**：删除 / 用代称
- **示例**：Nike → "运动鞋" / "白色运动鞋"

### 违规 2：使用女性相关词
- **处理**：删除 / 转男性
- **示例**：「她」 → 「他」

### 违规 3：使用重口血腥词
- **处理**：降级 / 删除
- **示例**：内脏描写 → 「伤口」
