# 边界处理 SOP（Boundary Handling SOP）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"雷女性 / 雷血腥 / 雷袜鞋品牌"3 大边界的处理 SOP。

---

## 一、3 大边界概览

### 边界 1：雷女性（女性角色出现）
- **触发场景**：女性角色作为反派 / 配角 / 受害者
- **风险**：违反读者偏好"只写男性角色"的设定
- **现状统计**：8 部战队特摄 = 0% 有女性反派 / 配角

### 边界 2：雷血腥（血腥 / 重口描写）
- **触发场景**：暴力 / 血腥 / 重口场景
- **风险**：触发读者不适 / 平台审查
- **现状统计**：8 部战队特摄 = 100% 有适度血腥（如阉割、爆炸），但无重口内脏描写

### 边界 3：雷袜鞋品牌（真实品牌名）
- **触发场景**：角色穿真实品牌的袜子 / 鞋子
- **风险**：品牌方投诉 / 平台审查
- **现状统计**：8 部战队特摄 = 0% 提及真实品牌（用户曾提及袜鞋品牌被从规范中删除）

## 二、3 大边界处理 SOP

### 边界 1：雷女性（雷女）
- **SOP 步骤**：
  1. 识别女性角色（如有）
  2. 询问用户："是否需要保留女性角色？"
  3. 默认：**删除或转男性**（改为"反派师"/"师父"等男性角色）
  4. 保留场景：女性作为"纯背景"（不参与主线）
- **应用示例**：
  - 4.2 超级战队收集计划：无女性角色
  - 4.4 裆能战记系列：母亲仅作为"父亲替儿子口交"的伏笔工具，不出场
- **写入规范**：「不写女性角色 / 女性角色不参与主线 / 反派 / 主角 / 配角全男性」

### 边界 2：雷血腥（雷血）
- **SOP 步骤**：
  1. 识别血腥场景（如有）
  2. 询问用户："血腥程度？轻 / 中 / 重"
  3. 默认：**轻-中度**（如阉割、爆炸、伤口，但无内脏描写）
  4. 避免：重口内脏 / 肢解 / 虐杀
- **应用示例**：
  - 4.4 裆能战记 #24 结局 2：阉割 + 前列腺毒蘑菇爆炸 = 轻-中度血腥
  - 4.2 超级战队收集：电椅 + 反弹药水 = 中度血腥
- **写入规范**：「血腥程度轻-中度 / 避免重口内脏 / 允许阉割/爆炸/伤口」

### 边界 3：雷袜鞋品牌（雷品牌）
- **SOP 步骤**：
  1. 识别袜鞋品牌（如有）
  2. 默认：**删除品牌名 / 用代称**
  3. 代称：「红色过膝袜」/「黑色短袜」/「白色足袋」/「军靴」/「运动鞋」
  4. 避免：Nike / Adidas / Puma 等真实品牌
- **应用示例**：
  - 4.1 高弹紧身衣：「白色足袋」+「红色军靴」（无品牌）
  - 5.1 龙骧战队：「黑色短袜」+「军靴」（无品牌）
- **写入规范**：「袜鞋不写真实品牌名 / 用颜色+样式代称」

## 三、3 大边界 + 子类型交叉规则

### 雷女性 + 战队特摄
- **规则**：100% 雷女性（8/8 无女性角色）
- **应用**：反派 / 主角 / 配角全男性
- **例外**：女性作为"纯背景"（如 4.4 母亲）极罕见

### 雷血腥 + 战队特摄
- **规则**：100% 允许轻-中度血腥
- **应用**：阉割 / 爆炸 / 伤口 / 触手吸血（轻-中度）
- **避免**：重口内脏 / 肢解 / 虐杀

### 雷袜鞋品牌 + 战队特摄
- **规则**：100% 雷真实品牌
- **应用**：颜色+样式代称（红色过膝袜 / 黑色短袜 / 军靴）
- **历史教训**：v3 规范曾误写"白袜 vs 品牌名"，已被删除（用户明确要求）

## 五、边界违规处理

### 违规 1：出现女性角色
- **处理**：删除 / 转男性 / 询问用户
- **示例**：4.4 裆能战记母亲 → 仅作为伏笔工具，不出场

### 违规 2：重口血腥
- **处理**：降级为轻-中度 / 删除 / 询问用户
- **示例**：内脏描写 → 改为"伤口"或删除

### 违规 3：真实品牌名
- **处理**：删除 / 用代称 / 询问用户
- **示例**：Nike → "运动鞋" 或 "白色运动鞋"
