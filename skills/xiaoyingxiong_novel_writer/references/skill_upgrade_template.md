# SKILL 升级建议模板（Skill Upgrade Suggestion Template）

> **本文件用途**：v2 SKILL 升级建议的**统一规范模板**。所有"v2 SKILL 升级建议"必须按本模板 5 必含元素给出。
> **提炼来源**：02 笔记 §7.5-7.6（5 必含元素 + 12 步核心执行步骤）+ 03 笔记 E.1-E.5（10+10+10+10+10 升级项 5 字段）+ 06 笔记 5 条升级项。
> **使用范围**：所有深度阅读笔记（01-08+09）末尾的"§七 v2 SKILL 升级建议汇总"小节。

---

## 一、5 必含元素（v2 SKILL 升级建议标准格式）

每条 v2 SKILL 升级建议**必须**包含以下 5 个字段（缺一不可）：

### 1.1 字段 1：新增/扩展的具体内容

**格式**：
```
- 在 `references/{文件名}.md` 末尾追加章节「## {章节标题}」
- 具体追加内容：{具体描述}
- 涉及的关键元素：{X 个原型 / Y 个公式 / Z 个 XP 标签}
```

**示例**：
```
- 在 `references/character_archetypes.md` 末尾追加 **A1-A34 角色原型**
- 每条原型包含完整人设、关系、调用条件
- 涉及 34 个角色原型
```

### 1.2 字段 2：结构/字段/模板（YAML 字段定义）

**格式**：
```yaml
{字段名_1}: {类型}  # 说明
{字段名_2}: {类型}  # 说明
{字段名_3}: {类型}  # 说明
...
```

**示例**：
```yaml
外观标签: enum  # 白皙/麦色/异国/矮小
家庭背景: text  # 家庭不幸/被收养/单亲
性格特征: enum  # 傲娇/温顺/萌/孤僻
被强制方式: enum  # 催眠/榨精/调教/绑定
自我说服曲线: enum  # 5 阶段 / 3 阶段 / 渐进式
```

### 1.3 字段 3：示例/用法/触发条件

**格式**：
```
触发关键词：{用户输入的关键词列表}
调用场景：{什么情况下使用}
输入示例：「{用户可能输入的句子}」
输出示例：「{skill 生成的输出}」
```

**示例**：
```
触发关键词：["白皙", "嫩感", "家庭不幸", "问题少年", "正太"]
调用场景：03 子类作品的"问题少年"主角设计
输入示例：「写一个白皙少年，家庭不幸，被反派强制成为肉便器」
输出示例：调用 character_archetypes.md 的"问题少年正太"原型 + vocabulary.md 的"白皙少年"描写词条
```

### 1.4 字段 4：与 v1 的差异

**格式**：
```
- v1 仅记什么：{v1 的状态}
- v2 必含什么：{v2 的新增}
- 升级幅度：{百分比 / 绝对值}
- 填补空白：{v1 缺什么，v2 补什么}
```

**示例**：
```
- v1 仅记：12 个 A1-A12 角色原型（战队英雄为主）
- v2 必含：34 个 A1-A34 角色原型（战队英雄 + 现代正太 + 修真少年 + 奇幻骑士长）
- 升级幅度：+183%（12 → 34）
- 填补空白：v1 缺乏"现代校园正太"、"成年职业反派"、"修真少年"等专门模板
```

### 1.5 字段 5：Skill 实际生成时的调用方式

**格式**：
```
- 在 `references/{文件名}.md` 末尾追加章节标题：「## {章节标题}」
- 在 `references/{配套文件名}.md` 同步新增 / 修改：「## {配套章节标题}」
- Skill 触发规则：检测到用户输入包含 [{关键词 1}, {关键词 2}, ...] 时，**完整调用** {新章节}
- 调用优先级：{高/中/低}（高 = 必含；中 = 建议；低 = 可选）
```

**示例**：
```
- 在 `references/character_archetypes.md` 末尾追加章节：「## A. 主角原型 - 现代校园正太子模板」
- 在 `references/vocabulary.md` 同步新增：「## 词条 - 白皙少年描写」
- 在 `references/plot_templates.md` 同步新增：「## T7-A 夏日赌约模板」
- Skill 触发规则：检测到用户输入包含 ["白皙", "嫩感", "正太", "家庭不幸", "问题少年"] 时，**完整调用** 现代校园正太子模板
- 调用优先级：**高**（03 子类作品必含）
```

## 三、使用规则

### 3.1 必含项（高优先级，v2 SKILL 必须有）
- **5 必含元素 5/5**（任何 1 个缺则视为不完整）
- **12 步核心执行**中至少 1 步（不必 12 步都做，但每批至少 1 步）
- **引用具体文件路径**（如 `references/character_archetypes.md`），**不能**只说"角色原型"
- **引用具体章节标题**（如 `## A. 主角原型 - 现代校园正太子模板`），**不能**只说"新增加正太"

### 3.2 建议项（中优先级）
- **字段 4 与 v1 差异** — 量化升级幅度（百分比或绝对值）
- **字段 5 调用优先级** — 标注高/中/低
- **多参考文件协同** — 一条升级可能涉及 2-3 个 reference 文件

### 3.3 可选项（低优先级）
- **配套词汇 / 场景钩子** — 在 vocabulary.md / scene_hooks.md 同步新增
- **跨类型桥梁** — 在 cross_subtype_bridges.md 新增
- **多级堕落 / 三层叠加** — 在 multi_level_corruption.md / three_layer_xp.md 新增

### 3.4 禁用项
- ❌ "不读 R-18" / "不进 Skill 自动生成管线" / "不直接进入 v2 SKILL 自动生成管线的女主中心内容" — **删除**
- ❌ "父辈记忆覆盖" / "玩具化" / "跨物种（魔物代替触手）" / "兽型/植物型代替触手" / "父子（精神）乱伦" / "父子（记忆覆盖）乱伦" / "精神父辈" / "父子（养父）" / "父子乱伦" / "父子关系（特殊型）直接血缘" / "掏裆 + 紧身裤" — **必须删除**（参 优化规范 v5.1 + 工作文档 §0.2）

## 五、本模板与 v11 详细化升级版流程的结合

- **写"§七 v2 SKILL 升级建议汇总"小节时** — 必须按 5 必含元素 5/5 格式

### 5.2 sub-agent 使用本模板

- **每条升级建议至少 100 字**（覆盖 5 字段）

### 5.3 验证清单
- [ ] 5 必含元素 5/5 完整

## 七、与优化规范 v5.1 的协同

### 7.1 优化规范 v5.1（笔记清理）
- **不**做 XP 命中查询

- **优化规范** = 写**笔记内容**的规范（清理掉"命中查询"等冗余）
- **升级模板** = 写**SKILL 升级建议**的规范（必须按 5 必含元素）
