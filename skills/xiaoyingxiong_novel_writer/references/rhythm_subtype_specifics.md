# 节奏子类型特化（Rhythm Subtype Specifics）

> 本文档基于 8 部"战队特摄"100% 实读 + 11 部主线语料提炼。提供"子类型 → 节奏模板"的特化规则。

---

## 一、节奏 4 大基础模板

### 模板 1：单反派长程沦陷
- **适用子类型**：01 + 04 + 06
- **节奏**：5-10 章 / 1 个沦陷阶段 / 24 章内完成
- **代表**：4.2 超级战队收集（21 章 / 5 战士 / 5 阶段堕落循环）

### 模板 2：多人物多线收束
- **适用子类型**：01 + 05 + 08
- **节奏**：3-5 主角线 / 多反派 / 集中引爆
- **代表**：4.4 裆能战记（5 人物线 / 4 子段 / 28 章）

### 模板 3：双英雄对称 + 同堕落
- **适用子类型**：01 + 05 + 04
- **节奏**：双主角同时被俘 / 互相攻击
- **代表**：4.1 高弹（白曜 + 顾烨皓）、5.1 龙骧（蜃煌 + 哥哥）

### 模板 4：穿越者养成 + 反差权威
- **适用子类型**：01 + 04 + 06
- **节奏**：穿越者提前布局 / 长期养成
- **代表**：5.4 超能 kk（苏贺提前布局养成白昊）

## 二、9 大子类型节奏特化

### 01 战队（标配）
- **章节结构**：训练 → 任务 → 战斗 → 被俘 → 调教 → 转化
- **章数**：24-30 章（单卷）/ 100+ 章（系列）
- **关键节点**：
  - 第 1-3 章：战队登场
  - 第 4-10 章：反派介入
  - 第 11-20 章：调教循环
  - 第 21-25 章：高潮 / 收束
  - 第 26+ 章：番外 / 续篇

### 02 喜剧（喜剧情色）
- **章节结构**：训练 → 喜剧 → 反派被逗乐 → 喜感堕落
- **章数**：8-12 章（短篇）
- **关键节点**：
  - 第 1-2 章：战队登场 + 反派登场
  - 第 3-8 章：怕痒 / 反讽 / 喜感堕落
  - 第 9-12 章：等价交换 / 反派叛变 / 喜剧情色高潮

### 03 反派（反派恶堕 / 心理深度）
- **章节结构**：反派登场 → 系统化调教 → 反派心理展开 → 反派自毁 / 叛变
- **章数**：12-24 章
- **关键节点**：
  - 第 1-5 章：反派心理展开
  - 第 6-15 章：反派系统化调教
  - 第 16-20 章：反派自毁 / 自我牺牲
  - 第 21-24 章：反派叛变 / 加入主角方

### 04 调教（系统化精神控制）
- **章节结构**：植入 → 渗透 → 仪式化 → 锁精三件套 → 滚雪球
- **章数**：20-30 章
- **关键节点**：
  - 第 1-3 章：植入（欲珠 / 芯片 / 印记）
  - 第 4-10 章：渗透（学长 / 教官 / 反派）
  - 第 11-20 章：仪式化（紧身衣 / 贞操锁 / 触手）
  - 第 21-25 章：锁精三件套 + 滚雪球
  - 第 26-30 章：高潮 / 收束

### 05 兄弟（双主角同堕落）
- **章节结构**：兄弟登场 → 同被俘 → 互相攻击 → 同沦陷
- **章数**：12-24 章
- **关键节点**：
  - 第 1-3 章：双主角登场
  - 第 4-10 章：同被俘
  - 第 11-15 章：互相攻击 / 反派利用
  - 第 16-24 章：同沦陷 / 兄弟情深反差

### 06 主仆（反派主导 / 反派第一人称）
- **章节结构**：反派系统化 → 主仆仪式 → 长期控制 → 反派心理展开
- **章数**：20-30 章
- **关键节点**：
  - 第 1-5 章：反派系统化（5 阶段）
  - 第 6-15 章：主仆仪式（紧身衣 / 贞操锁 / 控制芯片）
  - 第 16-25 章：长期控制 + 反派心理展开
  - 第 26-30 章：高潮 / 反派自毁 / 主角反杀

### 07 同人（二创 / 跨作品衍生）
- **章节结构**：原作角色登场 → 二创情节展开 → 同人化解读
- **章数**：8-20 章
- **关键节点**：
  - 第 1-3 章：原作角色 + 二创设定
  - 第 4-15 章：二创情节展开
  - 第 16-20 章：同人化高潮

### 08 触手（触手怪人 / 异种生物）
- **章节结构**：触手怪人登场 → 触手束缚 → 触手科技反差 → 触手高潮
- **章数**：12-24 章
- **关键节点**：
  - 第 1-3 章：触手怪人登场
  - 第 4-10 章：触手束缚
  - 第 11-18 章：触手科技反差（触手椅 / 触手地毯 / 触手剃须刀）
  - 第 19-24 章：触手高潮 / 多功能

### 09 足控（足部特化）
- **章节结构**：足部特写 → 雄臭描写 → 战靴脱下 → 踩踏 / 足部高潮
- **章数**：8-16 章
- **关键节点**：
  - 第 1-3 章：足部特写
  - 第 4-8 章：雄臭 / 战靴
  - 第 9-12 章：踩踏 / 足部高潮
  - 第 13-16 章：足控收束

## 三、节奏组合应用

### 01 + 04 + 08（标配 3 件套）
- **节奏模板**：战队 (01) + 调教 (04) + 触手 (08) = 24-30 章
- **关键节点**：训练 → 任务 → 战斗 → 被俘 → 触手束缚 → 调教循环 → 高潮 → 收束
- **代表**：4.1 高弹、4.2 超级战队收集、4.3 超级战士、5.1 龙骧、5.2 天装

### 01 + 04 + 06 + 08（4 件套）
- **节奏模板**：战队 (01) + 调教 (04) + 主仆 (06) + 触手 (08) = 30+ 章
- **关键节点**：在 3 件套基础上加入主仆仪式（紧身衣 / 贞操锁 / 控制芯片）
- **代表**：4.4 裆能战记（4 件套 + 兄弟 + 喜剧 + 反派 + 同人 = 8 件套极限）

### 01 + 02 + 04（喜剧情色 + 调教）
- **节奏模板**：战队 (01) + 喜剧 (02) + 调教 (04) = 12-20 章
- **关键节点**：训练 → 喜剧 → 反派被逗乐 → 喜感堕落 → 高潮
- **代表**：4.3 超级战士（喜剧情色 + 反派叛变）

### 01 + 05 + 09（兄弟 + 足控）
- **节奏模板**：战队 (01) + 兄弟 (05) + 足控 (09) = 12-20 章
- **关键节点**：兄弟登场 → 足部特写 → 兄弟同堕落
- **代表**：5.3 超星（竹马 + 催情菌魔 + 喷乳）
