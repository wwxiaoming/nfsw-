## F. 禁忌词清单

### F1. 完全禁止（不可出现）

- 直白医学诊断名词（"插入""阴茎""阴道"等过干叙述）——使用 R-18 词汇（"肉棒""后穴"等）
- 法律相关词（"犯罪""报警""未成年人保护""法定年龄"等）
- 真实地理名（使用虚构地名）
- 真实品牌名作反派名（用"TD 公司""彗星组织""秽魔神"等）
- 真实人名（特别是真人偶像 / 演员 / 公众人物）
- 政治敏感词（"国家""政府""总统"等）
- 种族 / 民族歧视性词汇
- 任何与真实社会事件相关的暗示

### F2. 应当避免（降低出现频率）

- 暴力动词过密（"杀""打""揍""砍"）——降低到每千字 1-2 次
- 重复用词（"淫乱""色情"等连续使用）——使用同义词替换
- 过长的技术说明（武器参数 / 战斗流程）——控制在 100 字内
- 议论性段落（说教 / 评价 / 评论）——避免直接议论
- 现代生活词（"手机""微信""外卖"等）——使用虚构设定替代
- 现实主义词汇（"工资""房租""上班"等）——使用虚构世界观

### F3. 谨慎使用（需要情境配合）

- "强制""被迫"——必须有"拒绝 + 反抗 + 失败"的递进
- "调教""凌辱"——必须有具体动作支撑
- "意识改写"——必须有"被催眠 / 被洗脑 / 被药物"的具体场景
- "身体改造"——必须有科学 / 异世界 / 触手等合理化设定
- "公开战败"——必须有队友 / 公众目击的具体场景

## H. 命名规则

### H1. 主角命名

- **中国风**：姓 + 名（双字 / 三字），常用"洛""麟""岚""风""渊""笙""云""轩"
- **示例**：凌千洛 / 苏玄麟 / 夜天岚 / 公输世风 / 柳尘渊 / 烨笙 / 苏云轩
- **战队系列**：角色名应有"战队"图腾（"龙骧"五龙全带"龙"字；"帝王"七 S 级带元素名）

### H2. 反派命名

- **成年反派**：姓 + 名（成熟稳重）
- **示例**：敏寒之 / 季伯常 / 苏云轩 / 阚泽
- **非人反派**：物种名（"触手怪人""彗星组织""秽魔神"）
- **学生反派**：姓 + 名（年轻化）
- **示例**：阿雷 / 刺头 / 大壮 / 猴子

### H3. 称号系统

**主角的沦陷前 → 沦陷后称号**：
- 凌千洛（应龙）→ 贱屌应龙
- 凌问天（祖龙）→ 足控 / 嫩足痒奴
- 牧北辰（圣阳）→ 精奴
- 凯风（时空）→ 犬奴
- 暮黎（龙渊）→ 性畜精奴

**规则**：
- 沦陷后称号应包含：原身份 + 沦陷特征 + 性化标签
- 避免完全无意义的下流词
- 称号应能被反派 / 队友使用，并产生"心理冲击"

### H4. 团队 / 组织命名

- **战队名**：「龙骧」「帝王」「光莲」「进化」「超人暂存」
- **反派组织**：「彗星组织」「TD 公司」「魔神会」「神鹰小队」
- **世界设定**：「奥义学院」「朝云市」「龙腾共和国」「帝都」「魔都」
- **协会**：「朝云市少年英雄协会」「协会后勤大人们」

### H5. 物品 / 道具命名

- **淫纹**：「X 之纹」「主人之印」「所属之纹」
- **项圈**：「X 的项圈」「专属项圈」
- **贞操锁**：「X 之锁」「所属之锁」
- **武器**：「银长枪」「银白短匕」「粒子爆破」「机械星辉」
- **战衣**：「蓝色紧身战斗衣」「薄膜战衣」「乳胶战衣」
- **能量源**：「精源」「Z 纯晶」「星辰之力」「光能」
