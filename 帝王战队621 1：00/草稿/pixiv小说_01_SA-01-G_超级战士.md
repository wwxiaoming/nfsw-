## 4.3 《超级战士》by blue sky

> 来源: /workspace/帝王战队621 1：00/pixiv小说/01_战队特摄/超级战士/
> 实际读: 8/8 章 (100%)  写入段: 4.3

### 作品定位

**同人 / 战队 / R-18 / 喜剧情色 / 怕痒调教 / 大学生 vs 外星科技博士 / 紧身衣"过紧"**

**blue sky** 2019-2022 跨 3 年创作的**长篇连载同人**。Pixiv 8 章 239.4KB，喜欢数稳定在 135-303 区间（终章 303 最高，序章 662 最高），平均喜欢 250+——**这在 R-18 同人里是高质量 + 稳定读者群**的标志。

作品把"都市传说第 32 条：每当城市陷入巨大危险就有正义英雄" 设定为**真实事件**，并把超级英雄 / 外星入侵者 / 跨物种调教三件套**用一种"沙雕 + 重口"的混合笔调**写出来。叙事上有大量**反差萌**——肖骁教授（外星科技首脑，160 不到） vs 乔澜（超级战士，191cm 大个子）的体型差 / 地位差 / 知识差反转。

**目标读者**：
- 战队控 + 紧身衣爱好者
- 怕痒（腋下 / 乳头 / 腰 / 足底）+ 羽毛 / 软毛刷调教师
- 喜剧情色爱好者（与"全程黑暗"的天装战队护星红形成对比）
- "反差萌" 爱好者（矮小知识型 vs 高大体格型）

**XP 命中清单**（按强度）：
- **第一优先**：紧身衣战队（红色 + 白色描边 + 头盔）、怕痒调教（腋下/乳头/腰/足底全覆盖）
- **第二优先**：足控（白袜 + 白靴 + 足底被挠）、大学校园背景（学生被外星教授玩弄）、喜剧情色
- **第三优先**：反英雄（超级战士被玩到哭着求饶）、榨精（每次调教都以射精收尾）、同性向（破坏军团高层全是男性）

### 关键章节（按叙事功能选 6 个）

- **#1 序章（25.5KB）**：乔澜在老宅储物间意外发现变身腰带 + 红晶片。**第一次变身测试**——191cm 壮汉 + 红色紧身衣 + 头盔 + 白色长手套长靴。**变身解除的条件被故意设置成"戴着头盔射精"**（说明书用最不显眼的白色小字写在最下面），制造了一个**永远绕不开的色色循环**。然后杰诺斯（紫色皮肤外星人）来挑战，**第一次被"淫荡泥球"（黏在奶头/腋下/裆部的痒痒触手）玩到喷射**。**全作最重要的"母题"在这一章全部立起来**。
- **#2 第一章：开端（37.8KB）**：乔澜在大学校园偶遇"肖骁教授"——这位是被破坏军团派来地球潜伏的**科技首脑**。乔澜跟踪肖骁 → 第一次变身潜入别墅 → 偷听到肖骁和杰诺斯的对话：**杰诺斯要杀超级战士 → 肖骁紧急召唤杰诺斯（"打雷"）救了乔澜**。然后乔澜去废弃别墅找杰诺斯 → **被 1 号 2 号用羽毛 + 抓吊 + 痒痒调教 + 强逼喊"杰诺斯大人万岁" + 强逼"我想成为杰诺斯大人的性奴"**。**肖骁突然出现救他——但方式是把超级战士按在自己地下室的实验椅上。**
- **#3 第二章：刚出狼窝，又入虎口（22.3KB）**：乔澜在肖骁地下室被严刑逼供——"你鸡巴勃起时多少厘米？"（标准答案 19cm）"你叫什么名字？"（标准答案 乔澜）。**肖骁一开始问的还是"拷问"，但语气越来越轻快**——他注射了镇静剂让乔澜昏睡，然后用"一见钟情"为借口叛出破坏军团。**这一章是"反英雄主角遇到科技首脑" 的起点**，也是"破坏军团内部矛盾外化" 的导火索（杰诺斯越级上报 → 总司令介入 → 科技经费纠纷）。
- **#4 第三章：一见钟情水（27.9KB）**：**全作最反差萌的一章**。肖骁 1) 用"化学喷雾"在乔澜战衣上开了几个洞（露出奶头 / 大腿内侧）2) 在肛门塞了跳蛋 3) 把"一见钟情"烟雾弹放在乔澜破门的必经之路上**让肖骁自己吸入**。然后肖骁开始**絮絮叨叨地边玩奶头边汇报"我对你一见钟情"**——"为什么和破坏军团决裂？因为我对你一见钟情啊"。"为什么叛变？因为老板不发工资了下属要和老板对着干"。"我需要你"。**全章在"喜剧情色 + 卖萌 + 反差"中完成"科技首脑收编超级战士" 的关键转折**。
- **#5 第四章：合作（20.5KB）**：肖骁向乔澜正式介绍**破坏军团**（17 部队 / 总司令 / 副司令 / 团长 / 队长结构 + 黯星球 = 平行世界）→ 作为"等价交换情报"，肖骁**要求乔澜去地下室被玩奶头，乔澜提问，肖骁回答**。"你来自哪里？""平行世界，叫黯星球"。"破坏军团是什么？""政府"。"为什么要入侵地球？"**肖骁答不出来 → 困了 → 上楼睡觉**。**这一章把"科技首脑 + 超级战士 = 嘴上调情 + 暗中结盟"的关系定型**。
- **#6 第五章：论解除变身的步骤（23.5KB）**：乔澜研究"为什么无法解除变身" → 发现**必须戴着头盔射精**。肖骁立刻设计"挤奶行动"——戴着乔澜的头盔 + 跨坐在乔澜身上 + 全方位机械臂/羽毛攻击。乔澜在多重刺激下射出 → 变回普通人。**然后肖骁骗乔澜搬出宿舍住进自己家——同居正式开始**。
- **#7 第六章：首战告捷？（34.9KB）**：乔澜第一次正式出任务——追到良源旧街的废弃大楼。3 号（破坏军团外星杂兵）给他看了一团"黄色泥状物"（**改良版淫荡泥球**），然后 3 号用"4 号大人万岁" 的口令炸开烟雾逃跑。乔澜被 7 团泥球同时进攻——**奶头 / 腋下 / 腰 / 大腿内侧 / 龟头 / 阴囊 / 腹股沟全覆盖**。**全作最系统的"全身怕痒 + 全身性化"描写**，最终乔澜喷出后解除变身。
- **#8 第七章：落入陷阱，超级战士沦陷大危机（48.8KB）**：3 号逃回 4 号（白大褂 + 金丝眼镜 + 斯文学者型外星科学家）那里 → 4 号调监控看到乔澜脸 → 4 号对"入侵地球"产生怀疑（"这一切不都是总司令的一家之言吗？"）。**然后 4 号精心设计陷阱抓乔澜**——粉色烟雾 + 针筒 + 在老宅设局。乔澜在刑椅上被：1) 脱头盔 2) 玩奶头 3) 玩腋下 4) 玩足底 5) 玩腰 + 6) 套上金属环不让他射精 7) 4 号躲在监控后面念叨"博士想要知道你出事了起码也得等到星期一" 等"心理战台词"。**乔澜撑了五六个小时**才崩溃说出"我是超级红战士乔澜……超级红战士乔澜愿意臣服于4号大人"。**这一章的"心理战 + 物理刑讯" 配合是全作最高水准**。

### 核心套路（按出现频率）

1. **怕痒 = 主轴**：全作 80% 的性化场景是"痒"——腋下 / 乳头 / 腰 / 大腿内侧 / 足底 / 腹股沟。**和天装战队护星红的"痛"（阉割/电击/失禁）形成完美对比**。
2. **战衣"过紧 + 透明化描边"**：每次出场都强调"战衣将 JJ / 奶头 / 胸肌轮廓都清晰勾勒出来"，而且**勃起后战衣会自动"匀出布料贴合"JJ 的每个细节（系带、冠状沟、血管）**——这是该作独有的设定。**这套"勃起时变衣不破衣"的机制**让超级战士在战斗中**最不希望勃起**（防御力下降、敏感度上升）。
3. **总司令 + 科技首脑 + 队长 + 杂兵** 的层级制度：总司令 > 副司令 > 科技首脑 ≈ 副司令 > 军委长 > 团长 > 队长 > 杂兵。**杰诺斯只是队长（倒数第二）**，而 4 号虽然只是"白大褂科学家"，但有独立实验室和 3 号当助手。**这套"职位不等于能力" 的反讽**是该作的笑点之一。
4. **肖骁的"一吻定情" + "越打越爱" 反差萌**：肖骁和乔澜的关系**从"拷问" → "调教" → "一见钟情" → "合作" → "同居"**——每一步都用喜剧情色包装。**最反差的是**乔澜大喊"我们是敌人！" → 肖骁说"因为你我对总司令一见钟情" → 乔澜懵掉。
5. **"杰诺斯" 永远被作者折腾**：名字被叫错（乔澜总叫"杰比斯"）→ 越级上报被总司令骂 → 想阴肖骁却被肖骁弹飞 → 想阴乔澜反被乔澜反杀 → 3 号抢走他的"性奴玩具"。**杰诺斯是喜剧担当 + 失败担当**。
6. **"解除变身的条件" 是叙事的"违规设计"**——每次想"冷静变回普通人" 都得在头盔下射精 → 越射越敏感 → 越敏感越想射 → 越射越不冷静。**这是个"内置的失控循环"**，作者用这个设定强行让英雄"永远不能干干净净脱战衣"。
7. **"等价交换" 的喜剧情色结构**：肖骁的"情报交易" 总是以"让我玩你 X" 为代价。**全作 6 次"交易" 全是喜剧情色**——这是该作最稳定的套路。
8. **4 号的"边监控边评数据" 的反派人设**：4 号在 #8 独自一人看夜视监控 + 念数据 + 戴耳机听现场声音。**这种"科研者看性虐实验" 的冷静 + 一点点小得意**是另一个反差萌的反派模板。

### 写作技法

1. **全知视角 + 大量内心独白**：作者**经常切换到乔澜或肖骁的内心 OS**——比如肖骁每次玩完乔澜都自我反思"为什么我语气这么欢快？是不是吃错药了？" 这种"自我吐槽" 的写法在 R-18 同人里是少见的。
2. **喜剧情色的精确节奏**：每个"重口" 场景后都有一段"日常" 缓冲——比如 #2 重口后 #3 一开始是校园日常 + 教授被同学追捧。**这种"重口 + 日常" 的交替**让读者不会一次性被内容压垮。
3. **军衔制度的"反讽" 用法**：杰诺斯作为"精英队长" 是破坏军团军衔制度的反派，但**作者明确写"杰诺斯混了这么多年还是个队长"**——把"精英" 的语义污染了。**这和总司令 / 副司令 / 团长**的高位形成反差。
4. **"紧身衣描边" 的精确化**：本作和天装战队护星红都是"紧身衣战队" 题材，但本作更精确化——**作者会用具体数字描述"勃起到什么程度"**（#1 "流出的前列腺液沿着阴茎的轮廓滴到睾丸的位置"），不像天装战队护星红那么"诗意化"。
5. **多线叙事**（#8 终章）：乔澜回老家 + 4 号 + 3 号 + 肖骁四条线平行推进。**这种在 R-18 同人里罕见的"群像结构" 让该作在主题上更完整**。
6. **"解除变身的条件" 作为叙事的金线**：从序章到第七章，这个条件一直被作者用各种方式绕过/解决/利用——是**该作最稳定的叙事钩子**。

### 跨作品对比

- vs **天装战队护星红**（同批 SA-01-G 另一部）：都是"战队 + 紧身衣 + 性化"题材，但**超级战士是 R-18 喜剧情色向**（怕痒 + 喜感 + 反差萌），**天装战队护星红是 R-18G 重度黑暗向**（公开处刑 + 阉割 + 失禁 + 父子宿命）。**前者是"超级英雄的喜剧后传"，后者是"超级英雄的黑暗解构"**。
- vs **超级战队收集计划**（同批 SA-01-E）：都是"战队 / 紧身衣" 题材，但**超级战士走"原创 + 大学生主角" 的轻松路线**，超级战队收集计划是"战队 + 收集" 的更系统化玩法。
- vs **裆能战记系列**（同批 SA-01-A/B/D/F）：**超级战士**和裆能战记都重度使用"紧身衣描边" 和"调教"，但**超级战士加入了"喜感"和"军衔制度反讽"**——比裆能战记多了一层"轻喜剧" 的皮。
- vs **【龙骧战队】二创**（同批 SA-01-H）：**超级战士**的紧身衣战队向 + 喜剧情色 + 调教元素 + 大学生主角 vs 龙骧战队二创的战队二创。两者在"战队的同人 R-18 化"上是一致的，但 IP 来源不同。
