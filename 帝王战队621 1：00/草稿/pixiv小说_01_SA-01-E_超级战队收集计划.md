### 一、作品定位

《超级战队收集计划》是一部**反派视角主导的超级战队堕落向同人 H 小说**，以"Pixiv 中文 R-18 战队特摄"子类中典型的「**敌役一方逐个捕获并堕落正派战队成员**」为母题。

核心卖点：
- **敌役主角第一人称驱动**：反派幻梦（林毅）以「收集者」姿态登场，每一章捕获一名圣兽战士，逐个击破、逐个改造、令其反过来攻击同伴——形成「滚雪球式堕落链」。
- **紧身衣 + 体格差 + 反差堕落**：以紧身战斗服为视觉锚点，主角团队身材设定全面模板化（鲨鱼肌 / 牛 / 大象等圣兽化身体），反派相对身材更瘦削，靠"异能 + 计谋 + 精神控制"以小博大。
- **"队友间被迫服从"的伦理冲突**：每一章都制造"为了某人而牺牲自己"的伦理绑架（圣兽绿为救队友被俘 / 圣兽黑为救绿单刀赴会 / 圣兽蓝被队友色诱等），把"堕落"包装为"无奈的牺牲"，以此降低读者对角色堕落的心理抗拒。
- **机械式调教道具轮换**：从狗链、口球、贞操锁、束茎环、跳蛋、飞机杯、尿道棒到洗脑仪、电椅、催眠眼镜、马眼电击棒等，**几乎每章都换一套 BDSM 道具**，形成"调教工具图鉴"式的视觉密度。

目标读者：战队特摄爱好者 + 紧身衣 + 反派主导 + 调教 + 恶堕标签的复合读者群。中文 R-18 同人类战队题材的"以反派为第一主角"套路代表作之一。

### 四、核心套路（10 条）

1. **「欲珠/灵药式」开局**：反派以乳白色珠子（欲珠/能量液/乳白药）植入或喂食主角团成员，作为后续「任意时刻发情/听令」的伏笔。**变体**：第 9 章「能量液」= 弟弟精液（被强喂）、第 16 章「乳白液体」= 24 小时敏感度反弹药水。
2. **「学长/熟人/卧底」渗透模板**：反派以「同校学长」（#3 王民线）、「受伤回归队友」（#13 王力线）、「贴心兄弟」（#16 王力帮沈涛特训）三种身份逐个接触正派。**关键设计**：用「无血缘兄弟」包装（王力认王民为弟弟）放大"背叛"的情感冲击。
3. **「人质威胁 + 伦理绑架」**：反派以"你队友的命在我手里"为反复套话，让正派成员"为了某人主动献身"。**3 次循环**：第 2 章（救城市平民）、第 4 章（救假人质）、第 8 章（救王民）。
4. **「狗链 + 紧身衣 + 跪地」仪式化堕落**：每一名正派成员堕落的视觉标志 = 紧身衣 + 项圈 + 跪在反派脚边。**第 7 / 11 / 12 / 13 章都出现完全相同的构图**。
5. **「困龙锁 / 束茎环 / 贞操锁」性控三件套**：通过外部物理约束压制射精，用「延后再释放」制造极端快感堆积。**第 4 章困龙锁 → 第 9 章束茎环 → 第 11 章贞操锁**形成"锁具升级链"。
6. **「能量守恒 + 精液供能」设定**：圣兽战士的精液 = 高纯度能量（#3 提到"能量含量比得上数百个成年男性"），反派通过榨取精液同时满足「堕落 + 力量采集」双重目的。**典型 RPG 化设定**。
7. **「洗脑 / 精神控制 / 记忆修改」三段式心理瓦解**：
   - 阶段 1：欲珠植入 / 身体敏感化（物理）
   - 阶段 2：困龙锁 / 录像威胁 / 反复插入（心理）
   - 阶段 3：洗脑头盔 / 催眠眼镜 / 现实扭曲（精神）
   三阶段在圣兽绿（第 2-7 章）和圣兽黑（第 8-12 章）身上**完全复刻**。
8. **「以子之矛攻子之盾」队友互攻**：圣兽黑被堕落 → 圣兽黑亲自去捕获圣兽蓝；圣兽绿被完全堕落 → 圣兽绿亲自给哥哥戴洗脑头盔。**核心伦理冲击点**。
9. **「道具图鉴」密度**：21 章出现的 BDSM / 调教道具包括——狗链、口球、贞操锁、束茎环、跳蛋、飞机杯、尿道棒、困龙锁、羽毛、木棒、电椅、电极片、磁力球、震动棒、洗脑仪、催眠眼镜、马眼棒（带电击）、催眠气体、注射器（乳头改造）、催眠眼镜、能量锁链、催眠手表、催眠手环……几乎每 2 章引入 1 个新道具。
10. **「角色内斗 + 反派反杀」节奏调节**：第 13 章西斯挑衅林毅被暴打 → 第 21 章西斯反杀林毅掏出心脏 → 圣兽虎替换庚金 → 史莱姆是绝恶王分身。**4 次反转让"反派无敌"在后期破裂**，避免套路僵化。

### 五、关键场景（5 个高光）

#### 场景 1：第 4 章「体育器材室·英雄游戏」（首次堕落标志场景）

- **角色**：林毅（学长伪装）vs 王民（圣兽绿 / 16 岁 / 175cm）
- **道具**：跳绳、跳马箱、困龙锁、羽毛毽子、木棒
- **情节链**：紧身衣扮演 → 狗链 → 跪下 → 爬行 → 舔脚 → 脚踩腹部 → 锁精 → 木棒敲龟头 → 崩溃求饶 → 释放
- **核心情绪**：羞耻 + 无奈 + 兄弟守护之名下的自我牺牲
- **可复用要素**：
  - "穿紧身衣扮演自己身份"是**身份暴露焦虑**的极致玩法
  - "困龙锁 + 羽毛 + 木棒三件套"可作为**T1-紧身衣型**子模板的固定工具组合

#### 场景 2：第 9 章「电椅 + 兄弟精液」（能量守恒设定的高峰）

- **角色**：林毅 vs 王力（圣兽黑 / 24 岁 / 182cm）
- **道具**：电椅、机械手、束茎环、乳头电极、睾丸电极、"能量液"
- **情节链**：跪地宣誓 → 坐电椅 → 5mA → 10mA → 乳头睾丸电极 → 失禁 → 强行灌能量液（=王民精液）→ 束茎环反弹 → 幻梦放出"王民正在被榨精"幻象 → 道德崩溃
- **核心情绪**：绝望 + 不知情饮下弟弟精液的伦理冲击
- **可复用要素**：
  - "被喂下自己不知情的亲人/重要之人身上的产物"是**BDSM 心理冲击**的最强套路之一
  - "电椅 + 束茎环 + 兄弟精液"三件套可作为**T1-榨精型**子模板的高阶变体

#### 场景 3：第 11 章「血乳交融 · 兄弟被迫相残」

- **角色**：王民 + 王力（兄弟 / 双奴隶）
- **道具**：中空玻璃管
- **情节链**：王民主动套项圈 → 林毅命令插入玻璃管连接两人马眼 → 王民被迫操王力 → 共同射精但因中空管逆流回睾丸
- **核心情绪**：兄弟乱伦禁忌 + 完全堕落（连"救"都变质为"陪你一起堕"）
- **可复用要素**：
  - "用空心管连接两人的器官"是非常少见的兄弟 H 设计，可作为**兄弟向**的极致变体
  - 王民自套项圈的反转（"被救者主动选择堕落"）打破"受害者"的刻板印象

#### 场景 4：第 16-18 章「健身器材调教 + 24 小时反弹」

- **角色**：王力（已堕落）vs 沈涛（圣兽蓝 / 22 岁 / 190cm）
- **道具**：推胸机刷桶、仰卧起坐板 + 滚轮、挠脚心、人形固定架、刷子模具
- **情节链**：特训借口 → 刷桶扫乳 / 挠脚心 → 喝反弹药水 → 24 小时后敏感度翻倍 → 困在刷桶模具中失禁 + 射精 → 抛弃运走
- **核心情绪**：信任崩塌（"特训"伪装）+ 怕痒弱点被利用
- **可复用要素**：
  - **「T1-足控型」子模板的极佳范本**：怕痒弱点 + 足心 + 全身滚轮联动
  - **「24 小时反弹药水」**：可作为"延迟生效型陷阱"的标准模板

#### 场景 5：第 21 章「多线收束 · 史莱姆分身揭示」

- **情节链**：林毅向绝恶王要圣兽战士所有权 → 西斯反杀林毅 → 圣兽虎反水（替换庚金）→ 史莱姆 = 绝恶王分身 → 牧俊白自爆式攻击 → 全员被俘
- **核心反转**：反派阵营的内部洗牌比"正派堕落"更复杂
- **可复用要素**：
  - **「阵营多层反转」**可作为长篇战队类的"中后期高潮"模板（避免反派无敌的乏味感）
  - 牧俊白"以身殉爆"是少数保留的"正派高光"，避免作品彻底阴暗收束

### 六、角色弧光（5 名正派 + 1 反派）

#### 反派：幻梦 / 林毅（18 岁 / 176cm / 林毅→幻梦）
- **起点**：林毅（龙城第一高中高二学生，被校园霸凌失手打死，被邪恶组织回收改造）
- **变化**：以"复仇 + 收集圣兽"为驱动，全程冷静、自恋、视圣兽为战利品；后期对圣兽蓝有"得不到的执念"（#21 独白"明明还没得到他"）
- **弧光**：**双面性设计**——白天是校园学长，夜晚是邪恶组织干部；**反派也有情感弱点的设定**（对圣兽蓝的特殊执念），但被西斯反杀导致复仇者陨落。
- **写作价值**：**罕见的"反派第一人称驱动"主角**，可作为反派向 H 的人设模板。

#### 圣兽绿 / 王民（16 岁 / 175cm / 高一 / 大象）
- **起点**：古武世家出身，马马虎虎，意志力低，篮球王牌
- **变化**：被幻梦灌欲珠 → 校园学长戏弄 → 体育馆狗链 → 俘虏 → 完全堕落
- **弧光**：**最完整的堕落曲线**（6 章完成），后期甚至主动给哥哥戴洗脑头盔——**堕落者从"受害者"转变成"加害者"**。
- **写作价值**：**适合作为 T1-紧身衣型 + 校园伪日常 + 恶堕的标准模板**。

#### 圣兽黑 / 王力（24 岁 / 182cm / 局长 / 牛）
- **起点**：退役特种兵 / 局长 / 认圣兽绿为弟弟 / 身体敏感
- **变化**：为救王民单刀赴会 → 被 12 小时榨精 → 戴项圈 → 吃弟弟精液不知情 → 反复电击 → 洗脑成"贱狗二号" → 奉命回基地卧底 + 调教圣兽蓝
- **弧光**：**"保护者堕落 + 反过来调教他人"**的双重背叛，最大化伦理冲击。
- **写作价值**：**T1-榨精型 + 兄弟羁绊型 + 卧底型**的综合模板。

#### 圣兽蓝 / 沈涛（22 岁 / 190cm / 鲨鱼）
- **起点**：游泳教练 / 狙击手 / 怕痒

### 七、反派机制分析

**主导手段**：
1. **精神控制 + 现实扭曲**（幻梦的核心异能）
2. **药物/珠子植入**（欲珠 → 敏感化 → 发情 → 听令）
3. **道具控制**（贞操锁 / 束茎环 / 困龙锁 / 洗脑仪 / 催眠眼镜）
4. **心理操控**（黑材料威胁 + 伦理绑架 + 假情报误导）
5. **队友互攻**（让堕落者反过来调教/攻击未堕落者）

**长程伏笔**：
- #3 提到"圣兽战衣有强大的防御机制" → #21 被林毅"钻了空子"破解
- #8 圣兽虎神秘出场 → #21 揭示为长期卧底
- #9 史莱姆博士的形象 → #21 揭示为绝恶王分身
- 林毅（幻梦）的"阿斯蒙迪斯吞噬"前史 → #21 仍被西斯反杀印证其"野心大于实力"的人设

**反脆弱设计**：
- 反派本身也会被反噬（#13 西斯挑衅被暴打、#21 西斯反杀林毅）
- 圣兽虎 / 圣兽白的"反扑"留下正派火种
- 整体**不追求反派绝对无敌**——保留"绝地反击"的张力

### 十五、写作技法观察

1. **POV 选择**：主反派（幻梦林毅）POV 为主 + 偶尔正派成员内心独白（#8 圣兽黑的愧疚、#16 沈涛的疑虑）
2. **节奏控制**：每 1-2 章完成一个"捕获-堕落"小循环，#14-21 进入"大决战"长循环，节奏张弛有度
3. **伏笔回收**：21 章中至少有 6 处长程伏笔被回收（#1 圣兽虎身份、#1 圣兽黑出身孤儿院、#3 欲珠能力解释、#9 精液能量守恒、#13 西斯挑衅、#21 史莱姆分身）
4. **视角选择**：本作选择"反派第一人称"是较罕见的设计，让读者**直接代入施虐者视角**，对战队 / 紧身衣爱好者有特殊吸引力

### 总结

《超级战队收集计划》是 Pixiv 中文 R-18 战队特摄类中**反派主导堕落向**的代表作之一。其价值在于：

1. **结构化**：5 阶段堕落循环 + 6 个角色逐一处理，可作为长篇战队类的剧本骨架
2. **道具密集**：21 章使用近 20 种 BDSM 道具，形成"调教工具图鉴"密度
3. **设定统一**：精液能量守恒 / 欲珠觉醒 / 圣兽动物化三套设定互不冲突且互相强化
4. **伦理极限**：通过"非血缘兄弟""假人质""为救某人主动献身"等设计最大化堕落冲击
5. **可改进点**：中后期反派阵营反转稍显仓促、#14-15 圣兽白/红处理略少、最终决战未完结（等 #22）

**推荐用于**：战队 / 紧身衣 / 反派主导 / 调教 / 恶堕 / 兄弟复合 XP 读者的**主模板库**级别作品。
