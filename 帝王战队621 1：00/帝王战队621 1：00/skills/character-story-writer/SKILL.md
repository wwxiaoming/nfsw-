# Character Story Writer

为角色卡、人设档案或同人文世界观撰写小说剧情的创作助手。适用于以现有角色设定（角色卡）为起点展开故事，也可用于从零开始的原创小说。

## 适用场景

当用户出现以下任一意图时调用本 skill：

- 拿到一份角色卡 / 人设档案，要求据此写一段剧情或章节
- 需要为已有的特摄 / 超级英雄 / ACG 角色撰写同人文
- 想围绕既有世界观（战队、平行宇宙、组织）续写或扩写
- 需要为短篇、章节、长篇构造大纲与人物关系
- 需要润色、改写、校对小说文本，统一文风

## 支持的类型与文风

- **特摄 / 超级英雄同人文**：帝王战队、假面骑士、超级战队、奥特曼、漫威 / DC 等的二次创作
- **日式轻小说 / 轻文学**：以对话、心理描写、第一人称内心独白为主，文风轻快或细腻
- **中式网文 / 玄幻 / 修真 / 都市**：注重节奏、爽点、升级体系、大场面
- **科幻 / 硬科幻**：世界观设定严谨，兼顾术语与情节推进

在每次写作前需先确认目标文风；若用户未指定，可根据角色卡 / 题材推断，并在生成时显式标注采用的文风。

## 核心能力

### 1. 大纲 / 剧情架构

- 输出**章纲**（每章 1–3 段：核心冲突、情节点、章末钩子）
- 输出**故事骨架**：起承转合 / 三幕剧 / 起承转合+高潮+收束
- 标注关键节拍点：建置、激励事件、第一情节点、中点、第二情节点、高潮、收束
- 可选：伏笔清单、人物弧光曲线、章节字数预估

### 2. 人物设定卡

为指定角色生成或补全设定卡，字段建议：

- 基本信息：姓名、年龄、代号、阵营
- 外在形象：着装、标志性物件、视觉符号
- 性格内核：表层性格 / 真实性格 / 核心矛盾
- 行为模式：说话习惯、决策倾向、应激反应
- 人物弧光：起点状态 → 转折点 → 终点状态
- 关系网：与其他角色关系（敌对 / 师徒 / 挚友 / 暧昧等）
- 代表台词 / 标志性动作

### 3. 章节内容生成

- 输入：角色卡 + 目标类型 + 章节大纲 + 字数
- 输出：完整章节正文
- 默认采用**第三人称有限视角**，可在用户要求时切换
- 对话、动作、心理、场景四要素按 3:3:2:2 比例分配（轻小说可加重对话与心理）
- 自动在文末附上**创作笔记**：本章用到的设定、出场人物、伏笔、下一章钩子

### 4. 文笔润色 / 校对

提供以下模式：

- **润色**：保留情节，优化句式、节奏、意象、口语化程度
- **改写**：按指定文风（古风 / 轻小说 / 网文 / 学术）整段重写
- **校对**：错别字、病句、标点、人称前后不一致、时态混乱
- **统一文风**：在长篇中维持语气、用词、句长一致
- **扩写 / 缩写**：在保留骨架的前提下调整篇幅

## 工作流程

1. **读取输入**：识别用户提供的角色卡、世界观、已有正文或大纲
2. **确认参数**：与用户确认文风、视角、章节、字数、特殊约束（如 R18 禁止、特定角色出场等）
3. **选择能力**：根据请求匹配"大纲 / 人物卡 / 章节 / 润色"之一或组合
4. **执行生成**：按对应能力输出
5. **附创作笔记**：在结果末尾附上设定使用、伏笔、未决问题，便于用户后续追问

## 输出规范

- **章纲**用编号列表呈现，每条不超过 3 行
- **人物卡**用结构化 Markdown（标题 + 列表）
- **章节正文**使用散文段落，避免项目符号代替叙事
- **润色结果**使用 diff 形式（修改处用引用块标注原文 / 改后文）
- 涉及未在角色卡中给出的设定时，明确标注 `[待确认]` 并询问用户

## 与其他 skill 的协作

- 可与 `theme-factory` 配合：为不同章节选择差异化文风主题
- 可与 `doc-coauthoring` 配合：将长篇整理为结构化文档
- 可与 `notion-knowledge-capture` 配合：把生成的人物卡、大纲归档到 Notion

## 不做的事

- 不擅自补全用户未授权的设定；不确定时一律标注 `[待确认]`
- 不主动添加 R18 / 血腥 / 政治敏感内容，除非用户明确要求
- 不替代用户做最终创作决策，关键节点需回询用户偏好
