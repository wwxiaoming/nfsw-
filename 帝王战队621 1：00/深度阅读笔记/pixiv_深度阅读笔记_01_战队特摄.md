"白曜"是一个 19 岁男青年，因家境贫困被反派（凌夜）相中，被迫穿上一种"高弹紧身衣"以激发体内沉睡的"白龙之力"。紧身衣是**核心设定**：一旦穿上，胯下区域会被"绝对贴合"地包裹，因材质过敏反应（触觉神经增敏）导致射精阈值极低——这是白曜"无限能量"的来源，但也是他**最大的弱点**。白曜为了给妹妹治病而签下"高利贷"式契约，**主角动机=经济压力+妹妹医药费**，是"不得不为"的灰色开局。

**第 2 段：胯下陷阱（#2、#5、#8、#11）**
反派的战术核心是**"胯下攻击"**：
- 凌夜设计"胯下刺激式"陷阱（#2 触手套 #5 踢裆部 #8 强制高潮至失禁 #11 注射类药物）
- 紧身衣一旦被抠裆/抓裆，会触发"能量脉冲"——把白曜的战斗能量反向吸出
- **核心公式**：紧身衣 + 胯下攻击 = 强制射精 + 战斗能量被抽走
- 这构成了"被战胜"的标准范式

**第 3 段：沉沦与驯化（#3、#7、#9、#13、#20）**
- #3 清洁室/浴室：白曜在自慰时被发现，被迫当众"教学"
- #7 沉沦：白曜开始主动享受胯下刺激
- #9 圈养战神：白曜被锁在笼中，被凌夜当宠物
- #13 戴项圈：白曜从战斗到驯化的视觉符号
- #20 自己戴上情趣道具：完成"从被迫到主动"的心理反转

**第 4 段：CP 线（#10-#12）**
- #10 新的伙伴"顾烨皓"出现，另一个穿紧身衣的战士，是**白曜的镜像 CP**
- #11 顾烨皓被哄骗，主动踏入反派陷阱
- #12 困于掌中巨龙：白曜与顾烨皓联手对抗凌夜，但**被反杀**
- 三人关系：白曜 ↔ 顾烨皓 = 战斗伙伴 + 暧昧（未点破）；凌夜 ↔ 白曜 = 主奴（带父子乱伦色彩，因为凌夜"塑造"了白曜的战士身份，类"养父"）

**第 5 段：反转线（#22-#23）**
- #22 顾烨皓堕落：被反派改造
- #23 凌夜翻车 / 顾哥反击：CP 反杀反派，是"反英雄向"结局
- 给读者"虽然被榨但最终反击"的爽感

#### 4.1.2 关键场景（5+）

1. **#2 初次交锋胯下**：白曜第一次任务，被反派**踩裆**触发强制射精 → 整个任务失败。**场景范式：紧身衣 + 踩裆 + 强制高潮 + 任务失败**。
2. **#3 清洁室/浴室**：反派在清洁室设置"胯下按摩器"，白曜被迫站立接受，被同事撞见，**当众勃起**。**场景范式：清洁室/浴室 + 工具刺激 + 当众 + 勃起曝光**。
3. **#5 苦战/危机**：白曜对抗另一只胯下怪（形如大蛇缠绕），被怪物的"尾巴"反复抠裆。**场景范式：跨物种（魔物代替触手） + 缠绕抠裆**。
4. **#8 首次败北**：白曜被多个反派围攻，被迫**戴铃铛项圈**示众。**场景范式：多人围攻 + 戴项圈 + 当众 + 锁链**。
5. **#11 哄骗顾烨皓**：反派伪装成"导师"，把顾烨皓引入实验室，**注射**类药物。**场景范式：伪装导师 + 注射 + 强行获得身体控制**。
6. **#20 自己戴情趣道具**：白曜已经"驯化完成"，主动把跳蛋、肛塞等戴在身上，**当众炫耀**。**场景范式：驯化完成 + 主动 + 炫耀**。
7. **#22 顾烨皓堕落**：镜像 CP 被改造，**吊起示众**。**场景范式：CP 同样命运 + 镜像示众**。
8. **#23 凌夜翻车 / 顾哥反击**：CP 联手反杀。**场景范式：驯化反转 + 反派失势**。

#### 4.1.3 角色弧光（5 个核心角色）

1. **白曜（主角）** — 19 岁战士 → 驯化的"战神" → 反转反杀。**弧光**："高冷战士"到"主动戴玩具"的堕落，再到"反杀驯化者"的反抗。
2. **顾烨皓** — 镜像 CP，是白曜"同类"和"同伴"，被反派哄骗。**弧光**："干净的同类"到"同样堕落"。
3. **凌夜（反派）** — 自恋型反派，把白曜当"作品"和"收藏品"。**弧光**："全知全能"到"被反噬"。

#### 4.1.6 写作技法

1. **状态符号化**：紧身衣的"高弹""自适应""胯下贴合"成为反复出现的视觉符号，每次战斗的"衣着描写"就是一次**色情铺垫**。
2. **胯下攻击 = 能量吸走的等价物**：把"打败敌人"等同于"榨精"，是**最关键的"战队特摄"XP 转译公式**。
3. **驯化三段式**：（i）被迫→（ii）抗拒但身体反应→（iii）主动戴道具炫耀。**形成完整的"堕落弧光"模板**。
4. **CP 镜像法**：顾烨皓是白曜的镜像，**两个人的堕落过程交替呈现**，构成"双线"叙事。
5. **反转结局**：驯化者最终被反噬，给读者"虽然被榨但没完全认输"的爽感。**关键：不能完全黑化，要有反转余地**。

#### 4.1.7 v2 SKILL 升级建议（5 个必含元素）

1. **新增/扩展的具体内容**：在 v1 基础上新增 **"紧身衣胯下战斗"专用子类型** `子类型.紧身衣胯下战`，含 4 个变体：`踩裆`、`抠裆`、`缠绕`、`注射刺激`。
2. **结构/字段/模板**：在 `小英雄卡.v2.json` 中增加字段 `紧身衣.胯下攻击点 = ["裆部", "臀缝", "大腿内侧", "会阴"]`；在 `套路.高弹紧身衣` 中增加 4 个状态机：`穿前 / 穿中 / 被攻击 / 反杀`。
3. **示例/用法/触发条件**：触发条件 `主角 = 紧身衣战士 ∧ 反派 = 胯下攻击型 → 自动套用 高弹紧身衣.胯下攻击 = 强制射精 + 能量被吸走`；示例参考本作品 #2/#8/#11。

#### 4.2.1 完整套路梳理

**第 1 段：人设架构（#1）**
故事讲反派"魔影团"设计"收集"全宇宙 5 位"圣兽"超级战士的阴谋。每位圣兽战士都穿一种**对应颜色 + 兽型特征**的紧身衣（如圣兽红/绿/黄/蓝/黑，对应龙/虎/鹰/蛇/麒麟）。反派的目标是**全部捕获并改造为"魔影团"的奴隶战士**。**核心设定**："圣兽之力"必须靠**不断榨精**才能维持（精能即能量），所以被抓后会陷入"越榨越弱、越弱越被榨"的死亡螺旋。

**第 2 段：捕获套路（#3、#5、#7、#10、#11）**
- #3 初尝禁果：圣兽红被女反派"魅魔"以色情引诱捕获，使用"**跨物种（魔物代替触手）**"——魅魔的头发是触手
- #5 英雄游戏上：圣兽黄被"游戏"诱惑，进入电玩城，**电击椅 + 强制射精**
- #7 圣兽绿捕获：圣兽绿被"森林幻境"迷惑，**树精缠绕 + 榨精**
- #10 指令榨精：反派发出"榨精"指令，所有被捕战士**同时被榨**——这是**多 P 场景的标准范式**
- #11 圣兽黑捕获血乳交融：圣兽黑被"狼人"反派捕获，**血 + 乳 + 精**混合的污名化描写

**第 3 段：陷阱与决战（#17、#21）**
- #17 陷阱：救援队也落入陷阱，"**英雄救美"反转成"英雄被救"**，但被救者再被捕
- #21 决战前夕：5 位圣兽全部堕落，反派发起"决战"——实为公开羞辱大会

**第 4 段：阵营反转 / 父子记忆覆盖**
圣兽红（白曜原型）的父亲是上一代"圣兽红"，被反派**公开羞辱后阉割**（如天装#1 类似），但本作中**白曜并不知道父亲的下落**，把"反派首领"误认为"导师"——这是 **"父子记忆覆盖"型**的典型变体。

**第 5 段：多色战队群像**
本作有 5 个不同颜色的紧身衣战士，每个对应一种**兽型 + 一种 XP 偏好**：
- 圣兽红（龙）→ 战斗型，跨物种捕
- 圣兽绿（虎）→ 树精 + 足/腿
- 圣兽黄（鹰）→ 电击 + 强制射精
- 圣兽蓝（蛇）→ 缠绕 + 锁链
- 圣兽黑（麒麟）→ 血 + 父子乱伦

**多色战队范式**：每色战士**对应不同的 XP 子型**，扩大 XP 命中面。

#### 4.2.2 关键场景（5+）

1. **#3 初尝禁果**：圣兽红被"魅魔"在床上榨精，**发丝触手**缠绕下体。**场景范式：魅魔 + 跨物种（触手） + 强制榨精**。
2. **#5 英雄游戏上**：圣兽黄被"游戏机"捕获，**电击椅 + 强制射精**。**场景范式：机械 + 电击 + 射精**。
3. **#7 圣兽绿捕获**：森林幻境，**树精缠绕 + 足部 + 腿**。**场景范式：自然系（魔物代替触手） + 腿/足**。
4. **#10 指令榨精**：反派一令下，**5 位战士同时被榨**。**场景范式：多 P 同时 + 命令服从**。
5. **#11 圣兽黑捕获血乳交融**：圣兽黑被狼人反派**咬伤 + 强行哺乳**。**场景范式：跨物种（魔物代替触手） + 血 + 乳 + 精**。

7. **#21 决战前夕**：5 位堕落战士**列队示众**。**场景范式：群像 + 公开 + 堕落仪式**。

#### 4.2.6 写作技法

1. **5 色战队模板**：每个颜色对应一种兽 + 一种 XP，是"战队特摄"最经典的"XP 配菜"模式。
2. **多 P 同时榨精**：把单 P 场景扩展为**多 P 群像**，扩大刺激面（**多 P = 战队特摄的标配**）。
3. **跨物种（魔物代替触手）**：把"触手"替换为"兽型魔物"，**完美踩中用户"魔物代替触手"XP**。
4. **救援反转**：救援队也被抓，形成**循环捕获**，扩大篇幅。
5. **决战仪式**：堕落战士列队示众，**给读者"集体堕落"的视觉冲击**。

### 5.1 【龙骧战队】二创（8 分 / 80% 读）

### 9.1 紧身衣的"二次元 vs 现实"双层意义

01 子类"战队特摄"中，**紧身衣**是核心视觉符号。仔细分析，**紧身衣在文本中扮演 3 重功能**：

1. **功能层**：作为战斗服，提供能量保护（5 色战队、紧身衣红/蓝/黄等）
2. **视觉层**：作为"第二层皮肤"——**完全勾勒出胯下轮廓**（所有作品都重复描写）
3. **XP 层**：作为"胯下攻击的传导介质"——紧身衣的"贴合"放大一切攻击的刺激

**这 3 层是"战队特摄"区别于其他子类（如 02 淫纹/催眠）的根本**：
- 02 子类的"淫纹"是**皮肤上的图案**（被动）

- 01 子类的"紧身衣"是**衣物的贴合**（主动+被动）

**v2 SKILL 关键升级**：必须把"紧身衣"作为**独立的视觉符号系统**（v1 SKILL 中只是"衣着描述"），新增 `符号.紧身衣` 模块。
