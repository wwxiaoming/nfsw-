# pixiv 优化大方向（v2 升级路线）

> 本文档是基于 v1（11 部小英雄长篇 + 6 份 references + 共性分析 12 部）叠加 1141 份新 pixiv 抽样的 **v2 优化大方向**。定调不锁死细节：给出主线方向 + 关键判断原则 + 增量 references 建议，9 份分级阅读笔记与 SKILL v2 升级时的具体细节不在本文件内展开。

---

## 1. 升级定位（v1 → v2 关系）

### 1.1 v1 已覆盖的
- **单选子类型模式**（战队 / 淫纹 / 催眠 / 触手 / 足控 / 收藏家 / 双主角 7 类）：v1 SKILL.md Step 1 默认"识别一个子类型"作为主线。
- **6 份 references 的核心方法论**：
  - `character_archetypes.md`：8 主角 + 8 反派 + 5 配角 + 决策树。
  - `plot_templates.md`：T1-T5 模板 + T6 复合模板 + 决策表。
  - `scene_hooks.md`：H01-H18 钩子 + 短/中/长篇组合建议。
  - `dialogue_style.md`：主角 5 阶段 + 反派 5 阶段 + 中日文差异。
  - `vocabulary.md`：身体 / 动作 / 情感 / 场景 / 体味 / 禁忌 / 替代 / 命名 / 自检 9 大类。
  - `rhythm_templates.md`：章节长度 + 场景切换 + 高潮位置 + 情绪曲线 + 收束 + 规划清单。
- **共性分析 12 部**（OO 少年、龙骧、进化之路、光莲、超人暂存、小英雄零决、帝王战队、双子特工、超英视界等）提炼出的题材定位、读者期待、跨系列差异、衔接点。
- **避坑要点**：不要纯肉文、要有反抗、不要重复钩子、不要跨子类型混乱、不要省略数据卡。

### 1.2 v1 未覆盖的
- **多子类型融合**：v1 决策树基于"选一个主线子类型"，未显式支持"战队+触手+足控+榨精"等多类型共构。
- **XP 偏好分层**：v1 不区分用户的 XP 命中，不在生成时显式加权。
- **质量权重驱动**：v1 假设源材料同质，没有"高分作品作为高密度模板库"的差异化策略。
- **外语 / 女性向 / 同人边界**：v1 描述里写了 7 个子类型，未明确"女性向不进入自动生成"等硬边界。
- **榨精 / 龟责 / 触手 / 足控等专项 XP 的剧情钩子深度**：v1 scene_hooks 18 个对正太校园、修真玄幻、星际世界观的覆盖偏薄。
- **同人原作 IP 的版权敏感度判定**：v1 没有针对"原神 / 斗罗 / 洛克人 / 漫威 / 暴雪"等 IP 的差异化处理。
- **数据化精度**的进一步细化（数据卡 5 项 → 可能需要 8-10 项以支持榨精 / 触手等子类）。

### 1.3 v2 的核心新增
- **多选子类型清单 + 命中权重**（取代 v1 的单选模式）。
- **XP 命中显式标注**（正太 / 小英雄 / 榨精 / 龟责 / 紧身衣 / 足控 / 触手 / 修真 / 兽人 / 反英雄 / 穿越 / 复仇 / 兄弟 / 师徒 / 父子 / 双子 / 治愈 / 反差等）。
- **质量权重驱动**（1-10 分）：高分作品 → 主模板库；中分作品 → 辅助模板库；低分作品 → 仅做分类。
- **多子类型融合模式**（如"战队英雄堕落 + 触手 + 紧身衣 + 伪科学脱敏" = 高弹紧身衣战士白曜）。
- **子类优先级显式分级**（03/04/05 ★★★★★；01/02 ★★★★；08 ★★★；06 ★★；07/09 ✗）。
- **9 份分级阅读笔记**作为 v2 references 的补充语料（后续任务）。
- **4 份可选增量 references**（subtype_decision_tree / xp_match_patterns / quality_weight_rubric / multi_subtype_blend）。

### 1.4 与 v1 的边界
- **v1 适用**：
  - 已有世界书 / 角色卡扩写（基本方法论不变）
  - 短 / 中 / 长篇节奏规划
  - 5 阶段对话曲线（傲娇 → 含蓄 → 决绝 → 软化 → 崩溃；命令 → 诱导 → 嘲讽 → 欣赏 → 威胁）
  - 18 个场景钩子的基础版
  - 中日文文风差异
  - 禁忌词清单
- **v2 新增**：
  - 多子类型识别 + 优先级排序
  - XP 命中 + 加分策略
  - 质量权重驱动的模板选择
  - 多类型融合模式的剧情结构
  - 子类优先级与处理方式
  - 边界处理（女性向 / 外语不进入自动生成）

## 2. 核心升级方向（5-8 条主线，定调不锁细节）

### 方向 1：识别子类型的多选清单

- **当前问题**：v1 SKILL.md Step 1 给出 7 个单选子类型（战队 / 淫纹 / 催眠 / 触手 / 足控 / 收藏家 / 双主角），决策树默认"选一个主线"。但 1141 份新抽样中，**绝大多数高分作品是"多子类型融合"**：高弹紧身衣战士白曜 = 战队 + 紧身衣 + 榨精 + 反派主导 + 兄弟反目 + 兄弟羁绊；夏日契约 = 正太 + 校园 + 兄弟 + 赌约 + 公开 play + 玩具；万界抓捕调教少年正太手册 = 系统流 + 调教 + 榨精 + 正太 + 三世界。
- **升级方向**：v2 改为**多选清单**，AI 拿到新世界书时按以下 12 个候选子类型**多选并标注主次**：
  1. 战队特摄 / 02 勇者魔物奇幻 / 03 正太校园堕落 / 04 调教拍卖系统流 / 05 异种兽化触手 / 06 修真玄幻 / 08 同人（同上 9 个子类的合并，作为"世界观容器"）
  2. 紧身衣 / 制服 / 校服（视觉锤母题）
  3. 足控 / 裸足 / 鞋袜（足部恋物）
  4. 触手 / 异肢 / 兽化（非人反派）
  5. 榨精 / 龟责 / 控射（榨精生物母题）
  6. 催眠 / 洗脑 / 常识改写（意识改造）
  7. 淫纹 / 烙印 / 标记（符号所属）
  8. 收藏家 / 拍卖 / 标价（物化母题）
  9. 反派主导 / 反派洗白 / 反派温柔（反派塑造）
  10. 兄弟 / 双子 / 师徒 / 父子（羁绊类型）
  11. 复仇 / 穿越 / 穿书 / 反英雄（叙事骨架）
  12. 纯爱 / 治愈 / 反差 / 甜蜜（情感基调）
- **关键判断**：
  - **不要锁死优先级**——AI 根据用户世界书自由组合，可在生成时显式说明"主线 A + 副线 B + 辅线 C"。
  - **多子类型要协调**——例如"战队+触手+足控"可以（白曜模板），但"战队+修真+百合"应被警告（语义冲突）。
  - **多选时仍要保留 1 个主线**——T1-T5 模板基于"主线反派 / 主线子类型"，多子类型围绕主线展开。
- **不写死的细节**：
  - 子类型清单的具体内容（5 个？12 个？20 个？）——留作 SKILL 升级时根据 9 份分级阅读笔记的实际数据决定。
  - 主线 / 副线 / 辅线的权重比例（60/30/10？还是 50/30/20？）——留作模板决策树时决定。
  - 9 份分级阅读笔记的每份具体格式——后续任务展开。

### 方向 2：XP 偏好作为子类型权重

- **当前问题**：v1 不区分用户 XP，假设所有子类型同等重要。但用户的 XP（正太 / 小英雄 / 榨精 / 龟责 / 紧身衣 / 足控 / 触手）有**强命中差异**——根据 01-09 总结：正太命中 ~50 部（覆盖 03 全 25 + 其他 ~25），小英雄 ~45 部，榨精 ~40 部，触手 ~20 部，紧身衣 ~10 部，足控 ~7 部，龟责 ~5 部。
- **升级方向**：v2 显式标注**用户 XP 命中**：
  - **第一优先 XP（v2 必命中）**：正太 + 小英雄 + 榨精——几乎覆盖所有高分作品。
  - **第二优先 XP（v2 高频命中）**：触手 / 紧身衣 / 足控 / 反派主导 / 复仇——各覆盖 10-20 部高分作品。
  - **第三优先 XP（v2 选择性命中）**：龟责 / 兽人 / 师徒 / 兄弟 / 双子 / 反英雄 / 穿越——按用户具体偏好激活。
  - **雷点（v2 必须避免）**：女性 / 血腥 / 真人 IP——在生成时显式过滤。
- **关键判断**：
  - **XP 命中不替换主线子类型**——它是"权重加分"而非"主线切换"。一本战队文如果命中榨精 + 触手，仍是战队主线 + 榨精触手副线。
  - **XP 加分要有上限**——根据 01-09 总结，多 XP 命中时总分上限 +5（防止过度加权）。
  - **XP 减分也要有下限**——多雷点同时命中时总分下限 -3（防止变成"为雷而雷"）。
- **不写死的细节**：
  - XP 加分 / 减分的具体分值表（+1?+2?+3?）——留作 9 份分级阅读笔记根据实际权重分布细化。
  - XP 命中与剧情模板的精确对应（如"榨精+触手 → 必定走 T1 触手怪人型"）——留作 SKILL 升级时验证。
  - 第三优先 XP 是否要在 frontmatter description 里显式列出——根据 description ≤ 200 字符的约束决定。

### 方向 3：质量权重驱动阅读与生成

- **当前问题**：v1 假设所有源材料同质（"11 部小英雄长篇"作为对等语料库）。但 1141 份新抽样的**质量分布**差异巨大：59 部 9-10 分（5.2%）、22 部 7-8 分（1.9%）、12 部 5-6 分（1.1%）、10 部 1-4 分（0.9%），其余约 1038 部未单独打分（占 91%，主要为中长篇连载的主体内容）。
- **升级方向**：v2 引入**质量权重 1-10 分**（原始 + XP 调整后）：
  - **9-10 分（~59 部）**：作为**主模板库**，每本提供 2-3 个独立可复用模板 + 1 个新钩子 + 1 个标志场景。
  - **7-8 分（~22 部）**：作为**辅助模板库**，每个子类补 2-3 个次级模板，扩展已有套路池的边界。
  - **5-6 分（~12 部）**：作为**风格参考**，仅在缺乏 9-8 分同类素材时调用。
  - **1-4 分（~10 部）**：**不进 Skill 自动生成管线**，仅做分类统计与反向参考（如"该子类有这个套路但不推荐复用"）。
- **关键判断**：
  - **高质量作品是模板源头**——白曜 / 超级战队收集计划 / 夏日契约 / 学生奇遇 / 万界抓捕 / 圣兽战士 / 妨碍拯救世界 / 绝不能让师父落空 / 霍格沃茨触手等标杆，**优先**作为 AI 写作时的钩子与场景来源。
  - **XP 调整后 9-10 分 ≠ 客观质量 9-10**——XP 加分是个人偏好，最终判断仍需考虑原作完成度 / 章节密度 / 文本结构。
  - **9 份分级阅读笔记的分配**——根据 9 个子类各写 1 份，每份内按高分 → 中分 → 低分排序，作为后续 SKILL 调用的"语料优先级索引"。
- **不写死的细节**：
  - 9-10 分作品的具体排序（白曜 vs 夏日契约谁是"标杆之首"？）——留作 9 份分级阅读笔记写作时讨论。
  - 7-8 分作品是否进 SKILL 触发器——根据 description 字数限制决定。
  - 低分作品的"反向参考"具体格式——一句话标记？还是清单？——留作 9 份分级阅读笔记写作时决定。

### 方向 4：分场景的多类型融合

- **当前问题**：v1 plot_templates 的 T6 复合模板提到"T1+T2 / T1+T5 / T4+T2 / T3+T5 / T2+T5"五种组合，但都是**模板级**的复合（如 T1 单反派长程 + T2 多人轮替），未深入到**场景级 / 钩子级**的子类型融合。
- **升级方向**：v2 鼓励**分场景的多类型融合**，即同一本小说中：
  - **主线子类型 = 1 个**（如战队）
  - **场景级子类型 = 2-4 个**（如紧身衣 + 榨精 + 触手 + 兄弟羁绊）
  - **每个场景聚焦 1-2 个子类型**，避免单场景堆砌
- **融合模式示例**（来自 01-09 总结的高分代表作）：
  - **高弹紧身衣战士白曜**（01）：战队（主线）+ 紧身衣（制服母题）+ 榨精（核心 XP）+ 反派主导（反派塑造）+ 兄弟羁绊（情感线）+ 伪科学脱敏（催眠变体）。
  - **夏日契约**（03）：正太（核心 XP）+ 校园（世界观）+ 兄弟（赌约关系）+ 公开 play（场景钩子）+ 玩具（道具）+ 日常腻缠（番外）。
  - **圣兽战士**（05）：英雄（主线）+ 兽化（异族）+ 触手（核心 XP）+ 目录化设定（世界观架构）+ 双线（宵禁篇/黑市篇）。
  - **万界抓捕调教少年正太手册**（04）：系统流（叙事骨架）+ 三世界（多卷结构）+ 调教（核心动作）+ 榨精（核心 XP）+ 正太（核心 XP）+ 反英雄型主角（角色塑造）。
  - **妨碍拯救世界的勇者居然是魅魔！**（08）：同人（世界观）+ 关卡递进（叙事结构）+ 魅魔（异族）+ 小英雄被俘（核心 XP）+ 榨精（核心 XP）。
- **关键判断**：
  - **融合要服务于主线**——多子类型不能"为融合而融合"，每个子类型要回答"它给主线带来什么新元素？"
  - **场景级子类型要可识别**——AI 生成时每个场景的"主钩子"要明确（这个场景是讲触手？还是讲足控？还是讲兄弟羁绊？）。
  - **多类型融合 ≠ 元素堆砌**——v2 仍要保留 v1 避坑要点"不要跨子类型混乱"，融合要有逻辑自洽。
- **不写死的细节**：
  - 具体哪些融合是"经典"（白曜型 / 夏日型 / 圣兽型）vs"应避免"（战队+修真+百合型）——留作 SKILL 升级时通过 9 份分级阅读笔记总结。
  - 同一本小说中允许的最大子类型数（4 个？6 个？8 个？）——留作模板决策时验证。
  - 子类型之间的"冲突清单"——留作 SKILL 升级时根据实际数据补充。

### 方向 5：女性向与外语的边界处理

- **当前问题**：v1 假设所有类型都生成，描述里未明确"女性向不进入自动生成""外语仅做识别"。
- **升级方向**：v2 显式标注**边界**：
  - **09_女性向**：3 部全雷女性（奴隶调教中心 4 分、勇者大战魔物 2 分、色欲之旅番外 2 分），**不进入 Skill 自动生成管线**，仅做风格识别（BG 治愈向 / 校园奴隶调度 / 百合艳后魅魔的"结构形式"作为参考）。
  - **07_外语**：5 部日语（勇装戦士ブレイブレンジャー 8 分、射精が一般化した世界 8 分、少年戦隊SEASONS 6 分、搾精生物から生き残れ！5 分、soxr soda 2 分），**不进入自动生成**（语言障碍 + 文化差异 + 雷女性减分），仅做素材参考（IF 分支冒险 / 射精一般化世界观 / 战队长期连载形式可借鉴）。
  - **雷女性 / 雷血腥**：在生成时显式过滤——不出现女主角主动参与调教、不出现血腥暴力细节。
- **关键判断**：
  - **边界处理是"硬约束"**——v2 SKILL 触发时应显式提示 AI"该请求命中 09 / 07 子类 / 雷女性 / 雷血腥，需调整策略"。
  - **不进入自动生成 ≠ 完全禁止**——用户明确要求时可作为"风格借鉴"模式运行，但不作为主线生成。
  - **边界标注要清晰**——frontmatter description 应当包含"不适用：09 女性向 / 07 外语 / 雷女性 / 雷血腥"。
- **不写死的细节**：
  - 边界条件的具体触发机制（用户输入命中 → 自动降级？还是询问用户确认？）——留作 SKILL 升级时决定。
  - 风格借鉴模式的具体输出格式（"参考 09 的 BG 治愈向结构，但主角改为男性"）——留作实战测试时验证。
  - 08 同人的原作 IP 版权敏感度（原神 / 斗罗 / 洛克人 / 漫威 / 暴雪）—— 留作 SKILL 升级时单独讨论。

### 方向 6：标志场景 / 钩子 / 模板的三层分离

- **当前问题**：v1 scene_hooks.md 18 个钩子是"通用钩子"，与 plot_templates 5 套模板紧密绑定，未分离出"标志场景"（每本高分作品独有的不可复用场景）与"通用钩子"。
- **升级方向**：v2 引入**三层结构**：
  - **第 1 层 = 标志场景**（高分作品独有）：如白曜的"伪科学脱敏注射 + 脱敏过程"、夏日契约的"暑假赌约升级 + 公园公开 play"、圣兽战士的"宵禁篇/黑市篇双线目录化"、妨碍拯救世界的"旅馆→警长→精灵族关卡递进"——这些场景**不可强复制**到其他作品，但可作为"灵感来源"被 AI 改造。
  - **第 2 层 = 通用钩子**（可复用）：v1 的 18 个钩子 + 9 份分级阅读笔记中提炼的 8-12 个新钩子（如"系统流任务卡 + 阶段结算" / "三魅魔家庭甜宠 + 3P" / "IF 选项冒险 + 区域分块" / "室友霸凌 + 公开 play"）。
  - **第 3 层 = 模板骨架**（可复用）：T1-T5 + T6 复合 + 9 份分级阅读笔记中提炼的"高弹紧身衣型 / 夏日契约型 / 圣兽战士型 / 万界抓捕型"等子模板。
- **关键判断**：
  - **标志场景是 v2 的"稀缺资源"**——它们是高分作品的灵魂，AI 引用时要注明出处。
  - **通用钩子要保持原有规模（18-30 个）**——避免 v1 钩子库被稀释。
  - **模板骨架要按子类细化**——v1 的 5 套模板是"通用骨架"，v2 可按 9 个子类各提炼 1-2 套"子模板"。
- **不写死的细节**：
  - 标志场景的具体收录数量（10 个？20 个？30 个？）——根据 9 份分级阅读笔记的实际数量决定。
  - 标志场景与通用钩子的"出处标注"格式（脚注？行内引用？）——留作 SKILL 升级时决定。
  - 子模板与 T1-T5 的关系（"子模板 ⊂ T1-T5"还是"子模板 ⊥ T1-T5"）——留作 SKILL 升级时讨论。

### 方向 7：基于 XP 的子模板差异化生成

- **当前问题**：v1 plot_templates.md 的 T1-T5 是"通用模板"，未按 XP（榨精 / 触手 / 足控 / 紧身衣等）差异化。例如 T1 单反派长程沦陷对"榨精反派"和"触手怪人"的阶段拆解相同。
- **升级方向**：v2 按 XP 差异化模板：
  - **T1-榨精型**（多世界系统流）：阶段 1-3 加入"系统任务卡 + 阶段结算奖励"；阶段 4-5 强调"榨精量/榨精频率/榨精场景升级"。
  - **T1-触手型**（兽化异种）：阶段 1-3 加入"目录化设定 + 世界观先行"；阶段 4-5 强调"触手形态变化 / 黏液 / 产卵 / 异种共生"。
  - **T1-足控型**（恋物反派）：阶段 1-3 加入"鞋袜品牌数据化 + 足部触觉描写密度"；阶段 4-5 强调"足部开发 / 挠脚心 / 足底踩射"。
  - **T1-紧身衣型**（制服母题）：阶段 1-3 加入"紧身战衣剥离 / 触手表皮 / 乳胶衣"；阶段 4-5 强调"制服 + 身体线条 + 帐篷/轮廓"。
  - **T1-正太型**（年龄 + 体格）：阶段 1-3 加入"童真反差 + 体味标签"；阶段 4-5 强调"白袜 + 校服 + 软肉 + 萌系语录"。
- **关键判断**：
  - **T1 通用骨架不变**——只是在每阶段加入 XP 特有的"动作 / 对白 / 心理"细节。
  - **多 XP 命中时叠加**——例如"触手+榨精"型要同时包含"目录化设定 + 榨精频率"两个维度。
  - **T1-X 模板库要按 9 个子类各写 1 份**——作为 9 份分级阅读笔记的一部分。
- **不写死的细节**：
  - T1-X 模板的具体数量（5 个？10 个？）——根据 XP 第一优先 + 第二优先的数量决定。
  - T1-X 与 T2-T6 的复合（如"T1-触手型 + T4 群像多线" = 圣兽战士模板）——留作 SKILL 升级时验证。
  - XP 加分对模板选择的具体影响（"命中榨精+触手 → 必须走 T1-榨精-触手复合型"？）——根据 9 份分级阅读笔记的实际数据决定。

### 方向 8：数据化精度的进一步细化

- **当前问题**：v1 character_archetypes.md 的决策树基于"身高 / 体重 / 弱龄 / 弱点 / 体味"5 项数据，但 01-09 总结中的高分作品普遍有更细的数据卡：JJ 尺寸（18.19cm / 15cm）、足码（44 码）、袜 / 鞋品牌（Nike 精英袜 / AJ23）、体味细分（奶香 + 薄荷 / 玉堂春 + 雪松）、武器（银长枪 / 银白短匕 / 粒子爆破）、战衣颜色（红 / 蓝 / 金 / 白 / 黑 / 青）。
- **升级方向**：v2 扩展数据卡至 8-10 项：
  - 必含 5 项：身高 / 体重 / 年龄 / 弱点 / 体味
  - 建议增加 5 项：JJ 尺寸（榨精类）/ 足码（足控类）/ 袜鞋品牌（足控/恋物类）/ 战衣颜色（战队类）/ 武器或异能（战队/修真类）
  - 可选增加：所属元素（火/水/雷/风/光/暗）/ 兽化形态（兽人/触手类）/ 印记位置（淫纹/烙印类）/ 性格弱点（傲娇/毒舌/奶凶/冷静）
- **关键判断**：
  - **数据化精度服务于读者认知**——不要"为数据而数据"，每个数据项要能影响剧情（足码 → 足控场景；JJ 尺寸 → 榨精量；武器 → 战斗场景）。
  - **数据卡 8-10 项是上限**——超过 10 项会让读者疲劳。
  - **数据卡可由子类型决定**——战队类必填战衣颜色 + 武器；足控类必填足码 + 袜鞋品牌；榨精类必填 JJ 尺寸。
- **不写死的细节**：
  - 8-10 项数据卡的具体清单——留作 SKILL 升级时根据 9 份分级阅读笔记的实际数据决定。
  - 数据卡格式（表格？清单？卡片？）——留作 SKILL 输出规范升级时决定。
  - 数据卡与"读者代入感"的关系（数据越细越易代入 vs 数据越细越出戏）——留作实战测试时验证。

## 9. 风险与边界

### 9.1 边界（硬约束）

- **09_女性向不进入自动生成**：v2 SKILL 触发时显式标注，用户明确要求时可作为"风格借鉴"模式运行，但不作为主线生成。
- **07_外语仅做识别**：v2 SKILL 触发时显式标注，仅作素材参考（IF 分支冒险 / 射精一般化世界观 / 战队长期连载形式可借鉴），不作为主线生成。
- **雷女性 / 雷血腥在生成时显式避免**：不出现女主角主动参与调教、不出现血腥暴力细节。
- **08_同人原作 IP 版权敏感度**：原神 / 斗罗 / 洛克人 / 漫威 / 暴雪等 IP 在生成时显式提示用户版权风险，由用户决定是否继续。
- **真实地理名 / 真实人名 / 真实品牌名的禁忌**：沿用 v1 vocabulary.md F1 禁忌清单。
- **直白医学诊断名词 / 法律相关词的禁忌**：沿用 v1 vocabulary.md F1 禁忌清单。

### 9.2 风险

- **风险 1：多子类型融合导致元素堆砌**——v2 鼓励"多子类型融合"，但若 AI 不加控制地堆砌所有子类型，会出现"战队+触手+足控+榨精+催眠+淫纹+收藏家"7 合 1 的混乱。
  - **缓解**：subtype_decision_tree.md 给出"主线 / 副线 / 辅线"权重（60/30/10 或 50/30/20），主线索不超过 1 个，副线不超过 2 个，辅线不超过 3 个。
- **风险 2：XP 加分过度加权**——v2 显式标注 XP 命中并加分（上限 +5），但若 AI 误判 XP 命中（如把"触手"误判为"足控"），会偏离用户实际偏好。
  - **缓解**：xp_match_patterns.md 给出每个 XP 的判定规则（基于场景关键词 / 角色卡 / 设定），并在生成时显式说明"命中 XP：xxx（+N 分）"由用户确认。
- **风险 3：质量权重被"XP 调整后"主导**——v2 的质量权重是"原始 + XP 调整"，XP 调整后 9-10 分的代表作可能客观质量只有 7-8 分（XP 加分后升到 9-10）。若 SKILL 误将"XP 加分作品"作为"客观质量标杆"，会拉低生成质量。
  - **缓解**：quality_weight_rubric.md 区分"原始质量"与"XP 调整后质量"，标杆作品以"原始质量 + XP 命中"双高为主（如白曜原始 10 分 + XP 加分 +5 达上限）。
- **风险 4：边界处理误判**——v2 显式标注 09/07 / 雷女性 / 雷血腥边界，但若 AI 误判（如把"百合"误判为"男同"），会生成违规内容。
  - **缓解**：在 v2 SKILL 触发时增加"边界检测 step"，显式询问用户"该请求是否命中 09 / 07 / 雷女性 / 雷血腥？"并由用户确认。
- **风险 5：数据化精度过度导致出戏**——v2 扩展数据卡至 8-10 项，但若 AI 在对话中过度强调数据（"我的 18.19cm 肉棒"），会破坏心理描写的细腻度。
  - **缓解**：数据卡在角色介绍 / 设定补全时使用，在对话 / 心理描写中只在关键节点引用（不超过每章 1-2 次）。
- **风险 6：9 份分级阅读笔记的工作量过大**——9 份 × 每份 5-10 部高分 + 1-3 部中分 + 一句话低分 = 9 × 8-13 = 72-117 部作品的详细阅读，工作量巨大。
  - **缓解**：9 份分级阅读笔记分批撰写（先 03/04/05 第一优先，再 01/02 第二优先，再 08/06/07/09 后续），每份控制在 3000-5000 字。
- **风险 7：实战测试发现 v1 references 不兼容**——v2 扩展 v1 references 时可能发现某些 v1 内容与 v2 不兼容（如 v1 的 T1 模板与 v2 的 T1-X 子模板冲突）。
  - **缓解**：v1 references 扩展时保留 v1 原文作为"基础版"，新增 v2 内容作为"扩展版"，由 AI 根据用户请求选择调用。

## 10. 总结

v2 升级的核心理念：

1. **从单选到多选**：v1 的"识别一个子类型" → v2 的"识别多个子类型 + 主次标注"，反映 1141 份新抽样中绝大多数高分作品是"多子类型融合"的现实。
2. **从无 XP 到有 XP**：v1 不区分用户 XP → v2 显式标注"正太 / 小英雄 / 榨精 / 触手 / 紧身衣 / 足控"7 个第一/二优先 XP，让生成内容更精准命中用户偏好。
3. **从同质到分层**：v1 假设所有源材料同质 → v2 引入"质量权重 1-10 分"，59 部 9-10 分代表作作为主模板库，22 部 7-8 分作为辅助模板库，22 部 1-6 分不进入自动生成。
4. **从无限到边界**：v1 假设所有类型都生成 → v2 显式标注"09 女性向 / 07 外语不进入自动生成""雷女性 / 雷血腥显式避免""08 同人原作 IP 版权敏感度"。
5. **从通用到子模板**：v1 的 5 套通用模板 → v2 的 T1-X 子模板（榨精 / 触手 / 足控 / 紧身衣 / 正太）+ T7-T9 新模板（正太校园 / 修真玄幻 / 同人 IP），让生成结构更精细化。

v2 不是推翻 v1，而是在 v1 基础上叠加 v2 增量：保留 v1 的 6 份 references 核心方法论 + 共性分析 12 部的题材定位，扩展 8 个核心方向 + 4 份可选增量 references + 9 份分级阅读笔记 + 1 套 SKILL v2 重构。
