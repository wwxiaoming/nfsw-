# 对话风格库（Dialogue Style）

> 本文档提供"小英雄"题材的角色对话模板与心理独白结构。包含：主角常用句式（5 阶段）、反派常用句式（5 阶段）、心理独白结构（内心 vs 身体反应对照）、中日文文风差异对照。

---

## A. 主角常用句式（5 阶段）

### 阶段 1：傲娇（Arogancy）

> 阶段定位：被俘前 / 战斗状态 / 反击阶段
> 语气特点：硬气 / 嘴硬 / 反抗
> 句长：短句 + 感叹号

**模板**：
```
"我才不会……！"
"你、你别过来……！"
"我可是 [战队名] 的 [身份]！你以为你……"
"我才不是你说的那种人！"
"你、你以为这样就能……？"
```

**完整示例**：
```
主角（咬牙切齿）："我可是龙骧战队的应龙……你、你以为这点雕虫小技就能……"
反派（微笑）："是吗？"
主角（声音发颤）："我、我的队员会来找我的……！"
```

---

### 阶段 2：含蓄（Evasiveness）

> 阶段定位：第一次被侵犯 / 身体开始反应
> 语气特点：支吾 / 省略 / 喘息
> 句长：中等 + 省略号

**模板**：
```
"你……你……唔……"
"别、别这样……我……"
"为什么……我的身体……"
"唔……你、你别……"
"我……唔……"
```

**完整示例**：
```
主角（声音变调）："你……你别碰那里……"
反派（继续动作）："……"
主角（声音破碎）："唔……为什么……我的身体……在……"
反派（温柔）："因为它属于我。"
```

---

### 阶段 3：决绝（Determination）

> 阶段定位：身体觉醒前的最后抵抗
> 语气特点：咬牙 / 决绝 / 反向激励
> 句长：短句 + 重复

**模板**：
```
"就算你……我也不会……"
"我不会屈服的……绝对不会……"
"我……我不会变成……你说的那种人……"
"我答应过 [重要的人]……我……"
"就算死……我也不会……"
```

**完整示例**：
```
主角（咬牙）："我不会屈服的……"
反派（继续刺激）："……"
主角（声音已变）："我……我答应过哥哥……我……"
反派（轻抚）："你哥哥……也想看到你这样吗？"
主角（崩溃前）："……唔……"
```

---

### 阶段 4：软化（Softening）

> 阶段定位：自我说服阶段 / 半沦陷
> 语气特点：叹气 / 接受 / 自我合理化
> 句长：长句 + 心理活动

**模板**：
```
"也许……这只是……战斗的副作用……"
"我……我不是在屈服……我只是……"
"……这样……好像……也不错……"
"如果……如果只是你一个人的话……"
"我……我答应你……但只是……"
```

**完整示例**：
```
主角（叹气）："……也许……这只是战斗的副作用。"
反派（微笑）："是。"
主角（声音已软）："我不是在屈服……我、我只是……"
反派（拥抱）："我知道……"
主角（闭眼）："……如果是你的话……也许……"
```

---

### 阶段 5：崩溃（Collapse）

> 阶段定位：彻底沦陷 / 主动配合
> 语气特点：哭腔 / 颤抖 / 主动索取
> 句长：短促 + 重复 + 语气词

**模板**：
```
"呜……不要了……求你……"
"呜……我……我想要……"
"……求你……对我……"
"……呜……不要离开……"
"……我……我是你的……"
```

**完整示例**：
```
主角（哭腔）："呜……不要了……求你……"
反派（动作继续）："……"
主角（声音已哑）："……求你……对我……"
反派（拥抱）："……乖……你是我的。"
主角（抱住反派）："……呜……❤️"
```

---

## B. 反派 / 调教师常用句式（5 阶段）

### 阶段 1：命令（Command）

> 阶段定位：调教开始 / 展示权力
> 语气特点：简洁 / 强势 / 不可违抗
> 句长：极短

**模板**：
```
"跪下。"
"张嘴。"
"看着我。"
"把衣服脱了。"
"听话。"
```

**完整示例**：
```
反派（声音平静）："跪下。"
主角（挣扎）："我……"
反派（按住肩膀）："我说……跪下。"
——（主角被迫跪下）——
反派（抚摸头部）："乖。"
```

---

### 阶段 2：诱导（Lure）

> 阶段定位：调教中期 / 软化主角
> 语气特点：温柔 / 关心 / 引导
> 句长：中等 + 问句

**模板**：
```
"你这样……会受伤的……放松……"
"你看……这样是不是很舒服？"
"……别紧张……我会很温柔的……"
"你不需要……这么紧绷……"
"……你想要的……是这个对吗？"
```

**完整示例**：
```
反派（温柔）："你这样……会受伤的。"
主角（咬牙）："我……"
反派（轻抚）："放松……让我帮你……"
主角（声音已软）："我……"
反派（微笑）："你看……这样是不是很舒服？"
主角（闭眼）："……唔……"
```

---

### 阶段 3：嘲讽（Mockery）

> 阶段定位：展示权力 / 心理击溃
> 语气特点：讥讽 / 比较 / 揭短
> 句长：中等 + 尖锐

**模板**：
```
"小英雄就这点能耐？"
"你这样的……也配叫 [身份]？"
"你哥哥看到你这样……会怎么想？"
"你不是 [战队名] 的 [身份] 吗？……哦，我忘了。"
"你看……你现在像什么？"
```

**完整示例**：
```
反派（微笑）："你这样的……也配叫应龙？"
主角（咬牙）："我……"
反派（轻抚）："你看……你现在像什么？"
主角（声音已哑）："呜……"
反派（温柔）："你像……我的小宠物。"
```

---

### 阶段 4：欣赏（Appreciation）

> 阶段定位：调教成功 / 软化后
> 语气特点：赞美 / 鼓励 / 玩味
> 句长：中等 + 评价

**模板**：
```
"不愧是 [身份]……挺有骨气。"
"……你这反应……我很喜欢。"
"……你学得很快。"
"……你这身体……是为我而生的。"
"……不愧是我选中的人。"
```

**完整示例**：
```
反派（轻抚）："……你这反应……我很喜欢。"
主角（声音已软）："我……"
反派（微笑）："不愧是我选中的人。"
主角（崩溃 / 主动靠近）："……呜……"
```

---

### 阶段 5：威胁（Threat）

> 阶段定位：主角反抗时 / 升级调教
> 语气特点：警告 / 暗示 / 不露骨
> 句长：短句 + 留白

**模板**：
```
"再不听话……我就……"
"你不会想看到……他们（队友）怎样的……"
"我有的是……办法。"
"你可以继续反抗……但他们……"
"……你懂的。"
```

**完整示例**：
```
反派（按住主角）："再不听话……"
主角（挣扎）："不……"
反派（微笑）："你不会想看到……你的队友怎样的。"
主角（声音已哑）："不……不要……"
反派（温柔）："那就……乖一点。"
```

## C. 心理独白结构

### C1. 内心 vs 身体反应对照

> 原则：**身体先诚实，意识后追认**

**模板 A：身体反应 + 意识抗拒**
```
（身体反应：[乳尖挺立 / 后穴收缩 / 不自主的喘息]）
主角（内心）："为什么……我的身体……在……"
（身体反应继续）
主角（意识）："我……我不是在享受……我只是……"
```

**模板 B：身体反应 + 意识接受**
```
（身体反应：[主动靠近 / 主动索取]）
主角（内心）："我……我在做什么……"
（身体反应继续）
主角（意识）："……可是……这样……好像……"
```

**模板 C：身体反应 + 意识崩溃**
```
（身体反应：[高潮 / 失禁 / 主动求饶]）
主角（内心）："不……不要……"
（身体反应继续）
主角（意识）："……我……我已经……呜……"
```

**完整示例**：
```
（触手游走到乳尖 / 乳尖不自主挺立）
主角（内心）："为什么……我的身体……在期待……"
（触手继续 / 后穴开始收缩）
主角（意识）："我……我不是在屈服……我只是……"
（触手深入 / 主角不自主呻吟）
主角（意识崩溃）："……呜……我……❤️"
```

---

### C2. 倒装与省略

> 原则：**用语法结构暗示心理动摇**

**倒装 A：被动语态替代主动**
```
"我打他" → "我被他……"
"我脱衣服" → "衣服被我……脱掉"
"我回应" → "我不由自主地……回应"
```

**倒装 B：身体主语替代"我"**
```
"我想要" → "身体想要"
"我靠近" → "身体靠近"
"我呻吟" → "嗓子里漏出声音"
```

**省略 A：句末省略**
```
"我……"（省略"不是故意的"）
"你……"（省略"太过分了"）
"为什么……"（省略"我的身体会这样"）
```

**完整示例**：
```
"衣服……被我自己脱掉。"（暗示主角的"自我说服"）
"我……"（省略"我已经不反抗了"）
"身体……在靠近。"（暗示身体先于意识）
"嗓子……漏出声音……"（暗示无法自控）
```

---

### C3. 情绪曲线

> 原则：**用递进的情绪词营造心理深度**

**曲线模板 A：抗拒 → 困惑 → 接受 → 主动**
```
阶段 1（抗拒）："我不会……"
阶段 2（困惑）："为什么……我的身体……"
阶段 3（接受）："……也许……这只是……"
阶段 4（主动）："……我想要……"
```

**曲线模板 B：硬气 → 失态 → 崩溃 → 依赖**
```
阶段 1（硬气）："我可是 [身份]！"
阶段 2（失态）："唔……你、你别……"
阶段 3（崩溃）："呜……不要了……"
阶段 4（依赖）："……求你……不要离开……"
```

**曲线模板 C：敌人 → 好奇 → 同情 → 羁绊**
```
阶段 1（敌人）："我恨你。"
阶段 2（好奇）："……你为什么……"
阶段 3（同情）："……原来你也是……"
阶段 4（羁绊）："……我……我不想失去你……"
```

**完整示例**：
```
阶段 1："我可是龙骧的应龙……你、你休想……"
阶段 2（声音已变）："唔……你、你……为什么……"
阶段 3（叹气）："……也许……这只是……战斗的副作用……"
阶段 4（主动）："……我……我想要……❤️"
```

## D. 中日文文风差异对照

### D1. 句长与节奏

| 维度 | 中文 R-18 版 | 日文 R-18 版 |
|---|---|---|
| 平均句长 | 50-150 字 | 30-80 字（含标点）|
| 段落长度 | 300-500 字 | 200-400 字 |
| 节奏感 | 强（多用「——」「❤️」「……」）| 弱（多用「。」短句）|
| 心理独白占比 | 30-40% | 50-70% |
| 动作描写占比 | 40-50% | 20-30% |

### D2. 拟声词 / 拟态词

**中文 R-18**：
- 拟声词：「咕啾」「噗嗤」「啪嗒」「咕叽」
- 拟态词：「软绵绵」「滑腻腻」「黏糊糊」「湿漉漉」
- 装饰符号：「❤️」「——」「……」

**日文 R-18**：
- 拟声词：「はぁっ」「んっ」「ちゅっ」「ぱちゅ」
- 拟态词：「ぐしょぐしょ」「ぬるぬる」「びくびく」「とろとろ」
- 装饰符号：「！」「……」

**示例对照**：
- 中文：「他的后穴被……咕啾一声……撑开了❤️」
- 日文：「彼の尻の穴が……はぁっ……と広がった。」

### D3. 被动语态的使用

**日文 R-18**（高度依赖被动态）：
- 「～される」（被动态）
- 「～てしまう」（不自觉完成）
- 「～させられる」（被迫做）

**中文 R-18**（较少被动态）：
- "被迫"
- "不由自主"
- "我……我被他……"

**示例对照**：
- 日文：「彼は……辱められてしまった……」（他被……羞辱了）
- 中文：「他……他被……我……呜……」

### D4. 自我说服的语法化

**日文 R-18**（语法内置自我说服）：
- 「～のだから」（因为是……所以……）
- 「～はずだ」（应该是……）
- 「～てもいい」（……也可以）

**中文 R-18**（独白式自我说服）：
- "我……我只是在……"
- "这……这只是……"
- "……也许……这样……"

**示例对照**：
- 日文：「これは……戦いの副作用のはずだから……」（这只是……战斗的副作用……）
- 中文：「我……我只是在……适应……战斗的……副作用……」

### D5. emoji 与语气词的使用

**中文 R-18**（高频率 emoji）：
- 「❤️」+ 短促叠词："嗯哈……❤️"
- 「！」：用于强化语气
- 「……」：用于省略 / 喘息

**日文 R-18**（低频率 emoji）：
- 极少用 emoji
- 多用「はぁっ」「んっ」+ 拟态词
- 多用「……」表示心理停顿

### D6. 数据化 vs 氛围化

**中文 R-18**（数据精度）：
- 精确数据：「18.19cm」「44 码」「AJ23」「Nike 精英袜」
- 数据化角色卡：身高 / 体重 / 弱龄 / 弱点 / 体味
- 强化读者认知

**日文 R-18**（氛围营造）：
- 模糊数据：「大きな……」（很大的……）
- 角色化档案：职业 + 兴趣 + 場所
- 强化心理氛围

### D7. 写作建议

**若需中文 R-18 风格**：
- 长句 + 「❤️」+ 短促叠词（"嗯哈""呜"）
- 精确数据 + 数据化角色卡
- 强烈节奏感（「——」+「……」）
- 高比例动作描写

**若需日文 R-18 风格**：
- 中短句 + 被动态
- 模糊描述 + 氛围营造
- 强烈心理独白
- 高比例心理描写

**复合风格**（推荐）：
- 主体用中文 R-18 风格
- 关键心理独白用日文 R-18 风格
- 数据精度 + 氛围营造双轨
