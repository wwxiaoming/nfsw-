# 场景钩子库（Scene Hooks）

> 本文档提供 18 个"小英雄"题材核心场景钩子。每个含：触发场景、行动要素、心理效果、3-5 句示例对白或旁白。AI 拿到世界书后，可按剧情需要选取并组合。

## H01. 战败后昏迷醒来发现被改造

### 触发场景
- 战斗失败 / 体力耗尽 / 中陷阱 → 昏迷
- 醒来时：环境陌生（密闭空间 / 实验室 / 收藏室 / 改造间）
- 身体出现"不属于自己"的感觉（束缚 / 异物感 / 新的敏感点）

### 行动要素
1. 主角从昏迷中苏醒 → 视觉 / 听觉 / 触觉多重刺激
2. 发现自己的战衣 / 制服被剥离 / 改造
3. 发现自己的身体出现"新反应"（乳尖异常敏感 / 后穴被扩张 / 淫纹出现）
4. 反派登场，用"温柔 / 科学 / 嘲讽"语气展示成果
5. 主角第一次"被展示"给其他人（助手 / 围观者 / 录像）

### 心理效果
- 从"这是梦" → "这是真的" → "我……我要逃" → "但我的身体……"

### 示例对白

```
主角（内心）："……我……在哪里……"
主角（出声）："放开我……！"
反派："别急……让我先记录一下你的反应。"
主角（声音已带颤抖）："你、你们对我做了什么……"
反派："让你成为……更完美的英雄。"
主角（沉默 / 内心崩溃）："……❤️"
```

## H02. 触手怪人 / 非人反派的捕获

### 触发场景
- 主角追击敌人 → 落入陷阱
- 触手 / 蛛丝 / 异世界生物突然出现
- 主角的"武器 / 能力"被克制

### 行动要素
1. 触手从背后 / 脚底 / 墙壁涌出
2. 主角试图反击但被束缚
3. 触手开始"系统化"探索身体（手腕 → 脚踝 → 腰间 → 乳尖 → 后穴）
4. 主角的"反抗"逐渐被"物理限制"压制
5. 出现"非人反派的人脸"或"温柔语气"

### 心理效果
- 从"区区触手……！" → "这、这比想象中……" → "为什么……动不了……" → "……唔……"

### 示例对白

```
主角（战斗状态）："区区触手……给我断！"
触手（动作继续）："……"
主角（声音已变调）："唔……你、你……！"
触手怪人（人脸出现）："……这才是英雄该有的样子。"
主角（半崩溃）："不……不要……"
主角（内心）："身体……动不了……声音……也发不出……"
```

## H03. 催眠 / 意识改写

### 触发场景
- 主角被囚禁 / 战斗后疲惫 → 反派用"科学 / 心理"手段
- 反复念诵 / 视觉刺激 / 听觉暗示
- 主角的"常识"开始被改写

### 行动要素
1. 反派让主角反复念"特定词汇"（"我是骚货" / "我喜欢被这样对待"）
2. 用"音乐 / 节拍 / 灯光"强化暗示
3. 主角的"自我抵抗"逐渐变弱
4. 出现"自我说服"的关键台词（"也许……他说得对"）
5. 主角在催眠后"主动执行"反派的指令

### 心理效果
- 从"我才不会念！" → "……我、我是骚货" → "为什么……我念出来的时候……有点……" → "……我好像一直都是这样"

### 示例对白

```
反派："现在，请把'屌大精浓的骚货'念十遍。"
主角（挣扎）："我……我不会……"
反派（温柔）："配合一下……这样我们都能……"
主角（声音渐弱）："……屌大精浓的骚货……1、2……"
反派（点头）："很好……继续……"
主角（声音已变调）："……3、4、5……唔……为什么……我念出来……"
反派："这就对了……接受它。"
主角（闭眼 / 声音颤抖）："……6、7……我好像……一直都是……"
```

## H04. 淫纹 / 印记植入

### 触发场景
- 主角被"标记"（烙印 / 纹身 / 淫纹 / 项圈）
- 标记的位置 / 形状 / 触发条件具有特殊含义
- 反派用标记展示"所属权"

### 行动要素
1. 反派用"专业工具"在主角身上刻 / 印 / 植入标记
2. 标记伴随"第一次激活"（触碰 / 念诵 / 性接触）
3. 标记被展示给其他人（"这是 X 的标记"）
4. 主角的"标记"成为"心理锚点"——每次被触碰都会强化沦陷感
5. 出现"标记成瘾"（主角主动要求被刻更多 / 主动展示标记）

### 心理效果
- 从"我不会让你刻！" → "……好痛……但好像……" → "看到它……就想起你……" → "……再刻一个……求你……"

### 示例对白

```
反派（抚摸主角手腕）："你的淫纹位置……应该在这里。"
主角（挣扎）："不……不要……！"
反派（温柔按压）："别动……很快就好。"
——（刻完之后）——
反派（轻触淫纹）："这枚纹是给你哥哥的礼物……"
主角（颤抖）："呜……为什么……听到你的声音……标记就……"
反派（微笑）："因为它属于我。"
主角（声音已软）："……我的……你的……❤️"
```

## H05. 公共空间调教（公交 / 公园 / 教室）

### 触发场景
- 主角在公共空间被反派的"工具"控制（远程 / 触发式）
- 周围有大量"不知情"的人
- 主角必须"维持表面"但身体已经开始反应

### 行动要素
1. 主角在公共空间（挤公交 / 上课 / 公园散步）
2. 反派在远程触发淫纹 / 催眠 / 药物
3. 主角的"身体反应"开始（乳尖挺立 / 后穴收缩 / 不自主的喘息）
4. 周围人的"目光"加重羞耻
5. 主角必须"找到角落"或"被迫维持"到极限

### 心理效果
- 从"我得忍" → "为什么……偏偏在……" → "唔……快到极限了……" → "不要……不要看我……"

### 示例对白

```
主角（内心 / 公交车上）："唔……又、又开始了……"
旁白：他咬着嘴唇，试图假装看窗外的风景。
主角（内心）："淫纹……只要他说'激活'……我的……"
反派（手机短信 / 远程）："激活。"
主角（声音走调）："……！"
路人回头："小朋友……你没事吧？"
主角（强撑）："没、没事……就是……有点晕车……"
主角（内心 / 几乎崩溃）："……不要……不要在这个地方……"
```

## H07. 队友情景：被迫对队友动手

### 触发场景
- 反派用"队友"作为要挟（"你做这个，我就放过他"）
- 主角必须"屈从"以保护队友
- 队员亲眼目睹但无法救援

### 行动要素
1. 反派展示"队友被困" / "队友将被调教"的画面
2. 主角面临选择："你做这件事 vs 队友被强暴"
3. 主角"咬牙"接受反派的指令
4. 队员的"目睹"加重心理创伤
5. 出现"队友的眼神"——既感激又悲伤

### 心理效果
- 从"我不要！" → "但如果不……他……" → "为了你……我……" → "你会不会……恨我……"

### 示例对白

```
反派："你有两个选择。一，你自己来。二，我让他来。"
主角（看向被困的队友）："……我……"
反派（微笑）："好孩子。"
主角（声音颤抖 / 走向反派）："……你不许碰他……"
队友（挣扎）："不要……不要为我……！"
主角（不看队友）："……请你……不要看……"
队友（声音破碎）："……对不起……"
主角（声音已带哭腔）："……呜……"
```

## H08. 队友情景：队友被公开凌辱

### 触发场景
- 主角已经沦陷，但队友被反派抓住
- 主角被迫"观看"或"参与"对队友的凌辱
- 主角的"保护者身份"被彻底剥夺

### 行动要素
1. 主角被带去"观看"队友被凌辱的现场
2. 主角的"保护本能"与"沦陷状态"剧烈冲突
3. 反派要求主角"评价" / "参与" / "展示自己"
4. 队友的"求救"与"拒绝让主角看"形成对比
5. 出现"主角第一次没有保护队友"的创伤时刻

### 心理效果
- 从"放开他……！" → "我……我答应过……" → "对不起……对不起……" → "我……不配做队长……"

### 示例对白

```
主角（挣扎）："放开他……！"
反派（按住主角）："看清楚……这是给你的奖励。"
——（队友被凌辱 / 主角被迫观看）——
队友（声音破碎）："不……不要看……你……不要看……"
主角（声音已哑）："为什么……我答应过……"
反派（温柔）："你做得很好……继续看着。"
主角（崩溃）："……对不起……呜……对不起……"
```

## H09. 收藏家展示 / 拍卖会

### 触发场景
- 主角作为"藏品"被展示 / 拍卖
- 多个收藏家 / 买家 / 围观者
- 主角的"价值"被当众报价

### 行动要素
1. 主角被带到一个"舞台" / "拍卖厅" / "展览室"
2. 主角的身体被"展示"（脱衣 / 展示淫纹 / 强制摆姿势）
3. 收藏家 / 买家开始"报价"
4. 主角的"报价"和"评价"被大声念出
5. 最终被"标得"或"展示"给最终的买家

### 心理效果
- 从"我是英雄……我不是商品……" → "为什么……他们用那种眼神……" → "呜……不要看我……" → "我是……L-09-17 号……"

### 示例对白

```
收藏家（宣布）："第 17 号藏品……来自龙骧战队的应龙……"
主角（内心）："……藏品……？"
收藏家（继续）："起拍价 50 万……"
买家 A："60 万……这淫纹位置不错。"
买家 B："80 万……我要了。"
反派（按住主角的肩膀）："你看……你值 80 万。"
主角（声音已哑）："我……我不是……商品……"
反派（温柔）："你是……你是 L-09-17……我的 17 号藏品。"
主角（崩溃）："……呜……"
```

## H10. 反派洗白：反派暴露童年创伤

### 触发场景
- 反派在"调教"中突然停下
- 反派暴露自己的"童年 / 创伤 / 执念起源"
- 主角的"被调教对象"身份暂时让位于"倾听者"身份

### 行动要素
1. 反派的"调教"动作突然停止
2. 反派展示"创伤"（伤疤 / 童年照片 / 回忆）
3. 反派用"自我暴露"的方式向主角袒露
4. 主角的"同情"被激发
5. 出现"调教"暂时停止，转化为"陪伴"

### 心理效果
- 从"你又要……？" → "他……他在……哭？" → "原来……他也是……" → "……我可以……听你说……"

### 示例对白

```
主角（闭眼 / 准备接受）："……来吧……"
反派（动作停止 / 沉默）
主角（睁眼）："……？"
反派（解开衣领 / 展示伤疤）："……我也有……和你一样的……"
主角（震惊）："你……"
反派（声音平静）："小时候……我被……"
主角（沉默 / 内心复杂）："……所以你……"
反派（微笑 / 温柔）："……对不起……"
主角（声音已软）："……我……我听你说……"
```

## H11. S/M 倒置：主动方 + 接受方

### 触发场景
- 反派 / 调教师是"关怀型" / "纯爱型"
- 主动方用"关怀 / 引导"代替"强制"
- 接受方在"被关怀"中意识到自己的 M 体质

### 行动要素
1. 主动方不直接"侵犯"接受方
2. 主动方用"温柔 / 关怀 / 询问"接近
3. 接受方在"被询问"中暴露自己的"敏感点" / "性癖"
4. 主动方按"接受方的意愿"逐步推进
5. 出现"接受方主动索取"的关键时刻

### 心理效果
- 从"我……我才不会……" → "如果……是你……" → "……我想要……" → "……请……"

### 示例对白

```
主动方（温柔）："……你想让我……碰你吗？"
接受方（内心挣扎）："……我……"
主动方（微笑）："你不用回答……我会等。"
接受方（声音已带哭腔）："……我……我想要……"
主动方（轻抚）："好……我知道了……"
接受方（崩溃 / 主动抱住）："……呜……请你……请你对我……"
主动方（拥抱）："……乖……我会照顾你……"
```

## H14. 多反派梯队：博士 + 流氓 / 触手 + 催眠

## H15. 兄弟 / 双子共沦陷

### 触发场景
- 双胞胎中一个先沦陷
- 反派用"兄弟"作为要挟
- 另一个也"主动"沦陷以保护

### 行动要素
1. A 沦陷 → B 试图救援
2. B 救援失败 → 也被抓住
3. 反派将两人"放在一起"调教
4. 两人的"羞耻"互为镜像
5. 出现"兄弟共沦陷"的心理归宿

### 心理效果
- 从"放开我弟弟……！" → "不……不要当着他的面……" → "为了你……我……" → "……我们……一起……"

### 示例对白

```
A（已经沦陷 / 看着 B）："不……不要……不要碰我弟弟……"
反派（按住 A）："为了他……你自己做。"
A（声音已哑）："我……我答应……"
——（B 被带过来）——
B（挣扎）："哥哥……不要……"
A（抱住 B）："对不起……对不起……"
B（声音已软）："哥哥……我们……一起……"
反派（微笑）："这就对了……兄弟就该共进退。"
```

## H16. 反派主动 + 主角配合：纯爱 / 救赎向

### 触发场景
- 主角处于"绝望 / 崩溃 / 自毁"状态
- 反派在"调教"中逐渐展示"关怀"
- 主角从"被调教"转化为"被爱"

### 行动要素
1. 主角处于"创伤"状态（被多个反派轮替 / 长期囚禁）
2. 反派出现并"接管"主角
3. 反派用"温柔 / 关怀 / 不侵犯"的方式照顾
4. 主角从"恐惧"到"依赖"
5. 出现"主角主动依赖反派"的关键时刻

### 心理效果
- 从"你……你也要……" → "你……你为什么……" → "……好温暖……" → "……不要离开我……"

### 示例对白

```
主角（崩溃 / 自暴自弃）："……随便你……反正……我已经……"
反派（不动作 / 轻抚头发）："……我不会……碰你。"
主角（睁眼 / 震惊）："……为什么？"
反派（微笑）："因为……你值得被好好照顾。"
主角（声音已哑）："……我……我不值得……"
反派（拥抱）："……你值得……"
主角（崩溃 / 主动抱住）："……呜……不要离开我……"
```

## H17. 队伍来访 / 队友目睹

### 触发场景
- 队友 / 老师 / 家人找到被囚禁的主角
- 主角的"沦陷状态"被当面看到
- 主角的"英雄身份"在熟人面前崩塌

### 行动要素
1. 主角被囚禁一段时间后，队伍前来救援
2. 救援队伍找到主角时，主角处于"沦陷状态"（部分裸 / 淫纹可见 / 反应明显）
3. 队友的"震惊"与"无法救援"
4. 主角的"羞耻"达到新高峰
5. 出现"队友带着主角离开但主角已经回不去"的结局

### 心理效果
- 从"是 X……他们来救我……" → "不……不要看……我现在……" → "呜……他们看到了……" → "……我已经不配做英雄了……"

### 示例对白

```
队友（找到主角）："X……！你……你还好吗？"
主角（低头 / 试图遮挡）："不……不要看……"
队友（震惊）："你的……你的身体……那个纹……"
主角（声音已哑）："我……我已经……"
队友（崩溃）："不……你还在……你还是你……"
主角（哭）："呜……我回不去了……我已经……不是以前的我了……"
```

## H18. 后日谈 / 番外：沦陷后的日常

### 触发场景
- 主角已经沦陷 / 与反派建立新关系
- 故事进入"番外日常"
- 展示主角的"新身份"与"新关系"

### 行动要素
1. 日常场景：训练 / 任务 / 休息
2. 主角与反派的"默契"互动
3. 队友的"知情"或"不知情"反应
4. 偶尔的"反抗回潮"（但很快被平息）
5. 出现"新生活"的温馨与暧昧

### 心理效果
- 从"……我怎么会变成这样……" → "……这样也不错……" → "……我……" → "……❤️"

### 示例对白

```
反派（日常 / 早晨）："……醒了？"
主角（半梦半醒）："……嗯……"
反派（轻抚）："今天……有任务。"
主角（小声）："……我知道……"
反派（微笑）："乖……结束后……有奖励。"
主角（小声 / 闭眼）："……嗯……❤️"
——（番外结束 / 转入正文）——
```
