## 🛎 步骤完成弹窗协议（v9 流程，2026-06-21 增）

> **原则**：每个关键步骤完成后，**主代理必须用 AskUserQuestion 弹窗**让用户决定下一步。不跳过、不擅自连跑。

### 弹窗触发场景
1. **Step 0 检查完成**（启动前）— 弹窗确认是否启动
2. **Step 1-6 派发完成**（含 retry）— 弹窗确认是否继续
3. **Step 7 草稿合并 / 笔记优化**（任一子步骤）— 每完成一子步弹窗
4. **Step 8 验证完成**（实际读 / 段号 / 覆盖）— 弹窗确认是否收尾
5. **跨批次切换** — 弹窗确认是否进入下一批次

### 弹窗模板（统一格式）
```
✅ {步骤名} 完成（{关键数据}）。
🔜 下一步：{下一步名称}（{预计耗时/规模}）。
请选择：
  1. {默认选项 - 继续}（推荐）
  2. {备选 1}
  3. {备选 2}
  4. {其他}
```

### v3 笔记优化（选项 1）的弹窗节点
- **弹窗 1**：读 v2 笔记现状 → 下一步（分析草稿）
- **弹窗 2**：v2 vs 草稿差异分析 → 下一步（设计 v3 结构）
- **弹窗 3**：v3 结构设计 → 下一步（写 v3 笔记）
- **弹窗 4**：v3 笔记 8 段完成 → 下一步（TOC + 锚点 + 验证）

**记忆文档 = 持久状态；主对话 = 极简索引。** 每批次完成后，主对话只保留 1-2 句状态 + 链接，所有细节下沉到记忆区。
