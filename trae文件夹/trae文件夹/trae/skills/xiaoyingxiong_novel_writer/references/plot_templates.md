# 剧情模板库（Plot Templates）

> 本文档提炼 5 套"小英雄"题材的剧情模板，每套包含阶段拆解（5-8 阶段）、关键转折、节奏曲线、变体说明。每套模板均可独立成章，也可作为多卷长篇的整体结构。

---

## T1. 单反派长程沦陷（Single Antagonist Long-term Corruption）

### 适用场景
- 主角被一个固定反派（淫纹师 / 催眠博士 / 收藏家 / 触手怪人）长时间调教
- 故事核心是"一人对一人的权力游戏"
- 适合中长篇（10-30 章）

### 阶段拆解（8 阶段）

```
【阶段 1】身份展示
├─ 展示主角的"英雄日常"：训练 / 任务 / 队友互动
├─ 暗示主角的"隐藏性癖"或"心理弱点"
├─ 引入反派的"神秘存在"（如反派在全城的"标记"事件）
└─ 阶段长度：1-2 章

【阶段 2】首次冲突与战败
├─ 主角与反派的第一次正面交锋
├─ 主角的"最强武器"被克制
├─ 主角战败 → 昏迷 → 醒来发现被囚禁
└─ 阶段长度：1-2 章

【阶段 3】被囚禁与第一次胁迫
├─ 反派展示"调教师身份"（实验室 / 收藏室 / 改造间）
├─ 第一次强制接触（剥离衣物 / 强制束缚 / 第一次侵犯）
├─ 主角的"高傲反抗"（"我才不会屈服！"）
└─ 阶段长度：2-3 章

【阶段 4】身体觉醒
├─ 反派用"专业 / 温柔 / 科学"包装继续调教
├─ 主角的身体开始"不自主"反应
├─ 主角尝试反抗但身体不配合
├─ 关键台词："为什么……我的身体……"
└─ 阶段长度：2-3 章

【阶段 5】自我说服
├─ 主角开始"自我说服"（"这只是战斗副作用" / "我没有真的屈服"）
├─ 反派用"心理学话术"或"淫纹 / 催眠"强化
├─ 第一次"主动配合"（虽然不承认）
└─ 阶段长度：2-3 章

【阶段 6】身份崩塌
├─ 反派将主角的"沦陷"展示给队友 / 公众
├─ 主角的"英雄身份"在心理上崩塌
├─ 出现"专属称号"（"贱屌英雄" / "英雄犬"等）
├─ 关键转折：主角第一次主动使用这个称号称呼自己
└─ 阶段长度：2-4 章

【阶段 7】彻底沦陷
├─ 主角的"自我说服"完全失败
├─ 反派的"所有权"被主角内心接受
├─ 出现"主动展示 / 主动索取"行为
└─ 阶段长度：2-3 章

【阶段 8】新平衡
├─ 主角在"沦陷"中找到新的身份锚点（保护队友 / 维持战队 / 接受现状）
├─ 反派的"控制"从"强制"变为"默契"
├─ 出现"后日谈"或"番外"（日常生活 / 战斗配合 / 队友知情）
└─ 阶段长度：1-2 章
```

### 关键转折

1. **战败转折**（阶段 2→3）：从"英雄"到"囚犯"的身份切换
2. **身体觉醒转折**（阶段 4→5）：从"我能控制自己"到"身体先诚实"
3. **身份崩塌转折**（阶段 5→6）：从"我不是这种人"到"我好像就是这种人"
4. **彻底沦陷转折**（阶段 6→7）：从"我在演戏"到"我需要这个"

### 变体说明

- **变体 A：科学调教师型**——反派用 HIP-HOP 节奏的话术，主角的"自我说服"更密集
- **变体 B：温柔大哥哥型**——反派用"专业"包装，主角的"心理松动"更快
- **变体 C：触手怪人型**——反派非人，节奏更机械化，主角的"反抗"更孤立
- **变体 D：收藏家型**——反派有"藏品编号"系统，主角的"身份崩塌"更仪式化

## T2. 多人轮替沦陷（Multi-Handler Rotation）

### 适用场景
- 主角被多个反派 / 调教师轮流调教
- 故事核心是"权力结构的层级"
- 适合中长篇战队文（10-25 章）

### 阶段拆解（6 阶段）

```
【阶段 1】第一调教师登场
├─ 主角被第一个反派（通常是"科学 / 温柔"型）捕获
├─ 经历 T1 的阶段 3-5（被囚禁 → 第一次胁迫 → 身体觉醒）
├─ 在第一调教师手下"半沦陷"
└─ 阶段长度：2-3 章

【阶段 2】调教师交接
├─ 主角被"转交"给第二调教师（"流氓 / 催眠"型）
├─ 第一调教师的"所有物"标记被覆盖为第二调教师的
├─ 主角的"沦陷进度"被新的调教师"清零"或"加速"
└─ 阶段长度：1-2 章

【阶段 3】第二调教师的特殊调教
├─ 第二调教师使用"完全不同的手段"（言语羞辱 / 群体凌辱 / 物理重塑）
├─ 主角的"第一调教师"留下的心理防线被击溃
├─ 出现"调教师之间的对比台词"（"X 调教师太温柔了"）
└─ 阶段长度：2-3 章

【阶段 4】第三 / 第四调教师轮替
├─ 主角被反复"转交"给不同调教师
├─ 每个调教师留下"专属烙印"（淫纹 / 调教师称号 / 物理标记）
├─ 主角的"心理抵抗"越来越弱
└─ 阶段长度：3-5 章

【阶段 5】群体凌辱高潮
├─ 所有调教师 + 围观者 + 主角的"展示"
├─ 公共空间（舞台 / 展览 / 比赛 / 拍卖）
├─ 主角的"英雄身份"在社会层面崩塌
└─ 阶段长度：1-2 章

【阶段 6】新主控者确立
├─ 出现"最终主控者"（第一调教师的回归 / 更高级反派 / 主角的"最终接受"）
├─ 主角的"多调教师标记"被收编为"主控者的所有物"
├─ 进入"稳定期"或"番外日常"
└─ 阶段长度：1-2 章
```

### 关键转折

1. **第一调教师转交**（阶段 1→2）：从"专属调教师"到"流水线产品"
2. **新调教师的"清零"**（阶段 2→3）：主角的"沦陷进度"被重置
3. **公共空间展示**（阶段 4→5）：从"私密"到"公开"的社会性崩塌
4. **最终主控者**（阶段 5→6）：从"多调教师"到"唯一归属"的心理归宿

### 变体说明

- **变体 A：流氓少年群 + 博士双反派**（"光莲"型）——流氓负责羞辱，博士负责改造
- **变体 B：黄毛 + 魔犬双反派**（"帝王"型）——不良少年 + 异兽
- **变体 C：触手怪人 + 调教师梯队**（"光莲红莲"型）——触手为主，其他为辅
- **变体 D：拍卖会 / 奴隶交易**（"帝王番外"型）——主角被"标价"后流转

## T3. 卧底反被驯化（Undercover Becoming the Tamed）

### 适用场景
- 主角以"卧底 / 反派内部成员"身份潜入敌营
- 故事核心是"以为是猎人实际是猎物"
- 适合中篇（8-15 章）

### 阶段拆解（7 阶段）

```
【阶段 1】任务接受
├─ 主角接到"潜入敌营"的任务
├─ 主角的"自信"（"我才不会被影响"）
├─ 队伍 / 上级的送行（暗示这是"危险任务"）
└─ 阶段长度：1 章

【阶段 2】潜入成功
├─ 主角成功伪装成反派内部成员
├─ 接触反派核心（淫纹师 / 收藏家 / 催眠博士）
├─ 收集情报 / 等待时机
└─ 阶段长度：1-2 章

【阶段 3】第一次被识破 / 暴露
├─ 反派发现主角的真实身份
├─ 但反派没有立刻"击杀"或"驱逐"主角
├─ 反派选择"调教主角"作为"报复 + 收藏"
└─ 阶段长度：1 章

【阶段 4】伪装 → 半接受
├─ 主角被反派的"温柔 / 力量 / 理解"打动
├─ 主角开始"享受"被反派关注
├─ 主角的"任务"被逐渐淡忘
├─ 关键台词："也许……这里也不错……"
└─ 阶段长度：2-3 章

【阶段 5】"最后任务"的迟疑
├─ 主角接到"最后任务"（破坏反派核心 / 刺杀反派头目）
├─ 主角在"任务"与"沦陷"之间犹豫
├─ 出现"被队友发现"的危机时刻
└─ 阶段长度：1-2 章

【阶段 6】最终反转
├─ 主角选择不执行任务（保护反派 / 与反派共进退）
├─ 或主角执行任务但反派"假死"后出现
├─ 主角的"英雄身份"完全放弃 / 转化为"双面身份"
└─ 阶段长度：1-2 章

【阶段 7】新平衡
├─ 主角的"卧底身份"成为过去
├─ 主角成为反派的"核心成员 / 收藏品"
├─ 出现"队伍来访"或"战友对决"等番外桥段
└─ 阶段长度：1-2 章
```

### 关键转折

1. **被识破转折**（阶段 3）：从"猎人"到"猎物"的身份反转
2. **半接受转折**（阶段 4）：从"演戏"到"也许是真的"
3. **任务迟疑转折**（阶段 5）：从"我不会犹豫"到"我好像犹豫了"
4. **最终反转转折**（阶段 6）：从"我是卧底"到"我是这里的人"

### 变体说明

- **变体 A：双面间谍型**（"凯风"型）——假装战败最终真戏
- **变体 B：被识破后洗白**（"敏寒之"型）——反派最终成为情人
- **变体 C：多卧底共沦陷**（群像型）——多主角同时潜入同时沦陷
- **变体 D：主动叛逃型**——主角不是被识破，而是主动选择"这里更好"

## T4. 群像多线推进（Ensemble Multi-line）

### 适用场景
- 多主角（4-7 人）同时沦陷
- 故事核心是"战队 / 群像 / 跨角色情感"
- 适合长篇（20-50 章）

### 阶段拆解（5 阶段 + 横向时间轴）

```
【横向时间轴】每章使用"地点 / 角色 / 时间"三坐标切换
├─ 例：第 3 章 #1 千洛在 A 地点 #1 时间
├─ 例：第 3 章 #2 玄麟在 B 地点 #2 时间
├─ 例：第 3 章 #3 天岚在 C 地点 #3 时间
└─ 每章 2-3 个角色片段，1 个主线 + 1-2 个支线

【阶段 1】战队介绍 + 日常展示
├─ 介绍每名队员的"身份 + 性格 + 弱点"
├─ 展示战队日常（训练 / 任务 / 休息）
├─ 暗示每名队员的"隐藏性癖"
└─ 阶段长度：1-2 章

【阶段 2】第一位沦陷（核心队员）
├─ 队长 / 王牌 / 副队先沦陷
├─ 其他队员的"震惊 / 救援失败"
├─ 沦陷队员成为"后续沦陷的起点"
└─ 阶段长度：3-5 章

【阶段 3】连锁沦陷（多位队员）
├─ 救援 → 失败 → 第二位沦陷
├─ 第二位的沦陷方式与第一位不同（不同调教师 / 不同子类型）
├─ 战队陷入"必须救队友"的循环
└─ 阶段长度：5-10 章

【阶段 4】全部沦陷或转机
├─ 选项 A：全部沦陷 → 群像共沦陷（"群交落地"）
├─ 选项 B：出现转机（外部救援 / 反派内讧 / 主控者反水）
├─ 阶段长度：3-5 章
└─ 转机后：战队重建 / 战队解散 / 战队成为反派组织

【阶段 5】番外 / 后日谈
├─ 每名队员的"沦陷后日常"
├─ 跨角色关系（队员之间的羁绊 / 恋爱 / 嫉妒）
├─ 调教师 / 反派的"番外视角"
└─ 阶段长度：5-10 章
```

### 关键转折

1. **第一位沦陷转折**（阶段 1→2）：从"战队"到"裂痕"
2. **连锁沦陷转折**（阶段 2→3）：从"救援"到"越救越陷"
3. **全部沦陷 / 转机转折**（阶段 3→4）：从"循环"到"破局"
4. **新身份转折**（阶段 4→5）：从"战队"到"新群像"

## T5. 敌人变情人（Enemy to Lover）

### 适用场景
- 反派 / 调教师最终与主角建立情感羁绊
- 故事核心是"从施害到相爱"
- 适合中篇（10-20 章）

### 阶段拆解（6 阶段）

```
【阶段 1】反派的全能展示
├─ 反派的"强大 / 神秘 / 优雅"展示
├─ 反派的"童年创伤 / 执念起源"暗示
├─ 主角的"被震慑 / 被吸引"反应
└─ 阶段长度：1-2 章

【阶段 2】战败 + 调教开始
├─ 主角被反派捕获
├─ 经历 T1 阶段 3-5（被囚禁 → 身体觉醒 → 自我说服）
├─ 但反派的"调教"中夹杂"关怀 / 理解 / 童年回忆"
└─ 阶段长度：3-5 章

【阶段 3】情感萌芽
├─ 主角的"沦陷"中开始混入"对反派的依赖"
├─ 反派的"调教"中开始混入"对主角的心软"
├─ 出现"反派的小动作"（多塞一块面包 / 放轻动作 / 临时中止调教）
└─ 阶段长度：2-3 章

【阶段 4】情感爆发
├─ 反派暴露自己的"创伤 / 童年 / 真相"
├─ 主角"同情 / 共情"反派
├─ 反派的"调教"暂时停止，转化为"关怀"
├─ 关键场景：反派第一次"不调教但陪伴"主角
└─ 阶段长度：1-2 章

【阶段 5】关系确立
├─ 主角主动 / 被动表达"我……我好像……"
├─ 反派接受 / 犹豫 / 拒绝
├─ 出现"外部阻碍"（其他反派 / 队伍 / 调教师职责）
└─ 阶段长度：1-2 章

【阶段 6】新关系
├─ 反派放弃"调教师"身份（部分放弃 / 全部放弃）
├─ 主角的"沦陷"转化为"自愿献身"
├─ 出现"双主角向"或"复仇向"的最终高潮
└─ 阶段长度：1-2 章
```

### 关键转折

1. **反派关怀转折**（阶段 2→3）：从"调教"到"陪伴"
2. **情感爆发转折**（阶段 3→4）：从"权力游戏"到"情感联结"
3. **关系确立转折**（阶段 4→5）：从"调教师 vs 调教师对象"到"两个独立的人"
4. **新关系转折**（阶段 5→6）：从"被调教"到"被爱"

## T6. 复合模板（Hybrid Templates）

> 真实创作中，单一模板往往不够。可组合使用：

### T1 + T2 复合
- 单反派长程沦陷作为"主线"
- 多人轮替沦陷作为"中段升级"
- 例：龙骧 #1-10 走 T1 路线，#11-15 加入流氓少年群做 T2 升级

### T1 + T5 复合
- 单反派长程沦陷作为"前半"
- 敌人变情人作为"后半"
- 例：双子特工 2（敏寒之线）走"调教师 → 羁绊 → 反派洗白"路径

### T4 + T2 复合
- 群像多线作为"整体结构"
- 多人轮替沦陷作为"每名队员的内部结构"
- 例：进化之路 38 章后的雷霄线 = 群像 + 轮替

### T3 + T5 复合
- 卧底反被驯化作为"主线"
- 敌人变情人作为"结局"
- 例：帝王凯风篇 = 假装战败 → 驯化 → 假戏真做

### T2 + T5 复合
- 多人轮替沦陷作为"调教师更替"
- 敌人变情人作为"最终归宿"
- 例：超人暂存 → 鹰线 = 科学调教师 → 情感羁绊
