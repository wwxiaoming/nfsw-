## XP 偏好说明
- **加分项（+1-3）**：正太、小英雄、榨精、龟责、紧身衣、足控、触手等榨精生物；多 XP 命中时总分上限 +5
- **减分项（-1-3）**：雷女性、雷血腥；多雷点同时命中时总分下限 -3
- **调整后权重 = 原始权重 + XP 加分 - 雷点减分**，范围限制 **1-10**
- **原始权重反映客观质量（文本结构/完成度/章节密度），XP 调整反映个人偏好**
- 09_女性向子类**全部 -3 雷女性分**，仅做风格识别，不进入 v2 Skill 自动生成管线

## 关键发现

### 发现 1：XP 命中与子类的强相关
- **03 正太校园** → 100% 正太命中（25/25 部获得 +2 正太基础分）
- **05 异种触手** → 100% 触手命中（10/10 部获得 +1~+3 触手加分）
- **04 调教拍卖** → 90% 榨精命中（9/10 部获得 +2 榨精加分）
- **01 战队特摄** → 100% 小英雄命中（8/8 部获得 +1~+2 小英雄加分）
- **02 勇者魔物** → 50% 榨精命中 + 90% 小英雄命中
- **08 同人** → 80% 榨精/触手/小英雄多 XP 命中

### 发现 2：高分作品（XP 调整后 9-10）集中在
- 03 正太校园（16 部）— 用户核心 XP 命中+多数作品因正太/足控/榨精多 XP 加分跃升
- 02 勇者魔物（11 部）— 史诗骨架+勇者小队群堕模板价值最高
- 04 调教拍卖 + 05 异种触手（各 8 部）— 系统流/异种榨精稳定产出
- 01 战队特摄（4 部）— 反派主导长篇+标杆白曜
- 06 修真玄幻（3 部）— 蔚羽修真榨精系统单点突破
- 08 同人（7 部）— 原作 IP + 榨精/触手模板

### 发现 3：低分作品（XP 调整后 1-4）集中在
- **09 女性向**（100% 雷女性，3/3 部 -3 分）— 全降为 1-4 分
- **06 修真玄幻**（与"小英雄"主题契合度中等偏低）— 1/5 部 1-4 分
- **07 外语**（Skill 复用难度大）— 1/5 部 1-4 分

- **04/05 偏题**（悬疑/古典偏离）— 各 1 部 1-4 分
