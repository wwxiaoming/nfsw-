### 1.2 阅读规则

- 10 分 = 100% 必读：每章都通读

- 7-8 分 = 70-80% 必读：作品信息 + 关键章
- 5-6 分 = 50-60% 必读：作品信息 + 前 1-3 章
- 4 分及以下：仅作品信息 + 1 章

> **用户硬约束**："只有 1 章的直接读" — 1 章作品全部 100% 通读。

### 3.5 与 v1 SKILL 的关键差异

- **触手术语已统一改写为"榨精魔物"**（用户硬性要求）——v1 中"触手/触须"现全部改写为"榨精魔物/精气抽取生物"
- **新增"万界穿梭调教"作为系统流高阶变体**（v1 仅有"现代都市+少量古代穿越"）
- **新增"医学化调教叙事"包装**（v1 是"暴力/羞辱/强制"为主）
- **新增"都市淫修 / 精气采补"中国古典仙侠分支**（v1 缺"中式精气"标签）
- **新增"精源经济 / 精牛世界"完整世界观**（v1 精牛是"标签"，本作是"文明"）
- **新增"机构化调教师"**（v1 是"独立个人"如亚伯/苗苗）
- **新增"拍卖会 / 公开精液拍卖"具体场景**（v1 缺具体场景）
- **新增"修为返还系统"作为 M 变体**（v1 仅有"系统惩罚"型）
- **新增"主题性性奴场景"作为场景库**（v1 较少"花丛/厨房/擂台"主题化）
- **新增"多主角战队 POV"作为叙事结构**（v1 触手兽化是单主角 POV）
- **新增"圣兽原型 + 性格标签"作为角色设计模板**（v1 角色性格同质化）
- **新增"论坛 / 网页作为叙事框架"作为短篇集组织方式**（v1 没有这个组织方式）
- **新增"非人类调教师"作为反派变体**（v1 调教师都是人类）
- **新增"邪教仪式 / 献祭调教"作为具体场景**（v1 缺邪教母题）
- **新增"触手宇宙 / 触手系列化"作为世界观扩展**（v1 缺系列化结构）
- **新增"性游戏 / 色情大富翁"作为调教结构**（v1 缺性游戏母题）
- **新增"非战斗向兽化共生"作为情感变体**（v1 兽化是战斗/敌对为主）

### 7.5 写作技法（综合）

1. **"系统流"作为 v1 已有的母题**——v2 必须保留，但新增"万界穿梭"和"修为返还 M 变体"。
2. **"榨精魔物"作为 v1 触手的改写**——必须保留"插入/缠绕"功能，但**术语统一改写为"榨精魔物"**。
3. **"主题化场景"作为 v2 增量**——把"性奴场景"主题化（花丛/厨房/擂台/牢笼/下水道/城堡），是 v2 最强场景库。
4. **"多主角 + 多 POV"作为 v2 增量**——多英雄轮流被俘/被救，避免单主角疲劳。
5. **"圣兽原型 + 性格标签"作为 v2 增量**——按"原型性格"设计调教剧本。
6. **"论坛 + 短篇集"作为 v2 增量**——把"短篇集"组织成"网络空间"。
7. **"非人类调教师"作为 v2 增量**——虫嗣 / 异维度生物作为"非人类调教师"。
8. **"邪教仪式 + 淫纹"作为 v2 增量**——v1 缺邪教母题，本作提供最完整范本。
9. **"触手宇宙 / 触手系列化"作为 v2 增量**——"系列号 + 章节 + 原型"结构。
10. **"非战斗向兽化共生"作为 v2 增量**——"愿望是交融"而非"战斗"。
11. **"中式精气"作为 v2 增量**——与"日系榨精"并列，**扩大题材库**。
12. **"精源经济 / 精牛世界"作为 v2 增量**——把"精牛"从"标签"升级为"文明"。
13. **"机构化调教师"作为 v2 增量**——把"调教师"从"独立个人"升级为"机构化"。
14. **"公开拍卖 + 围观"作为 v2 增量**——v1 缺具体场景，本作提供。
15. **"修为返还 M 变体"作为 v2 增量**——被徒弟反向调教获得修为返还。
