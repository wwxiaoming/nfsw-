## 高分代表作（9-10 分）

- **夏日契约（33 章，9 分）**：本子类**唯一最完整**的兄弟赌约奴隶长篇，章节推进清晰（赌约→惩罚→插入→公开→玩具→日常→终曲），且 5 次重制版本沉淀，作者保留"番外+AU 投票"机制，是"校园兄弟养成+重制模板"的标杆。可作 Skill **兄弟向/赌约奴隶/重制版系列**核心参考。

- **学生奇遇（24 章，9 分）**：三季完整长篇（夜遇→嘉乐→陈默三角→失踪/虐待/救赎），融合"纯爱+恋足+霸凌+绑架+救赎"多元素，人物卡完备（奇遇/陈默），从温馨到黑暗再回归治愈，**情感弧线最成熟**。可作 Skill **多季+多元素+三角关系**模板。

- **正太胶囊公司（21 章，8 分）**：本子类**唯一赛博朋克/科幻题材**，含基因编辑、仿生人、量子危机、人偶性爱大赛等硬核设定，20 章完结，剧情结构最宏大。可作 Skill **科幻+正太采集+硬核设定**唯一样本。

- **少年赤脚行（9 章，8 分）**：武侠+炉鼎+赤脚正太，父子/师徒/客栈/娼馆元素齐备，9 章完整度极高，**唯一武侠风**。可作 Skill **父子/师徒+武侠异世界**代表。

# XP 偏好调整

## 调整规则

按用户 XP 偏好（正太核心 + 多元素命中 + 反血腥雷点）对每部作品的原始质量权重进行加减分：

**加分项（+1~+3）**：
- **正太**：03 子类默认 +2；正太受/调教 +2；正太中心 +3
- **小英雄**：英雄主角 +1；英雄堕落/反差 +2；英雄被俘核心 +3
- **榨精**：榨精套路 +1；榨精主线 +2；榨精核心 +3
- **龟责**：龟责出现 +1；龟责频繁 +2；龟责主题 +3
- **紧身衣**：紧身衣设定 +1；紧身衣束缚 +2；紧身衣核心 +3
- **足控**：足控场景 +1；足控主题 +2
- **触手/榨精生物**：触手出现 +1；榨精触手 +2；触手中心 +3
- **多 XP 命中**：2 个 XP +1 奖励，3+ 个 XP +2 奖励

**减分项（-1~-3）**：
- **雷女性**：女性角色主导 -1；女性中心 -2；纯女性向 -3
- **雷血腥**：血腥场景 -1；血腥主题 -2；重度血腥 -3

**计算公式**：调整后权重 = clamp(原始权重 + XP 加分 - 雷点减分, 1, 10)
