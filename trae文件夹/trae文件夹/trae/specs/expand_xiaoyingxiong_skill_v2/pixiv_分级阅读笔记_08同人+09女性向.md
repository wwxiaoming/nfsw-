### 高分 1：**妨碍拯救世界的勇者居然是魅魔！**（子目录名）— 调整后 10 分

- **基本介绍**：勇者奈奥维尔的转生异世界长篇，共 16 章，作者"幻想连篇2024"。融合穿越 / 魅魔之皇血统觉醒 / 奇幻剑与魔法 / 伙伴小队组建 / 反派阴谋等多层叙事。
- **原作世界**：**半原创奇幻世界**（无具体 IP，类 DND 设定 + 勇者魔王 / 圣女神官 / 剑与魔法的框架）。
- **章节结构**（16 章线性递进）：
  - 第 1-3 章：维尔转生 8 年后成为婴儿 → 凯德拉关卡新兵 → 魔物漆身事件 → 魅魔之力觉醒
  - 第 4-7 章：寻父遗物 → 魔法师辛达瑞拉的榨精 → 血源圣器"灵肉契约" → 警长夫人榨精 + 脸上刻淫纹
  - 第 8-11 章：精灵族关卡 → 三精灵榨精选拔 → 精灵女王"精尽人亡陷阱"
  - 第 12-15 章：圣域中心任务 → 红色黑暗精灵埃雷娜 + 蜘蛛毒液 + 魅魔淫纹救主 → 收服第一个性奴哈利姆
  - 第 16 章：表弟零（魅魔之皇）出场 → 中二病对决 → 血盟精炼
- **主要人物**：
  - **维尔（奈奥维尔）**：转生者，8 岁肉体 + 21 世纪灵魂，魅魔之皇血统（粉红心形印记），拥有战士 + 魅魔双系能力
  - **老林（矮人族铁匠）**：父亲角色，魔物漆身（牛头人/白银级下品）行业的引路人
  - **西夫百夫长**：黄金级战士，父辈部下
  - **辛达瑞拉**：高阶女魔法师（佩奥塔里奇学派），榨精维尔但同时是哈利姆的指路导师
  - **哈利姆**：黑发少年魔法师奴隶，从佩奥塔里奇出身，被维尔精炼为第一个性奴（病娇型伙伴）
  - **零**：白发表弟，魅魔之皇同族，九岁孩童，中二病 + 尿失禁
- **关键套路**：
  - **关卡递进结构**（旅馆→警长→罪恶关卡→精灵族，每关一女主一榨法）
  - **魅魔之皇血统被动触发**（濒死时腹部粉红心形印记自动亮起，反制对手并榨取灵魂）
  - **血源圣器"灵肉契约"**（神器级榨精道具设定）
  - **性奴精炼 + 灵魂链接**（性奴用淫纹标记 + 主人可用心灵感应操控）
  - **反英雄主角**（明确拒绝"勇者"标签，理由是"父亲为了陌生人而死不值得"）
- **文风**：长段对话 + 心理独白 + 战斗场景结合，正剧风格但保留少年漫画式的"觉醒"叙事。数据化精度中等（无 JJ 尺寸 / 足码等显式数据）。
- **关键场景**：
  - 1-3 章：维尔被捕后失禁 → 鹰身人女妖被魅惑 → 主动榨取灵魂（"魅魔淫纹"第一次被动发动）
  - 12 章：埃雷娜濒死强暴 → 维尔用魅魔之皇淫纹反制 + 鬼手强行榨精 → 哈利姆旁观后病娇爆发（"应该得到主人身体和精华的，只能是我！"）
  - 16 章：表兄弟对决 + 零被吓尿 + 维尔内射救零 + 精炼"零"
- **v2 增量**：
  - **T9-同人-IP-奇幻模板**：原作半原创 / 8 岁主角 / 关卡递进（每关 1 个新种族女主）/ 魅魔之皇血统（被动淫纹）/ 伙伴-性奴双线（哈利姆）

  - **新钩子 H30 魅魔之皇淫纹被动发动**（濒死时心形印记亮起）
  - **新反派 B 调教师**：辛达瑞拉型（理性榨精 + 毒舌 + 培养型关系）
- **v1 差异**：
  - v1 缺"半原创同人"这一子类——v1 假设同人必须是已有 IP（漫威/暴雪等），但本作品证明"半原创设定 + 关卡递进"也能成为同人模板
  - v1 缺"反英雄主角"的明确塑造——维尔拒绝勇者标签，理由是"父母为陌生人牺牲"——这是 v1 共性分析未覆盖的角度
  - v1 的"卧底反驯"模板仅限卧底，本作品的"被动觉醒 → 主动精炼"链路是 v1 未覆盖

### 高分 2：**血脉掠夺者**（子目录名）— 调整后 10 分

- **基本介绍**：玄幻血统觉醒长篇，14 章，作者"幻想连篇2024"。融合《斗罗大陆》同人的"魂环 / 魂骨 / 武魂"框架 + 穿越者蓝蔚羽 + 复制血脉 + 父子之战高潮。
- **原作世界**：**斗罗大陆（唐家三少原作）同人**，使用史莱克学院 / 武魂 / 海神阁 / 唐舞麟-蓝轩宇父子关系等原作设定。
- **章节结构**（14 章，学院→血祖身世→父子之战）：
  - 第 1-3 章：蓝蔚羽（穿越者）宿舍袭击蓝轩宇 → 夺血脉 + 精炼蓝轩宇 → 收服银发少年刘峰 + 胖子钱磊

  - 第 12-14 章：血祖出现 → 父子之战 → 身世揭晓（主角是血祖之子）→ 武器店遇险（预览）
- **主要人物**：
  - **蓝蔚羽（穿越者）**：10 岁少年，银纹/金纹蓝银草（双重武魂），主动榨精 + 复制血脉 + 淫纹控制

  - **钱磊（小胖子）**：武魂召唤金币，被蓝蔚羽"主动坐上来"收服
  - **唐舞麟**：14 岁金龙王血脉（被时光倒流回少年），是蓝轩宇的生父，被蓝蔚羽控制
  - **海神阁阁主（凌梓晨）**：万年女性反派 + 唐舞麟暗恋者，与唐舞麟"一次性交"以怀上孩子
- **关键套路**：

  - **主动坐上来**（胖子钱磊自己脱裤子坐上蓝蔚羽的巨根，主动求精炼）
  - **父子同时被榨**（唐舞麟用时光倒流回到 14 岁最敏感的状态后被儿子蓝轩宇榨精）
  - **双武魂淫纹操控**（金纹蓝银草捆肉棒 + 银纹蓝银草塞入马眼）
  - **海神阁主交易**（"让他跟你做一次，仅此一次"换取学院特权）
  - **教师/学长日常榨精**（唐舞麟"因为丢失了记忆"被淫纹完全驯化）
- **文风**：群像调度 + 多角色同步榨精 + 父子关系伦理冲击。正剧 + 群像调度。数据化精度高（JJ 描述精细："快有自己手臂粗"、"龟头向上弯曲成完美弧度"）。
- **关键场景**：
  - 第 1 章：蓝蔚羽"复制一份还回" + "粉红色爱心" 标记 → 蓝轩宇从反抗到主动配合
