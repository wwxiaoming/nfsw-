## 系列 1. ○○少年、（浅葱）

### 基本信息
- 作者：浅葱（asagi，Pixiv ID 7944688）
- 章节数：25 章（2014-07 → 2026-04，长期连载单发系列）
- 语言：日文
- 核心定位：单话完结（単発もの）的少年秀吉（ショタ）短篇合集，每章用「○○少年、△△する」的标题公式制造独立的「标签化少年」切片。
- 时间跨度：约 12 年

### 章节结构
全部 25 章皆为「标签少年 + 动词/状态」的命名公式：

阶段分布：
- **开篇引入**：几乎每章都采用「少年 + 职业/身份 + 场所」的固定三件套开场（道场 / 公园 / 岛 / 浴室 / 后巷 / 温泉街 / 健身房……）。
- **中段发展**：1-2 个调教 / 露出 / 战斗场景，第 3 章几乎是零肉文（露出癖少年纯描写），第 4、5、6、8 章是「指导型 / 接客型」，第 11、13、21 章加入催眠 / 触手 / 改造元素。
- **末段**：每章「単発」结束，少有跨章承袭；17、20 章是「少年小噺」，是先前篇章的「后日谈」小段子集。
- **收尾**：大多以少年的独白 / 自嘲 / 自慰高潮结束，少数使用开放性收束（如 #22 王族少年是胸糞向无救赎结局，作者明示警告）。

### 主要人物
- 主角：每章一个独立的「标签少年」；年龄集中在 12-15 岁；典型配置为「某种身份（运动选手/演艺/古风）× 还未自觉的肉体/性癖」，普遍设定是「身体已发育但性心理尚在萌芽」的小柄少年。
- 反派 / 调教师：
  - 公园偶遇的男人组（#1、#10、#11）
  - 健身房 / 按摩店温柔大哥哥（#6、#19、#25）—— 表面专业、用身体知识缓慢打开少年
  - 异世界商人、奴隶主、温泉旅馆老板等古风设定反派（#14、#22、#7）
  - 触手怪人 / 邪恶英雄（#13、#21）
- 配角：双子的父亲（#15）、兄弟（#7、#15）、探险队友（#5）等，多为「温柔-严厉」二元结构。

### 套路母题（13 个）
1. 固定标题公式：「○○少年、△△する」+ 标点（「。」或「される」被动态）
2. 公园 / 夜道 / 温泉街 / 废校等「公共半私密空间」为秀吉调教主场
3. 战败 / 落单 / 受伤 / 受欺负 → 引入成人男性
4. 表面职业身份（空手、剑道、足球、子役、佣兵、王族）+ 隐藏性癖（露出、被踩、催眠）
5. 自我说服型心理独白：「俺はこれが普通なんだ…」
6. 倒装被动语态（される、される体），强调「被……了」的施受关系
7. 身体与心理反应严格对照：身体先诚实、意识后追认
8. 拟声词（がさがさ、じゃりっ、ぽたっ）作为场景切换锚点
9. 拿衣服 / 脱衣服 / 全裸 / 湿透的「服装阶梯」
10. 少年的「家里没人」/「队友不在」/「祭りが近い」等契机性场景前置
11. 「后日谈（少年小噺）」：跨章节回收登场人物
12. 作者评论（作者语）夹在文末，做自嘲 + 雷区预警 + 排行榜感谢
13. 每章约 8000-15000 字，独立完结，不设大长篇伏笔

### 关键场景
- **#1 公园全裸夜游**：空手少年勇太在公园脱光 → 偶遇男人 → 被胁迫的雏形
- **#6 健身房按摩**：表面是「スポーツケアセンター」的专业按摩师 → 实为温柔型调教师 → 通过「肌肉分析」与「身体接触」逐步打破少年心防
- **#13 英雄恶堕**：ヒーロー少年（英雄少年）被触手怪人「絡め堕とされる」→ 罕见地将「英雄 × 触手 × 恶堕」与「ショタ」结合
- **#21 感覚遮断 + 巨根化改造**：跌落少年被改造 → 巨根化 + 巨玉化 → 改造系新尝试
- **#22 王族少年**：作者主动标注「胸糞 + 救いがない」→ 唯一明显的「向坏结局」尝试

### 文风特征
- 句长：以中短句为主，叙述句常以「～ている」收尾；感官句以短促拟态/拟声词独立成段
- 视角：第三人称有限视角（贴近少年独白），少数篇章用第一人称（#2 露出少年）
- 对话风格：含蓄 + 笨拙（少年口吻），成年男性多用半推半就的温柔
- 感官描写重点：触觉（肌肤摩擦、风、液体）、心理（羞耻 + 自我说服）、视觉（暗闇月光、シルエット）
- 日文 vs 中文差异：日文版高度依赖被动 / 自发语态（される、てしまう、させられる），用动作被动态暗示「被强迫」与「被快感侵蚀」的语法隐喻；中文版本（同类型中文作品）通常改用「被迫」「不自主」等词汇，丧失这种语法柔化效果。

- **外传角色**：苍隼（忍者、S 级、肛塞戴在英雄战衣下）、烨笙（黯月，紫色战衣裸足癖）、黑鸦（驯化者）等。

### 套路母题（15 个）
1. **公式化长标题**：模板「{形容词1}的少年{身份}，被{反派动作}，调教成{最终状态}」
2. **镇国五龙 / 战队编制**：固定人物池 + 平等轮换
3. **总攻 / 主控（云轩）+ 各自专属弱点**：每个队员都对应一个"软肋"（足、奶、淫纹、催眠、肛塞、感观遮断）
4. **Omega 等级 / 数据化角色卡**：情欲值、奴化程度、肉棒尺寸都是「数据」便于读者认知
5. **乳胶 / 胶衣 / 紧身战衣**：作为「包裹 + 视觉刺激」双重符号
6. **薄膜战衣（薄膜/胶质紧身）**：暴露轮廓的常用「性感枷锁」
7. **「贱屌」「小骚鬼」「英雄犬」等专属性称号**：羞辱标签化
8. **足控 / 裸足 / 鞋袜崇拜**：青龙、黯月、溟龙都涉及足癖
9. **催眠 / 洗脑 / 常识改写 / PUA**：作为非物理性控制手段
10. **恶堕 + 假戏真做**：卧底潜入敌营反被驯化
11. **战败 → 昏迷 → 醒来发现被改造**：标准剧情推进
12. **公共空间调教（公交 / 公园 / 球馆）**：增加「羞耻」维度
13. **哥哥/弟弟的禁忌关系**：弟控 + 恋兄 = 高频情感锁
14. **角色名字以「龙」字收束**：祖龙 / 烛龙 / 应龙 / 青龙 / 焱龙 / 溟龙 → 强化「龙」图腾
15. **预售 / 赞助章节模式**：用「11w 字 + 20 张图 + 8 折」直接面向核心读者商业化

### 关键场景
- **#1 千洛在哥哥胯下做春梦**：肉棒 / 后穴同时充血，是「龙族血脉」与「情欲」的混合定义。
- **#7 邪恶博士修改常识**：将「屌大精浓的骚逼浪货」植入少年脑内，HIP-HOP 节奏感极强的「催眠式改写」。
- **#11 公交车上戴肛塞上学**：经典「公共空间驯化」场景——男主挤在公车最里侧，紧身战衣下乳尖挺立、肛塞顶出轮廓。
- **#12 烨笙的恋足癖直播**：英雄的裸足对着摄像头「十根脚趾灵活扭动」，将「恋足」+「直播」+「英雄」三重身份叠加。
- **#13-15 尘渊的 PUA 全套**：从缺爱、被吸等级、被逐出门，到公园遛狗 → 完整 PUA 流程模板。

### 文风特征
- 句长：长句为主（白描+心理+动作三重叠加），单段可超过 500 字；句尾常用「❤️」emoji 软化冲击
- 视角：第三人称 + 偶插人物内白（角色名 + 冒号 + 心理活动），类似剧本脚本
- 对话风格：直白、挑逗、傲娇 + 娇喘；常用「呜…❤️」「嗯哈…」「要…要射了…」
- 感官描写重点：触觉（紧身衣摩擦、肛塞顶弄）、视觉（轮廓 / 汗水 / 精液痕迹）、嗅觉（足味、体香）
- 中文 vs 日文差异：中文版更依赖 emoji「❤️」与短促叠词「嗯哈」「呜」，制造听觉印象；日文版用「はぁっ」「んっ」+ 拟态词。中版更强调「数据化」（情欲值 100/100），日文版更强调「氛围」与「自我说服」。

## 系列 3. 进化之路（大魔法师）

### 基本信息
- 作者：大魔法师（Pixiv ID 114643812）
- 章节数：21 章（2025-03 → 2026-04）
- 语言：中文
- 核心定位：以「TNA 生物 / 进化 / 同化 / 洗脑」科幻设定为外壳的群像调教长篇。是中国 Pixiv 罕见的长篇连载 + 主线-支线双线推进作品。
- 时间跨度：约 1 年

### 章节结构
- 章节标题以「编号 + 关键词三段式」构成（章节 1-12 是「1-3」「4-6」合并发表，13 起改为单章长篇），例如：
  - 1-3：初识 / 气味 / 危机
  - 4-6：仪式 / 缘起 / 转化
  - 7-9：真相 / 公仆 / 审讯
  - 10-12：崇拜 / 处男 / 授精
  - 13-15：陷落 / 四人 / 五人
  - 16-18：赎罪 / 婚礼 / 异常
  - 19-21：淫窝 / 爱情 / 保留
  - 22-24：上瘾 / 发布 / 梦境
  - 25-27：组织 / 矛盾 / 威胁
  - 28-30：祝咒 / 潜伏 / 青春
  - 31-33：背叛 / 利用 / 球赛
  - 34-37：造神 / 新生 / 拯救 / 凡人
- 38 起切换为单章独立长篇：38 掩体 / 39 权色 / 40 源头 / 41 依偎 / 42 男人 / 43 约会 / 44 发泄 / 45 失败 / 46 悔恨
- 后期（38-46）转场到新人物「雷霄」+ 「黎明」+ 「南城高中 6 号前锋」的人物支线

阶段分布：
- **第一幕（章 1-3）**：引子（袁炜登场 + 宋家双子性格突变）
- **第二幕（章 4-9）**：转化仪式、篮球队长 蒋阔 主导同化、警局审讯
- **第三幕（章 10-18）**：崇拜、处男、授精、陷落、赎罪等群像
- **第四幕（章 19-27）**：组织矛盾、政府介入、黎明（警察）被同化
- **第五幕（章 28-37）**：交通大学场景、欧阳咒被强制公开
- **第六幕（章 38-46）**：雷霄支线，艾滋病毒叙事

### 主要人物
- **袁炜**（25 岁，183cm）：男主，「委托代理人」，半政府半江湖；后期作为「正义侧 / 调查员」身份贯穿全文。
- **宋理 / 宋擎**（双胞胎，大二学生）：哥哥宋理后期变为同化对象；弟弟宋擎被「进化」后觉醒，又反复挣脱，是「失控神明」式角色。
- **蒋阔**（1.95m 篮球体育生，22cm 巨物）：东华大学队长，作为第二代「神明替身」存在。
- **陆凌光**（180cm，70kg，精致处男型）：羽毛球队长，禁欲 + 恋足心理。
- **邓毅**（青梅竹马直男）：宋理最好的朋友，悲剧性「清醒者」代表。
- **黎明**（警察）：后期揭示是「八年前给少年雷霄种下艾滋」的施害者。
- **雷霄**（南城高中 6 号前锋）：艾滋感染 + 心理创伤 + 报复冲动。

### 套路母题（15 个）
1. **三段式关键词标题**：每章用 2-3 个并列关键词作诗化命名
2. **科幻外壳 + 心理动机**：TNA 生物设定作为「为什么大家突然变同性恋」的合理化借口
3. **群像调度**：同时间多线推进，靠「场所 / 角色 / 时间」三个坐标切换
4. **"进化"双重含义**：生理增强 + 性向转变，合二为一

## 写作可复用结构（提炼）

1. **战队 / 角色档案制**：固定 5-7 名队员 + 总攻 / 主角 / 副线分工 + 等阶 + 专属弱点

3. **三段式小节**：每章分 3 节，节奏分明，章末有作者语 / 排行榜感谢
4. **调教前-中-后公式**：
   - 前：身份/职业展示 + 性癖暗示 + 被俘契机
   - 中：温柔接触 → 心理松动 → 身体诚实 → 自我说服
   - 后：羞耻高潮 / 反差结局 / 后日谈段子
5. **母题库**（高频复用）：
   - 裸奔 / 触手 / 乳胶 / 催眠 / 足控 / 鞋袜 / 精液内射
   - 调教师「温柔大哥哥」/「同学少年」/「邪恶博士」/「触手怪人」四类
6. **跨章 / 跨篇回收**：用「少年小噺」或「外传」做后日谈
7. **数据化 + 心理学双轨**：硬数据（尺寸 / 情欲值）+ 软心理（自我说服 / 创伤过往）
