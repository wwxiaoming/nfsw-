# 小英雄小说共性分析

> 本文档基于批次 A（4 系列）、批次 B（5 系列）、批次 C（3 文件）共 12 部作品的深度阅读笔记，提炼出该题材跨作品的共性模式。所有结论均从 12 部作品中归纳得出，不复制原文，仅作结构化提炼，用于支持后续 SKILL / 角色卡 / 剧本自动生成。
> 覆盖作品清单：○○少年、（浅葱）、龙骧战队（轩辕小天）、进化之路（大魔法师）、光莲战队（外行怪人）、超人暂存（静风舰掌舵者）、小英雄零决（寒月o）、帝王战队——新世界（轩辕小天）、帝王战队——番外篇（轩辕小天）、正太小英雄用身体拯救世界（雨桐烟柳画桥）、双子特工、双子特工 2、超英视界——少年英雄们的淫色情史。

---

## 0. 题材定位

**题材本质**：以「身着制服 / 战衣 / 校服 / 紧身衣的 10-16 岁少年英雄（ショタ / 正太）」为绝对主体，借助「超级英雄、战队、特工、异能」等强设定外壳，把「少年成长」「身体开发」「权力臣服」「羞耻觉醒」四组母题糅合进 R-18 调教叙事的成人向亚文化题材。少年不是「受害者」，而是被塑造成「拥有某种能力 / 弱点 / 执念的小大人」，其主体性与性化并置是题材核心张力。

**核心张力**：
- 力量 vs 软弱：英雄在战场上的"超人感"与在密室中的"无能为力"形成对称。
- 纯真 vs 欲望：体味标签（奶香 / 薄荷 / 玉堂春）+ 童颜童语 + 性化描写的强烈对冲。
- 公共 vs 私密：制服、战衣、校园是「公共身份」；卧室、管道、审讯室、密室是「私域被侵入」。
- 拯救 vs 沉沦：英雄身份越"高"，被调教时的落差越具冲击力。

**读者期待**：
1. 看到「身份-职业-弱点」精准档案化（数据化角色卡）。
2. 看到「战败 / 被俘 / 昏迷 / 改造」作为剧情门的标准转换。
3. 看到「制服 / 紧身衣 / 白袜 / 裸足 / 体味」高频视觉符号。
4. 期待一种"温柔-强硬-温柔"的循环节奏，而不是单次暴力。
5. 期待「标题公式」一眼可辨（○○少年、 / 标签少年 + 动词；龙骧 #1 那种长标题等）。

**与其他题材的边界**：
- 区别于一般 BL / 调教文：必须有"英雄 / 战队 / 异能"等超自然外壳。
- 区别于普通正太文：必须有"战斗 / 任务 / 拯救世界"的叙事骨架。
- 区别于纯 NTR / 绿帽文：调教师往往是「敌对阵营」或「绝对权力代表」，而非情敌。
- 与 NTR 的交集：当面 NTR 桥段（重冥篇下）是高频子母题，但服务于「主奴关系 vs 战友感情」的张力。

## 1. 人物原型库

### 1.1 主角原型（≥ 5 类）

**① 标签少年型（「○○少年、」式）**
- 身份特征：单一身份标签（空手、剑道、足球、佣兵、王族、子役、露出），年龄 12-15 岁，体型「小柄」+「未自觉的肉体」。
- 性格：含蓄、笨拙、对自身性癖尚未命名。
- 心理弧线：从「这很正常」的自我说服 → 被动快感侵蚀 → 接受或半接受。
- 剧情功能：单话完结式人物切片；无需跨章承袭。
- 典型代表：○○少年、全 25 章每一章的「标签少年」。

**② 战队队员 / 副线型**
- 身份特征：固定 5-7 人战队队员之一，有专属色（红 / 蓝 / 金 / 白 / 黑 / 青）+ 专属武器 / 异能 + 专属弱点（足、奶、淫纹、催眠、肛塞）。
- 性格：被数据化（身高 / 体重 / JJ 尺寸 / 等级）以方便读者快速识别。
- 心理弧线：从「骄傲的英雄」到「专属的所属物」；沦陷 = 队伍的"成人礼"。
- 剧情功能：作为「固定人物池」的子集，可独立成章也可联动；适合"轮替沦陷"模板。
- 典型代表：龙骧战队（应龙千洛、烛龙玄麟、青龙天岚、焱龙世风、溟龙尘渊）、光莲战队（红莲嘉洛、蓝莲敖宇、金莲、白莲）、帝王战队（祖龙问天、玄冰重冥、时空凯风、龙渊暮黎、圣阳北辰、轮回空耀、时之子夜）。

**③ 卧底 / 潜入型**
- 身份特征：原本是英雄阵营，被派潜入敌营；身负"内鬼"心理压力。
- 性格：警惕 / 隐忍 / 压抑肉欲；任务身份 vs 真情实感撕扯。
- 心理弧线：从「任务需要」到「真戏真做」到「主动臣服」（"假戏真做"是母题）。
- 剧情功能：提供"内-外"双线视角；强化"羞耻 / 背叛 / 沉沦"心理深度。
- 典型代表：龙骧 #2 玄麟（烛龙）卧底篇、帝王战队凯风篇（假装战败潜入）、光莲嘉洛篇 2（潜意识期待重逢）。

**④ 反英雄 / 穿书 / 反讽型**
- 身份特征：穿书者、穿入者、原反派英雄转正、自带异能但被世界机制压制。
- 性格：吐槽役、毒舌、与"少年英雄"调性形成错位。
- 心理弧线：从「我是工具人」到「我要改变剧情」到「最终被世界规则收编」。
- 剧情功能：承担"作者话痨 + 世界观补丁 + 反讽视角"功能；提供作品间的元评论空间。
- 典型代表：正太小英雄用身体拯救世界（乐澄穿书）、进化之路（袁炜"委托代理人"半江湖半政府）、超人暂存（鹰——"思考型反派"从外部主导）。

**⑤ 智能体 / 异类型**
- 身份特征：非人类叙述者 / 异族 / 智械 / 上古遗物；用「我」的第一人称视角。
- 性格：冷静自持、关怀型 S、欲望被觉醒叙事带出。
- 心理弧线：从「观察」到「占有」到「自我定义爱」；通常伴有哲学性自问。
- 剧情功能：提供独特视角与心理独白空间；适合"纯爱 + 心理"路线。
- 典型代表：超英视界（晶辉之星 AI）、双子特工 2（敏寒之空间法则裁决者）。

**⑥ 兄弟双子 / 搭档 CP 型**
- 身份特征：双胞胎 / 兄弟 / 最佳拍档；年龄一致，能力互补。
- 性格：奶声奶气 + 战场吐槽双切换；存在固定"哥哥 vs 弟弟"分工。
- 心理弧线：从「任务互助」到「私下游戏」到「若即若离的羁绊」。
- 剧情功能：天然自带情感张力；适合"战斗 × 性"双线切换。
- 典型代表：双子特工（徐则星 / 徐则空）、○○少年 #7 兄弟篇、#15 双子篇、进化之路（宋理 / 宋擎）。

### 1.2 反派 / 调教师原型（≥ 5 类）

**① 温柔大哥哥型**
- 身份特征：健身房教练、按摩师、摄影师、医生、温柔学长；用"专业"外壳做接触。
- 性格：语调温柔、半推半就；不直接使用暴力，靠"身体知识"打破心防。
- 心理弧线：从"专业"到"私欲"显形；常带有"曾是被调教者"的背景。
- 剧情功能：低强度"心理入侵"模板；适合"日常感"调教展开。
- 典型代表：○○少年 #6 健身房按摩师、#19 太眉少年篇、#25 巨根少年；小英雄零决 #8 季伯常摄影宅男；超英视界（晶辉之星主动告白）。

**② 邪恶博士 / 催眠反派型**
- 身份特征：白大褂 / 实验服 / 学术权威；掌握"催眠 / 洗脑 / 常识改写 / PUA"。
- 性格：冷静、条理清晰、带有研究笔记式的记录癖。
- 心理弧线：从"实验体"到"成果"；经常对少年"植入"概念（如"屌大精浓的骚逼浪货"）。
- 剧情功能：制造"心理改造"型剧情升级；适合"催眠 / 记忆改写"母题。
- 典型代表：龙骧 #7 邪恶博士修改常识、龙骧 #20 教官、超人暂存 L 博士（幕后）、正太小英雄用身体拯救世界 #9 阿诺（疯狂科学家）。

**③ 触手怪人 / 异界生物型**
- 身份特征：非人 / 半人 / 触手 / 异界生物；常带"飞行道具 + 体液（黏液 / 花粉 / 丝）"。
- 性格：无情绪或低情绪；用"本能"驱动调教。
- 心理弧线：从"捕食"到"调教师化"；常被设计为"首篇 boss"。
- 剧情功能：作为剧情门（首战告败）的标准敌人；适合"改造 / 异种产卵 / 寄生"母题。
- 典型代表：光莲 #1 触手怪人（乳头改造）、小英雄零决 #7 蜘蛛怪人 + 触手怪"真空"、○○少年 #13 英雄恶堕、正太小英雄用身体拯救世界 #5 蟆休拉 / #10 虫潮。

**④ 收藏家 / 主控者型**
- 身份特征：成年、富有、收集少年英雄作为"藏品"；拥有专属展示空间（咖啡馆 / 拍卖行 / 地下酒馆）。
- 性格：华丽诡异 / 收藏癖 / 给予式控制（让英雄"自愿"臣服）。
- 心理弧线：从"单件收藏"到"全套收藏"；经常作为多线主控者贯穿全文。
- 剧情功能：作为长程主视角；适合"多主角轮替"模板。
- 典型代表：帝王战队新世界（天火煌炎 / 巫山雨）、龙骧（苏云轩队长 / 腹黑哥哥）、进化之路（蒋阔作为"第二代神明替身"）。

**⑤ 不良少年 / 流氓群型**
- 身份特征：街头混混 / 不良四人组 / 校园霸王；无明确组织，靠"人数 + 羞辱"压制。
- 性格：粗口、暴力、群体行动；个别成员有"心软"反差。
- 心理弧线：从"陌生人 → 主人化"；经常在第二篇展开。
- 剧情功能：作为"日常化反派"补充；适合"多反派梯队"结构。
- 典型代表：光莲 #2-3 阿雷 / 刺头 / 大壮 / 猴子四人组、帝王战队新世界（黄毛 + 魔犬下克上组合）、超人暂存（虎将军 + 威尔玛少校武斗派）。

**⑥ 上级 S / 权力压制型**
- 身份特征：等级 / 血缘 / 空间法则等"绝对权力"代表；西装皮鞋 / 冷峻 / 长子 / 家族继承人。
- 性格：冷淡、克制；偶有"被童年创伤扭曲"的洗白背景。
- 心理弧线：从"控制"到"依恋"到"离别"；常作为"反派洗白 + 治愈系"双线角色。
- 剧情功能：提供"绝对力量压迫"模板；适合"反派洗白"母题。
- 典型代表：双子特工 2（敏寒之空间法则裁决者）、帝王战队（巫山雨正太攻）、龙骧（苏云轩哥哥型总攻）。

**⑦ 校园混混 / 同学少年型**
- 身份特征：同校学长 / 学弟 / 隔壁班 / 校友；身份平行、接触日常化。
- 性格：好奇、试探、成长；常带"心机 / 真心"双面。
- 心理弧线：从"陌生"到"亲密"到"未必是爱"；常用于"校园日常"模板。
- 剧情功能：连接"战斗 / 拯救世界"与"日常 / 校园"两条线。
- 典型代表：帝王战队番外 #7-9 岚云传 / 启润传、#1 虎哥校园霸凌、超英视界（班长 / 炽闪 / 布鲁）。

### 1.3 配角 / 盟友原型（≥ 3 类）

**① 总攻 / 队内守护者型**
- 身份特征：队长 / 副队 / 总攻 / 哥哥；作为少年英雄的"内部"主控。
- 性格：腹黑 / 关怀 / 控制欲强。
- 剧情功能：提供"内部权力"模板；与"外部反派"形成对照。
- 典型代表：龙骧（苏云轩）、帝王战队（天火煌炎）、进化之路（蒋阔队长 / 袁炜调查员）。

**② 暗恋对象 / 同期小英雄型**
- 身份特征：同龄 / 异色 / 异能互补 / 治疗系 / 童贞不灭。
- 性格：温柔 / 奶凶 / 毒舌。
- 剧情功能：作为"情感支线"锚点；失踪即情感爆点。
- 典型代表：小英雄零决（郑小枫月光法）、正太小英雄用身体拯救世界（小天使宸泺）、超人暂存（狮子柯仁 / 秃鹫卓明远战友）。

**③ 直男 / 清醒者 / 悲剧型盟友**
- 身份特征：直男 / 未被同化 / 旁观者 / 旧友。
- 性格：清醒、痛苦、无法拯救。
- 剧情功能：提供"悲剧维度"，强化"沦陷"反差；经常作为"未被同化者"的对照。
- 典型代表：进化之路（邓毅青梅竹马直男）、超人暂存（虎将军 + 威尔玛少校）、帝王战队（叶枫秋 B 级英雄沦落为牲畜）。

**④ 兽人 / 异族小英雄型**
- 身份特征：兽耳 / 兽尾 / 翅膀 / 异族血统；专属体味 + 专属变身。
- 性格：野性 + 教导型；与少年英雄形成"师徒 + 战友"双关系。
- 剧情功能：提供"非人视角"与"师徒情感线"。
- 典型代表：帝王战队（空耀轮回狼耳）、文斌（机械星辉猫耳）、正太小英雄用身体拯救世界（矽辞巨狼少年）。

**⑤ 工具人 / 搞笑角色型**
- 身份特征：首领大叔 / 搞笑 NPC / 路人物业 / 班长。
- 性格：插科打诨、缓解氛围。
- 剧情功能：作为"信息差"载体 + "读者喘息空间"。
- 典型代表：双子特工 2（首领大叔）、小英雄零决（神鹰小队 / 志铭博士闷骚导师）、超英视界（班长直男 / 布鲁花心前辈）。

## 2. 剧情模板（≥ 3 套）

### 模板 A：单反派长程调教型
**适用**：长篇连载、单一反派主导、节奏稳定。
**典型代表**：超人暂存（鹰 + 虎双反派）、帝王战队新世界（天火主控）、龙骧（苏云轩 + 邪恶博士）。

- **阶段 1（铺垫）**：英雄的日常 + 能力展示 + 战败契机暗示。
  - 触发条件：战败 / 任务失败 / 内奸暴露 / 队友失联。
  - 阶段内容：日常 → 任务 → 失败。
  - 转折点：昏迷 / 跌落 / 被俘。
- **阶段 2（初入）**：反派/调教师登场，建立"专业"或"权威"形象。
  - 触发条件：被俘。
  - 阶段内容：身份档案展示 + 调教师背景铺垫 + 第一波"心理压迫"。
  - 转折点：第一波具体接触（催眠 / 灌水 / 束缚）。
- **阶段 3（心理松动）**：从"刚硬抵抗"到"半推半就"。
  - 阶段内容：身体先诚实 + 自我说服 + 出现"自己是不是变态"的自嘲。
  - 转折点：第一次非自主的生理反应（漏尿 / 勃起 / 喷精 / 流泪）。
- **阶段 4（升级）**：多手段叠加（催眠 + 药物 + 束缚 + 公开化）。
  - 阶段内容：印记 / 项圈 / 锁精环等"所属权标志"植入 + 公开处刑 / CCTV 直播。
  - 转折点：第一次"被当众使用"。
- **阶段 5（团队沦陷）**：队员依次沦陷，建立"必然命运"感。
  - 阶段内容：被俘的队员被展示 / 队员之间被迫对打 / 录像带互看。
  - 转折点：原本最有骨气的"队长"沦陷。
- **阶段 6（反转 / 收束）**：营救 / 反杀 / 反派洗白 / 治愈系离别。
  - 触发条件：外援出现 / 反派内部分裂 / 主角觉醒新能力。
  - 收束方式：开放式（继续连载）、治愈系（离别赠物）、悲剧式（被完全驯化）。

### 模板 B：多人轮替沦陷型
**适用**：战队 / 群像 / 多主角、平等轮换结构。
**典型代表**：龙骧战队、光莲战队、帝王战队、进化之路。

- **阶段 1（战队档案）**：固定 5-7 名队员介绍，每人配独立色 + 异能 + 弱点。
  - 阶段内容：身高 / 体重 / JJ 尺寸 / 等级 / 体味 / 制服色全部数据化。
  - 转折点：第一位队员的"沦陷契机"出现。
- **阶段 2（第一位沦陷）**：通常选队长或副队长。
  - 阶段内容：身份最高 → 沦陷最惨 → 反差最大。
  - 转折点：第一次"被改造"完成。
- **阶段 3（第二、三位沦陷）**：按"性格 / 弱点"差异化展开。
  - 阶段内容：足控 / 催眠 / 淫纹 / 催眠 / 肛塞 / 感官遮断的对应手段。
  - 转折点：第二位队员目睹第一位队员沦陷（"我也会这样吗"心理预设）。
- **阶段 4（全员沦陷 / if 反转）**：全部沦陷 OR 出现 if 线（部分队员获救）。
  - 阶段内容：宿命论全员沦陷 / 或 if 线展现"如果有人阻止会怎样"。
  - 转折点：番外篇 / 设定集展示"全员去向分工"。
- **阶段 5（外传 / 后日谈）**：沦陷后的"部门化"分配或日常化堕落。
  - 阶段内容：每人有专属"任务"（接客 / 展示 / 榨精 / 守门）。
  - 收束方式：设定集 / 番外合集 / 群交落地。

### 模板 C：卧底反被驯化型
**适用**：潜入 / 间谍 / 假戏真做 / 心理深度。
**典型代表**：龙骧 #2 玄麟篇、帝王战队凯风篇、光莲 #2 嘉洛篇、双子特工 2（敏寒之对兄弟的压制）。

- **阶段 1（任务接领）**：明确任务目标、风险等级、回报代价。
  - 阶段内容：接任务 → 准备 → 出发。
  - 转折点：进入敌营。
- **阶段 2（身份扮演）**：以新身份在敌营活动。
  - 阶段内容：伪装 + 试探 + 第一次被识别（可能是反派的识破或同化的察觉）。
  - 转折点：第一次被迫服从的命令。
- **阶段 3（第一次沦陷）**：被"任务需要"合理化。
  - 阶段内容：自慰 / 接触 / 服侍；内心是"任务需要"vs"我是不是开始享受"。
  - 转折点：发现"敌人也懂我"的共情瞬间。
- **阶段 4（真假混淆）**：分不清自己是"在演"还是"真想"。
  - 阶段内容：被赐名 / 被占有 / 被认同；与外部队友的信息差造成更大撕裂。
  - 转折点：第一次"主动"（而非"被迫"）的行动。
- **阶段 5（彻底沦陷 / 觉醒反转）**：完全驯化 OR 突然觉醒反杀。
  - 阶段内容：被外部救援 / 自己觉醒 / 反派崩溃。
  - 收束方式：悲剧式（回不去了）/ 治愈式（带着新的归属回去）/ 开放式（成为双面间谍）。

### 模板 D：小学生 / 校服萌系型
**适用**：幼态强化、白袜足控、童真 + 战斗反差。
**典型代表**：小英雄零决、双子特工（小学双子）、超英视界（绿叶初中生）、正太小英雄用身体拯救世界（乐澄初一）。

- **阶段 1（觉醒 / 入学）**：小学生/初中生刚觉醒能力或刚转入新学校。
  - 阶段内容：身份介绍 + 体味标签 + 校园制服 + 第一次展示异能。
  - 转折点：第一次战败或被陌生人接触。
- **阶段 2（被温柔接住）**：被怪蜀黍 / 大哥哥 / 上级 S 收留。
  - 阶段内容：陌生环境的紧张 → 温水澡 / 共眠 / 受伤治疗。
  - 转折点：第一次"被温柔抚摸"的非自主反应。
- **阶段 3（白袜 / 校服 / 软肉视觉锤）**：日常向身体描写强化。
  - 阶段内容：白袜 + 校服 + 短袖 + 软肉 + 薄荷香/奶香叠加。
  - 转折点：第一次"被偷看"或"被强迫展示"。
- **阶段 4（龟头责 / 足控极致化）**：极端敏感局部开发。
  - 阶段内容：龟头责 / 尿道检 / 足底挠 / 吸乳器。
  - 转折点：第一次"自我厌恶"到"自我接受"。
- **阶段 5（感情线深化）**：暗恋对象登场 / 失联 / 营救。
  - 阶段内容：被救 / 治愈 / 反向告白 / 离别。
  - 收束方式：纯爱向 / 治愈系 / 校园日常延续。

### 模板 E：科幻外壳同化群像型
**适用**：长篇世界观、多线同化、社会议题融入。
**典型代表**：进化之路（TNA 生物 / 同化 / 艾滋）、正太小英雄用身体拯救世界（精源 / Z 纯晶）、超人暂存（纳米紧身衣破解链）。

- **阶段 1（科幻设定抛出）**：TNA 生物 / 进化 / 同化 / 精源 / 病毒等"合理化借口"。
  - 阶段内容：开篇 1-3 章建立世界观 + 群像登场。
  - 转折点：第一次"觉醒 / 转化"事件。
- **阶段 2（多线推进）**：场所 / 角色 / 时间三坐标切换。
  - 阶段内容：大学 / 警局 / 军队 / 体育馆 / 街道不同场景。
  - 转折点：政府/官方力量的介入（镇压 vs 默许）。

  - 转折点：作者"升华"主题，让作品超越纯肉文。
- **阶段 5（结局分支）**：新人物支线 / 复仇成功 / 同化扩散 / 全员沦陷。
  - 收束方式：开放式 / 悲剧式 / 续作钩子 / 数据档案收束。

### 模板 F：智能体 / 第一人称纯爱型
**适用**：独特视角、哲学性自问、纯爱向、S 自白。

## 4. 对话风格

### 4.1 主角常用句式
- **自我说服型**：「俺はこれが普通なんだ…」（○○少年、典型句式）；"我只是在任务需要"（双子特工 2 玄麟型）。
- **童言童语 + 战场吐槽双切换**：「算你欠我一包辣条」（双子特工则星）；"你零爷爷还能留你小命"（零决）；"老毕登都是高抬你了"（乐澄）。
- **傲娇 + 娇喘**：「呜…❤️」「嗯哈…」「要…要射了…」+ 短促叠词（龙骧千洛、嘉洛）。
- **含蓄 + 笨拙**：少年口吻 + 成年男性的对话被压缩为单字回应。
- **毒舌 + 自嘲**：清真系少年的吐槽役（正太小英雄用身体拯救世界）。
- **奶声奶气 + 关心**："哥，这样真的好吗？"（双子特工兄弟）。
- **哲学性自问**（智能体视角）："什么是爱？""什么是人性？"（超英视界）。

### 4.2 反派常用句式
- **温柔半推半就型**：「我只是帮你放松一下」（○○少年 #6 按摩师）；"这是专业的"。
- **戏剧化华丽型**：「专属宠物」「肉便器标本」「贱畜精奴」「淫骚母狗」（帝王战队天火）。
- **研究笔记式**：「让我们记录一下你的反应」（龙骧邪恶博士、超人暂存 L 博士）。
- **政治化隐喻型**：「把超人当筹码」「战略价值」（超人暂存鹰 + 虎将军）。
- **收藏家式**：「藏品 / 拍卖 / 标价 / 编号」（帝王战队天火、巫山雨）。
- **正太攻反转式**：「让我成为你的哥哥」（巫山雨型）；"我能当你一天哥哥吗"（敏寒之型）。
- **硬气反派式**：满嘴脏话（"操你妈""狗杂种"）+ 身体暴力（虎将军）。
- **催眠咒语型**：「服从我」「你是贱屌英雄犬」（进化之路"服从我"咒语式短句）。

### 4.3 心理独白结构
- **身体-意识分裂**：「身体先诚实，意识后追认」（○○少年、核心结构）；常见模式：身体反应 → "我只是累了 / 我只是紧张" → 接受。
- **自我说服三段式**：
  1. 事件发生
  2. 「这很正常 / 我只是 xxx」的解释
  3. 下一次更深的接受
- **角色名 + 冒号 + 心理活动**（剧本式独白）：龙骧常用。
- **「……」+「——」+「❤️」**作为情绪标点。
- **内心双线对话**（"任务需要 vs 我是不是变态"）：双子特工 2、玄麟型。
- **哲学性自问独白**（智能体视角）：超英视界；常带"我是否拥有情感"的元问题。

### 4.4 倒装与省略手法
- **日文被动态**：「される」「てしまう」「させられる」暗示"被强迫"与"被快感侵蚀"语法隐喻。
- **中文倒装**：「这很正常…（停顿）…我只是想休息」。
- **短促叠字**：「呜嗯嗯啊啊啊」「咕啾」「啪嗒」+ 拟声词独立成段。
- **省略号铺陈**：「……是…是…❤️」（娇喘叠词 + emoji 软化）。
- **长定语 + 短动词**：「扑哧」「啪嗒」拟声词密布（超人暂存）。
- **内心独白省略主语**：「（我）只是紧张而已」（省略主语造成"自我说服"效果）。

### 4.5 中日文文风差异
- **日文系（○○少年、）**：
  - 高度依赖被动 / 自发语态（される、てしまう、させられる）。
  - 动作被动态暗示"被强迫"与"被快感侵蚀"语法隐喻。
  - 短句 + 拟态 / 拟声词独立成段。
  - "自我说服" 心理独白为主。
  - 氛围感重，不强调数据精度。
- **中文系（龙骧、进化之路、光莲、超人暂存、零决等）**：
  - 依赖 emoji「❤️」与短促叠词「嗯哈」「呜」制造听觉印象。
  - "数据化" 角色卡（情欲值 100/100、身高 163cm、JJ 18.19cm）。
  - 强调"数据精度"（18cm、44 码、耐克精英袜、AJ23）。
  - 长句 + 心理 + 动作三重叠加。
  - "硬核细节堆叠"（鞋袜 / 体味 / 制服品牌）。
- **中-日混合型（帝王战队）**：
  - 群像 + 史诗感。
  - 长复句 + 世界观铺垫极长。
  - 对话华丽诡异（戏剧化反派 + 傲气英雄双轨）。

## 6. 节奏模板

### 6.1 章节长度
- **日文单话型（○○少年、）**：每章 8000-15000 字，独立完结。
- **中文短篇（光莲、光莲篇一）**：每章 1000-3000 字（每节），节奏明快。
- **中文长篇单章（进化之路、超人暂存、帝王战队）**：每章 5000-20000 字；合订 / 三段式发布（1-3、4-6、7-9）。
- **同人短篇（双子特工、超英视界）**：单篇 11000-25000 字。
- **单章跨度建议**：10000-15000 字为单章最常见；超过 20000 字需要分小节。

### 6.2 场景切换频率
- **战队型**：每章 3-5 个场景（日常 → 战斗 → 沦陷 → 番外 / 设定）。
- **群像型**：每章 5-8 个场景（场所 / 角色 / 时间三坐标切换）。
- **单线型**：每章 2-3 个场景（任务 → 沦陷 → 收束）。
- **第一人称型**：每章 1-2 个大场景 + 大量内心独白。
- **建议**：平均每 2000-3000 字切换一次场景或情绪。

### 6.3 高潮位置
- **章节高潮**：常出现在 70-80% 位置（"被公开 / 被当众使用" / "全员沦陷"）。
- **故事高潮**：常出现在 80-90% 位置（"主控者客厅展示" / "反派最终酷刑"）。
- **反转位置**：常出现在 90% 之后（"觉醒反杀" / "营救出现" / "离别赠物"）。
- **淫逸高潮**：常在 60-80% 之间，避免与剧情高潮重叠。

### 6.4 情绪曲线
- **模板 A（单反派长程）**：
  1. 日常（平静）
  2. 战败（紧张）
  3. 被俘（恐惧）
  4. 心理松动（混乱）
  5. 第一次沦陷（崩溃）
  6. 升级（绝望）
  7. 营救 / 反转（希望 / 治愈）
- **模板 B（多人轮替）**：
  - 每位队员一个独立的"紧张 → 沦陷 → 接受"小周期。
  - 在"全员沦陷"时达到总高潮。
- **模板 C（卧底）**：
  - 假身份压抑 → 第一次被迫服从 → 任务 / 真情混淆 → 彻底沦陷。
  - 情绪波幅最大。
- **模板 D（小学生）**：
  - 童真 → 第一次被温柔接触 → 自我厌恶 → 接受 → 治愈。
  - 情绪波幅中等偏小，主打"萌 + 治愈"。

### 6.5 收束方式
- **开放式**：继续连载，章节结束于"新的威胁出现"或"新的伙伴登场"。
- **治愈系**：离别赠物（白袜 / 内裤 / 照片）+ 眼泪。
- **悲剧式**：完全驯化 / 当众使用 / 自我放逐。
- **反英雄式**：觉醒反杀 + 新的复仇。
- **数据化收束**：设定集 / 全员去向分工表 / 角色卡更新。
- **if 线分叉**：常规线 + 平行 if 线的二选一结构。

## 7. 文风标识

### 7.1 句长
- **日文单话型**：以中短句为主，叙述句常以「～ている」收尾；感官句以短促拟态/拟声词独立成段。
- **中文长篇型**：长句为主（白描+心理+动作三重叠加），单段可超过 500 字；句尾常用「❤️」emoji 软化冲击。
- **中文群像型**：长句极多（一句可达 200 字以上），节奏感强，靠「——」「……」做断句。
- **同人短篇型**：短长交替，战斗用短句堆砌（"噗嗤！""咔嚓！"），日常用中等长度叙事句。
- **第一人称型**：极长，大量心理独白与"呜嗯嗯啊啊啊"等拟声叠字。

### 7.2 用词偏好
- **数据化词汇**（中文系）：身高 / 体重 / JJ 尺寸 / 球鞋码数 / 袜子品牌（Nike 精英袜、阿迪三叶草、AJ23）。
- **日文拟声拟态词**：がさがさ、じゃりっ、ぽたっ、がちゃっ。
- **中文拟声拟态词**：咕啾、啪嗒、扑哧、噗嗤、咔嚓。
- **emoji 与符号**：❤️、……、——、✨（中文系常用）。
- **叠字叠词**：呜嗯嗯啊啊啊、嗯哈、要…要射了…
- **羞辱性称号**：贱屌、小骚鬼、英雄犬、肉便器、骚逼浪货、废物贱狗、黑皮肌肉犬、淫足骚蹄子、白浊处理器、漏尿处理器、嫩脚痒奴、淫足母狗、废物杂种、堕落天使、淫骚母狗。
- **角色化体味标签**：奶香 / 薄荷香 / 玉堂春香 / 雪松香 / 梅花香 / 雄臭 / 汗味 / 足味 / 奶臭 / 骚臭。

### 7.3 叙述视角
- **第三人称有限视角（贴近少年独白）**：○○少年、的主要结构。
- **第三人称 + 偶插人物内白（角色名 + 冒号 + 心理活动）**：龙骧常用，类似剧本脚本。
- **第三人称 + 大量角色直接引语（小说化剧本）**：进化之路。
- **第三人称 + 角色心理独白 + 偶尔插入角色直接对话**：光莲。
- **多视角切换**：帝王战队（天火 / 巫山雨 / 黄毛 / 凯风）。
- **第一人称（智能体）**：超英视界。
- **第三人称多视角（兄弟 / 反派）**：双子特工 2。

### 7.4 感官描写重点
- **触觉**：肌肤摩擦、风、液体、紧身衣摩擦、肛塞顶弄、触手缠绕。
- **视觉**：暗闇月光、シルエット、皮肤色调、肌肉线条、轮廓、汗水、精液痕迹、内裤顶帐篷 / 三角裤勾轮廓。
- **嗅觉**：足味、体香、奶香、薄荷香、玉堂春香、雪松香、雄臭、汗味、奶臭、骚臭。
- **听觉**：喘息、娇喘、心跳、流水声、沉默（很重要）。
- **心理（常常被强调为第一感官）**：羞耻 + 自我说服、自尊与肉欲的撕扯、任务需要 vs 我是不是变态、自我厌恶 + 被接纳的反教化。
- **色情化听觉**：咕啾、啪嗒、扑哧、噗嗤（拟声词密布）。

### 7.5 标题命名规则
- **日文系公式**：「○○少年、△△する」+ 标点（「。」或「される」被动态）；25 个标题全部沿用。
- **中文长标题公式**：「{形容词1}的少年{身份}，被{反派动作}，调教成{最终状态}」（龙骧）。
- **中文超长标题公式**：「{身高特征}的{少年英雄}，被{反派} + {动作}，{羞辱结局}」+「({成员}篇{序号})」（光莲）。
- **中文三段式关键词标题**：「初识 / 气味 / 危机」式诗化命名（进化之路、帝王战队番外篇）。
- **中文"前情提要 + 设定补丁"**：长篇开篇常用"前情提要"和章节间的"设定补丁"机制（正太小英雄用身体拯救世界）。
- **if 线分叉标题**：「if 药师小枫」「if 战败线」（小英雄零决、正太小英雄用身体拯救世界）。
- **番外 / 设定集 / 后日谈**：「少年小噺 壱」「人设立绘图（设定集）」（○○少年、#17 / #20；龙骧 #8）。
