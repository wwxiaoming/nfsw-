## 系列 1. 超人暂存（37 chat + 5 番外 · 静风舰掌舵者）

### 基本信息
- 作者：静风舰掌舵者（Pixiv ID 9016108）
- 章节数：37 个 chat 章节（chat 1 - chat 29，含 0.5/2.5/4.5 等半章过渡） + 5 个"犀牛超人调教"番外
- 时间跨度：2022-02 至 2026-06（持续 4 年多仍在更新）
- 标签：R-18G / 调教 / 催眠 / 肌肉 / ホモ / 奴隶 / 恶堕 / 战俘 / 榨精
- 核心定位：单主视角（鹰/红发青年）操控四名 S 级肌肉系少男超人的"长程科学调教 + 战术合作"复合型长篇

### 章节结构
1. **第一阶段（chat 1–chat 9）**：先锋超人小队的两位成员狮子柯仁、秃鹫卓明远先后被俘；鹰通过医学洗脑 + 欲望循环 + 单纯囚禁三套手段建立对二人的心理优势
2. **第二阶段（chat 10–chat 20）**：鲨鱼柯礼在引诱下被捕；三超人开始互相"被安排"接触；鹰的实验从生理改造升级到意识层植入
3. **第三阶段（chat 21–chat 29）**：犀牛云鹏被处刑式调教 + 多次反复破防；L 博士的"究极计划"被揭露；三人对战队的归属开始反转
4. **犀牛番外 1–5**：单线深挖犀牛云鹏的浣肠、强制高潮循环、口枷佩戴、群交落地的"肉体调教"全过程
5. **最终章（chat 25-29）**：S 级巨型机械兽从地底突破军营，三超人以"展示品"身份被摆上甲板待运，营救行动与"驯化"两条线并行收束

### 主要人物
- **鹰（红发青年 / 调教师 / 主导者）**：20 岁外表的科学家 / 巫术操控者 / 不直接使用暴力的"思考型反派"；与虎将军形成权力博弈
- **虎将军（粗野武人）**：旧军事集团的高层 / 性虐成瘾者 / 负责拷问与展示处分
- **威尔玛少校（执行者）**：虎将军的副手 / 士兵训练师 / 把战俘变成"训练工具"；策划战利品展示
- **狮子柯仁（队长 / 正统派）**：高大健壮 / 棱角分明 / 战商高 / 被囚禁后仍维持"高傲低头"的姿态
- **秃鹫卓明远（军师型）**：眼角圆眉 / 战商极高 / 弱点是过于关心队友 / 通过自我出卖换取情报
- **鲨鱼柯礼（少年 / 速度型）**：身材苗条精壮 / 脾气火爆 / 嘴硬 / 易被激怒 / 多次被士兵轮番玩弄
- **犀牛云鹏（防御型 / 反差萌）**：壮硕肌肉 / 沉稳寡言 / 重情义 / "被迫当众发情"是核心桥段
- **L 博士（幕后操盘手）**：4 人导师 / 隐藏的究极计划发起人 / 不断在战俘口中被提及

### 套路母题（共 14 个）
1. **科学调教师 vs 武斗型反派**——双反派权力分配公式（鹰负责灵魂、虎负责肉体）
2. **纳米紧身衣的破解链**——超人能力源自战衣，战衣破解是情节关键钩子
3. **纯水刑 / 溺水 + 殴打**的循环酷刑（秃鹫篇开场）
4. **机器内置的"勃起—冷却—再刺激"循环**（鲨鱼篇核心）
5. **催眠式灵魂印记 / 契约项圈**——可被强制开启奴隶人格的设定
6. **战俘的"展示品"列队检阅**——公开场合的绳子 + 私处绳结 + 强行走正步
7. **八角笼内战友对打**——通过逼队友性交/击倒换取另一人性命的"赌局"
8. **虎将军式残酷肉刑**：银针穿刺阳具、木板夹碎睾丸、烙印、窒息 + 电击联合酷刑
9. **CCTV 全程直播调教** + 公开战败公告 / 新闻采访式拍片
10. **S 级战俘被"分配"给普通士兵轮值"消费"**——"1001 组每人一晚最低 10 次"
11. **群交落地的英雄性宴会**——4 个英雄互相口交/肛交/射精限制
12. **舰船 / 容器 / 鸟笼 / 圆盘**等"展示型牢笼"设计（鲨鱼水缸、秃鹫鸟笼、犀牛拉磨盘）
13. **巨型机械兽救援**（钻头 + 三机械兽）—— 营救方的超规格战力 + 悬念收尾
14. **X 博士"究极计划"作为悬念支撑**——贯穿全文的伏笔

### 关键场景
- **柯仁被口灌桶装水 + 眼罩 + 张口器的"意识重启"开场**（chat 1）
- **秃鹫水刑 2 小时不间断 + 周围人机械执行**（chat 2）
- **鲨鱼"性器束缚 + 跳蛋循环"实验笔记式调教**（chat 5）
- **威尔玛带队"战利品展示"，台下士兵轮流吐唾沫 + 巴掌**（chat 20）
- **秃鹫把尊严交给鹰换取情报的"心照不宣"谈话**（chat 23）
- **云鹏 vs 柯礼"被迫八角笼性交"**（chat 15）
- **舰船仓库内 4 超人"循环高潮禁止"群交落地**（chat 29）
- **番外 1：云鹏浣肠 + 灌液 + 排便羞辱**（完整的"基础失控"流程）
- **番外 3：跳蛋 + 龟头责 + 尿道棒 + 长时间孤立调教逼问"你是什么"**（身份剥夺母题）
- **番外 5：4 人同时在场互相性服务的"群交交响曲"**

### 文风特征
- 句长：长句堆砌，特别在性描写段落中大量使用"短促动词 + 长定语"结构（"扑哧""啪嗒"等拟声词密布）
- 视角：第三人称有限视角，主要跟随鹰 / 虎 / 三位超人的心理
- 对话风格：反派台词政治化与隐喻化（"把超人当筹码""战略价值"），超人台词硬气 + 满嘴脏话（"操你妈""狗杂种"）
- 感官描写重点：汗液 / 黏稠 / 绳索粗粝 / 龟头红肿 / 眼罩下的黑暗 / 耳光 + 唾沫
- 时间线跨度大：同一年中 chat 编号从 1 跳到 29 但实际跨度 4 年多，作者有明确的时间感
- 长篇规划感强：每章节都有"战商 / 战略 / 战术"层面的对话，区别于纯肉文

## 系列 2. 小英雄零决（12 章 + 1 if · 寒月o）

### 基本信息
- 作者：寒月o（Pixiv ID 74731685）
- 章节数：12 个主章节（编号不连贯，含 #1–#8 + if 药师小枫 + 9–11）+ 中间间歇
- 时间跨度：2024-07 至 2026-03
- 标签：R-18 / 小英雄 / 恶堕 / BL / 正太 / 调教 / 榨精 / 败北 / 触手 / 白袜 / 龟头责
- 作者自述：本系列与前作风格不同，"有剧情过渡也有人物刻画，是小说和 h 文之间的折中"
- 核心定位：原创"星辰英雄"零决（小学生）× 怪人 / 彗星组织 vs 调查员小枫的"少年反英雄"长篇

### 章节结构
1. **第一至三章**：零决觉醒 → 引入志铭博士 / 彗星组织背景 / 神鹰小队敌对关系
2. **第四至六章**：蜘蛛怪人篇 → 蓝色战斗服 / 星眸透视 / 多肢对手 → 第一次战败
3. **第七至八章**：深陷旋涡（独自闯魔窟）→ 战败被怪蜀黍（季伯常）捡回家 → 第一次真正的"龟头责"调教
4. **if 药师小枫**：独立世界观的"穿越 / 跨宇宙相遇"if 线 → 触手段调教展开
5. **第九至十一章**：小枫失踪 / 触手怪"真空" / 机械榨精 / 情感线断裂

### 主要人物
- **零决（主角）**：六年级小学生 / 蓝色紧身战斗衣 / 银长枪 / 星辰之力 / 自尊心强 / 白袜控属性
- **郑小枫（重要配角 / 暗恋对象）**：10 岁 / 月光法系药剂师 / 黑短发 / 脚 + 鸡鸡敏感 / 童贞不灭设定
- **志铭博士（导师）**：年龄相近的青年 / 白大褂 / 神鹰小队原型 / 闷骚性格
- **季伯常（战败后"捡"主角回家的怪蜀黍）**：摄影宅男 / 内心挣扎的隐性调教师
- **彗星组织（敌对）**：第三席"真空" / 触手系 / 多肢系 / 巨兽系等不同分支
- **神鹰小队（官方组织）**：与主角抢风头的同龄精英小队 / 戏份为氛围烘托

### 套路母题（共 13 个）
1. **小学生英雄 × 触手怪的初战败**——年龄反差 + 巨物恐惧
2. **白袜足控的极致化**：白袜脚踩水洼都会让主角产生生理反应
3. **星眸透视**——战斗开挂 + 触觉放大的设定钩
4. **蓝色紧身战斗衣** + 银长枪的"纯真战士"视觉锤
5. **草药治疗 / 精源补充**的世界观——少年英雄以精源为能量
6. **暗恋 / 友谊向感情线** 作为核心情感驱动（小枫失踪是分水岭）
7. **if 线分叉**——"另一个世界的小枫"作为情趣 if 补充
8. **"怪蜀黍救回家"** 桥段——被陌生人温柔包裹后心理防线崩塌
9. **龟头责 / 尿道检**——超敏感局部的极端开发
10. **触手丝 / 蛛丝束缚 + 战败**（第七章多层蛛网迷宫）
11. **机械榨精机**——非人调教师 + 极端工业化设定（第十一章）
12. **男童的"白嫩 / 奶香 / 薄荷味"**——身体标签化作为视觉锤
13. **校服 / 校园 / 小学**的"幼态"语境强化

### 关键场景
- **零决街头觉醒战狼人**（第一章开场）
- **志铭博士家中"解除变身后露鸟"**——意外暴露
- **后山蜘蛛洞穴人面蛛集群**（第四章）
- **星眸透视破解 + 多肢蜘蛛怪人 6 手战败**（第七章）
- **大哥哥捡回家 + 龟头责开苞**（第八章）
- **if 线触手段初遇**（药师小枫）
- **小枫家里真空突然出现 + 触手入侵**（第十一章）
- **机械榨精机"性玩具化"**——最黑暗一章

### 文风特征
- 句长：偏短，情感戏长句 + 战斗戏短促句
- 视角：第三人称有限视角，主要跟随零决
- 对话风格：奶声奶气 + 童言童语 + 战斗状态切换到冷峻吐槽（"你零爷爷还能留你小命"）
- 感官描写重点：白袜 + 校园制服 + 软嫩肌肤 + 薄荷味 / 奶香 + 星辰蓝光特效
- 间歇更新风格：作者会加"作者的话"长段碎碎念（追梦 / 学业 / 群宣传）
- 世界观严肃：彗星组织 / 神鹰小队 / 星辰之力设定有完整体系，与纯肉文区别明显
